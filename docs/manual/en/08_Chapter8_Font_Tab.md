# Chapter 8 Font Tab

In the "Font" tab you can compare and choose fonts and save text appearances (styles). Saved styles can be used with one click in the Layout tab and the Image tab.

The screen has three areas.

| Area | Role |
| --- | --- |
| Left | Font list (Google / System / Category) |
| Center | Preview, and creating styles and presets |
| Right | Information about the selected font, tag and category management, apply buttons |

## 8-1 Finding and Comparing Fonts

### Font sources

Switch the fonts shown with the tabs above the list on the left.

| Tab | Contents |
| --- | --- |
| Google | A pre-registered list of Google Fonts |
| System | Fonts installed on your PC. Press "Load system fonts" to load them |
| Category | Fonts you sorted yourself (8-2) |

Type a name in the search box above the list and press "Search" to filter fonts.

> **Caution**
> Loading system fonts works in Chrome and Edge. The first time, the browser asks whether to allow access to your fonts; choose "Allow". In other browsers, the system font list may not appear.

> **Caution**
> Google Fonts are loaded from the internet. When offline, fonts that have not been loaded yet may not be displayed.

### Switching the preview

Switch the preview content with the tabs at the top of the center area.

| Tab | Contents |
| --- | --- |
| Basic | Samples of English, hiragana, katakana, kanji, numbers, and symbols. Choose which kinds to show with the checkboxes |
| Sentence | Example sentences in horizontal and vertical writing |
| Custom | Preview any text you type. You can set separate fonts for Japanese and English |
| Category List | Show all fonts in the selected category side by side |
| Style | Create styles and presets (8-3) |

You can also change the size and the writing direction shown (both, horizontal only, vertical only).

## 8-2 Organizing with Tags and Categories

When you have too many fonts to find what you want, organize them with tags and categories. Select a font in the list on the left and its name appears on the right.

### Categories

A category is like a "shelf" for fonts. If you sort fonts into categories such as "handwritten", "dialogue", and "sound effects", you can also choose from those categories in the Layout tab.

1. Press "+ Category" on the right and enter a name to create a category.
2. Select a font in the list on the left.
3. Choose the category in the drop-down on the right and press "Add".

Press "Remove" to take a font out of a category, and "- Category" to delete the category itself.

### Tags

A tag is a note-like label attached to a font. Type a tag in "Add Tag" to attach it to the selected font. Tags you have used before appear in a list, so you can click to attach them.

## 8-3 Creating Styles and Presets

### Styles vs. presets

| Name | Contents | Use |
| --- | --- | --- |
| Style | Text appearance (fill, stroke, outline, shadow, etc.). No font included | Looks you use with any font, such as "red outline" or "with shadow" |
| Preset | Font + size + vertical or not + style | Text you always set up the same way, such as "dialogue" or "sound effect" |

### Creating a style

1. Open the "Style" tab in the center.
2. Type the text to check in "Preview text:".
3. Set fill, stroke, outline, shadow, and so on. The items are the same as the "Style" window in the Layout tab (Chapter 7, 7-2).
4. Enter a name and press "Save".

| Item | Description |
| --- | --- |
| Fill | Solid, gradient, or texture. Uncheck for no fill |
| Stroke | The outline of the characters |
| Bold, italic, underline | Text decoration |
| Line height, vertical position, alignment | How multiple lines are arranged |
| Outline | A thick border around the outside of the text |
| Shadow | Shadow color, blur, and position (X, Y) |

Choose a saved style from "Saved" to load and edit it.

| Operation | Result |
| --- | --- |
| "Save" without changing the name | Overwrites it |
| "Save" with a new name | Saves as a separate style, leaving the original unchanged |
| "New" | Clears the fields to start a new one |
| "Delete" | Deletes the selected style |

### Creating a preset

1. Select the font to use in the list on the left.
2. In the "Presets" section below the "Style" tab, set "Size (pt)", whether it is vertical, and the style to use.
3. Enter a name and press "Save".

The operations (choose from Saved, save under a new name, delete) are the same as for styles.

## 8-4 Using Your Styles

### In the Layout tab

Saved styles and presets appear as sample images (thumbnails) in the "F" tab of the Layout tab's asset panel.

| Situation | Clicking a thumbnail |
| --- | --- |
| No text selected | Inserts new text in the center of the selected panel |
| Text selected | Applies the style (or preset) to that text |

Use "Background" above the thumbnails to change the sample background (Default, Black, White, Gray, Manual). Switch it when a style such as white text is hard to see.

> **Tip**
> Style thumbnails are all shown in the same font (Zen Antique) so the looks are easy to compare. Preset thumbnails are shown in their registered font.

### Directly from the Font tab

"Apply to selected text" on the right applies the chosen font to the text selected in the Layout tab.

### Setting the default font for Auto

"Set as default font" in the "Auto Layout" section on the right makes the selected font the default font for Auto Layout in the Auto tab (Chapter 11). It is saved immediately, without confirmation.

> **Tip**
> When exporting, the fonts you used are embedded in the file automatically (SVG, PNG, etc.), so the text looks the same even on PCs without those fonts.

> **Chapter summary**
> - Choose a font on the left and preview it in the center. For system fonts, use "Load system fonts" in Chrome or Edge
> - Sorting fonts into categories such as "dialogue" and "sound effects" makes them easy to find in the Layout tab too
> - Style = appearance only; preset = font + size + style
> - Saved styles can be used with one click from the asset panel's "F" tab
