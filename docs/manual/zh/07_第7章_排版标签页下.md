# 第7章 排版标签页（下）：对话气泡、文字、绘制

本章介绍对话气泡与台词、文字、图形与涂绘、蒙版，以及漫画风格效果的添加方法。

如果你只想给一张图像加字，读完 7-1、7-2，就可以给放在页面上的图像加上标题或台词。

## 7-1 对话气泡

使用工具栏中的“对话框”放置对话气泡并调整形状。基本的放置方法已在第4章 4-5 中介绍过。

### 对话气泡的类型

可以选择的对话气泡有以下7种。

| 类型 | 适合的场景 |
| --- | --- |
| 普通（椭圆） | 普通的对话 |
| 圆角矩形 | 平静的对话、说明 |
| 标题框（直角、无尾巴） | 旁白、地点或时间的说明 |
| 思考（气泡） | 内心独白（尾巴变成小气泡） |
| 爆炸 | 喊叫、惊讶 |
| 云 (蓬松) | 内心独白、轻柔的台词 |
| 云 (波浪) | 不安、动摇的心情 |

### 放置、调整

1. 点击选择要放对话气泡的分格。
2. 选择类型，点击“插入”。对话气泡会放在分格中央。
3. 用控制点改变大小，拖动来移动位置。

| 项目 | 内容 |
| --- | --- |
| 编辑：ON／OFF | ON 期间可以移动对话气泡或改变形状。插入后会自动变为 ON |
| 颜色 | 对话气泡内部的颜色 |
| 边框 | 对话气泡边框线的颜色 |
| 尾巴：角度、长度、宽 | 尾巴的方向、长度、根部粗细 |
| 无尾巴 | 勾选后去掉尾巴。取消勾选后恢复原来的长度 |

拖动8个圆形控制点时，只有被抓住的一侧会伸缩（另一侧不动）。

不同类型还会额外显示以下调整项目。

| 类型 | 额外的项目 |
| --- | --- |
| 爆炸 | 种子（尖刺的排列方式）、尖刺数、长度、随机度、内侧弧度（让尖刺之间的凹处变圆） |
| 思考 | 气泡大小、数量、间距（主体与气泡的距离） |
| 圆角矩形 | 圆角（角的圆润程度） |
| 云 | 种子、数量、凹凸、随机度 |

> **提示**
> 爆炸和云的“种子”是形状图案的编号。改变数字后，在设置不变的情况下只有形状会改变。可以多试几次，直到得到满意的形状。

### 添加台词

选中对话气泡并点击“内嵌文字”，会打开“内嵌文字”界面（第4章 4-5）。

| 项目 | 内容 |
| --- | --- |
| 文字 | 台词。可以换行 |
| 字号、行距 | 文字的大小和行的间距 |
| 竖排 | 勾选后竖排 |
| 文字颜色 | 黑、白、红、蓝 |
| 粗体 | 勾选后为粗体 |
| 上下（左右）、对齐 | 文字在对话气泡中的位置。横排为上下和左右，竖排为左右和上下 |
| 字体 | 从 Google／系统／类别 3个标签中选择 |

台词会按对话气泡的大小自动换行。对话气泡本身的大小不会改变，文字溢出时，请用控制点把对话气泡拉大。放入的台词可以通过双击对话气泡来修改。

### 拖动移动台词的位置

选中带台词的对话气泡后，文字周围会出现紫色虚线框，其左下角显示一个小三角形角标。

| 操作 | 作用 |
| --- | --- |
| 拖动三角形角标 | 对话气泡保持不动，只移动台词的位置（旋转过的对话气泡中，会沿对话气泡的方向移动） |
| 双击三角形角标或对话气泡 | 与以前一样，打开台词输入界面 |

> **注意**
> 在输入界面中修改“上下”或“对齐”后，拖动移动的距离会被重置，以对齐位置为准。

> **提示**
> 爆炸和云的轮廓凹凸不平，因此文字可放入的范围会比形状小一圈。

### 延长气泡：拆分较长的台词

可以把较长的台词拆分到2个以上相连的对话气泡中。

1. 选择作为基础的对话气泡。
2. 点击“添加延长气泡”。会添加一个形状、颜色相同的对话气泡，并通过收窄的连接部分（颈部）相连。
3. 把添加的对话气泡移到合适的位置，用“内嵌文字”输入台词的后续部分。

| 行为 | 内容 |
| --- | --- |
| 移动原对话气泡 | 延长气泡也会一起移动 |
| 移动延长气泡 | 只有颈部会伸缩 |
| 线条 | 重叠部分不显示线条，只有整体外侧是一条线 |
| 删除 | 只删除延长气泡时，原对话气泡保留。删除原对话气泡时，延长气泡也会一起删除 |

### 把对话气泡转换为图像

点击“转换为图像”，会把所选对话气泡转换为 PNG 图像，并以相同的位置、相同的大小添加。原对话气泡会保留，不需要的话请删除。

## 7-2 文字

不使用对话气泡、只放置文字时，使用工具栏中的“文字”。可用于标题、拟声词、手写风格的文字等。

### 放置文字

1. 点击工具栏中的“文字”。
2. 选择字体、“竖排”（是否竖排）、“颜色”。
3. 点击“T”按钮，进入可以放置文字的模式。
4. 在预览中点击要放置文字的位置。会打开“文字输入”界面。
5. 输入文字后点击 OK。可以换行。

放置的文字双击后可以重新输入。

### 改变文字的大小、形状

点击文字后，周围会显示边框和控制点。

| 操作 | 方法 |
| --- | --- |
| 移动 | 拖动文字 |
| 文字大小 | 拖动角上的绿色控制点（被拖动角的对角会固定，按相对于该点放大、缩小的量决定大小） |
| 拉长、压扁 | 拖动边中央的蓝色控制点 |
| 斜向倾斜 | 按住 Shift 键拖动边上的蓝色控制点 |
| 恢复拉伸、倾斜 | 点击“重置变形” |
| 竖排⇔横排 | 选中文字，切换“竖排”的勾选 |

> **提示**
> 竖排主要用于日文漫画。中文的标题或拟声词通常使用横排，但想营造特殊效果时也可以使用竖排。

### 字体的选择

| 标签 | 内容 |
| --- | --- |
| Google | Google Fonts 的字体（与字体标签页共用的列表） |
| 系统 | 电脑中安装的字体 |
| 类别 | 在字体标签页中分类的字体（第8章） |

列表中没有出现字体时，点击“重新加载”。

> **提示**
> 要使用中文字体，可以在“系统”中选择电脑中已安装的中文字体（例如微软雅黑、思源黑体等），或者在 Google 标签中选择 Noto Sans SC 等支持简体中文的字体。

### 样式：勾边字、阴影、渐变

点击“样式”，会打开详细设定文字外观的界面。

| 项目 | 内容 |
| --- | --- |
| 填充 | 文字的颜色。从单色、渐变、纹理（图像图案）中选择。取消勾选则无填充 |
| 描边 | 文字的轮廓线 |
| 勾边字 | 在文字外侧加上粗边（漫画的拟声词和标题中常用） |
| 阴影 | 文字的阴影 |
| 粗体、斜体、下划线 | 文字的装饰 |
| 行距、上下位置、对齐 | 多行文字的排列方式 |

一边看预览一边调整，选中文字时会立即应用到该文字上。未选中文字时，会作为新文字放到所选分格的中央。

> **提示**
> 制作的样式可以保存，并与字体标签页的“样式”列表共用。保存的样式可以从素材面板的“F”标签中一键使用（第8章）。

> **提示**
> 描边、勾边字、阴影的粗细是按相对于文字大小的比例记录的。即使之后把文字放大，外观的比例也不会改变。

### 其他按钮

| 按钮 | 内容 |
| --- | --- |
| 文字→PNG | 把所选文字转换为 PNG 图像 |
| Insert | 打开“插入文字”界面。插入来源可选择“脚本（情节中选中的单元格）”或“OCR（OCR标签页检测到的文字）”，以文字形式放入（见下方提示框、第10章 10-8、第11章） |

> **提示**
> 选择“OCR”后，OCR 标签页读取的文字会放到读取时框的位置。字号可选择“根据区域大小自动换算”或“指定字号”，文字方向可从“根据框的形状自动判断”“横排”“竖排”中选择。文字会逐个放入覆盖层，撤销时会一次性取消插入的全部文字。

## 7-3 绘制图形、涂绘（绘图）

工具栏的“绘制”上方有4种模式。

| 模式 | 能做的事 |
| --- | --- |
| 绘制 | 绘制矩形、圆形、直线等图形（之后可以修改形状和颜色） |
| 绘画 | 用画笔自由绘画 |
| SVG改色 | 修改从素材中放入的 SVG 图像的颜色 |
| SVG→PNG | 把 SVG 图像转换为 PNG 图像 |

### 绘制：绘制图形

1. 点击选择要绘制图形的分格。
2. 在“绘制”模式中选择要绘制的形状。
3. 把“绘制”设为“ON”，在分格内拖动。

把“绘制”设为“OFF”后，可以选中绘制的图形进行移动或修改形状。

| 形状 | 绘制方法 |
| --- | --- |
| 矩形、椭圆、直线 | 拖动。矩形可以用“圆角”把角变圆 |
| 曲线 | 按拖动的轨迹绘制自由线条 |
| 多边形 | 点击依次添加角，点击起点附近闭合 |
| 矢量曲线 | 点击依次添加点，用平滑的曲线连接。点击起点附近闭合。按 Enter 键则不闭合直接结束 |
| 锁链、绳索 | 沿拖动的轨迹绘制锁链、绳索图案 |
| My曲线 | 把“选择图像”中选择的图像沿拖动的轨迹排列（一开始就带有默认图像） |

多边形和矢量曲线可以按 Esc 键取消上一个点。

| 项目 | 内容 |
| --- | --- |
| 填充 | 从单色、渐变、纹理（图像图案）中选择。选“无”则无填充 |
| 描边 | 线条的颜色和粗细。选“无”则无线条 |
| 不透明度 | 透明程度 |
| 图形转PNG | 把所选图形转换为 PNG 图像，并添加到相同位置 |

选中图形时修改填充或描边，会立即应用到该图形上。未选中时，会成为下一个绘制图形的设置。

### 绘画：用画笔绘画

1. 选择要绘画的分格（或覆盖层、草稿）。
2. 在“绘画”模式中点击“添加绘画”。会添加一张与分格同样大小、用于绘画的透明图像，并立即进入可以绘画的状态。
3. 设定“画笔颜色”“大小”“不透明度”，拖动进行绘画。

| 项目 | 内容 |
| --- | --- |
| 背景色 | 勾选并选择颜色后，会添加一张用该颜色填充（而不是透明）的图像 |
| x5 | 开启（橙色）后，画笔粗细变为5倍 |
| 橡皮擦 | 开启（红色）后，擦除绘制的部分 |
| 统合选中图像 | 把在图层面板中勾选的图像、绘画合并为一张图像 |

使用数位板时，粗细和浓淡会随笔压变化。画笔不仅可以在绘画用的图像上绘画，也可以直接在放入分格的普通图像上绘画。

> **提示**
> 绘画也可以用来制作在 Workflow Studio 中进行 I2I（以图生图）时的草图或参考图像。以透明状态发送时，有些生成模型会把透明部分当作黑色处理。把“背景色”设为白色会更放心（第10章）。

### SVG改色、SVG→PNG

从素材中放入的 SVG 图像，可以修改颜色或转换为 PNG 图像。

| 模式 | 用法 |
| --- | --- |
| SVG改色 | 选中 SVG 图像，点击“提取颜色”→ 为每种颜色重新选择颜色，然后点击“应用更改” |
| SVG→PNG | 选中 SVG 图像，输入宽、高（留空则为原尺寸），点击“转换为PNG并插入” |

## 7-4 蒙版：只隐藏、只显示一部分

使用蒙版，可以像橡皮擦一样隐藏图像或分格的一部分。原图不会被删除，之后可以反复修改。

### 蒙版的类型

| 类型 | 作用 |
| --- | --- |
| 隐藏蒙版（涂抹处被隐藏） | 用画笔涂抹的地方会看不见 |
| 显示蒙版（仅显示涂抹处） | 只有用画笔涂抹的地方可见 |

### 添加蒙版

1. 选择要添加蒙版的图像（或分格、覆盖层）。它会显示在“对象”中。
2. 点击工具栏中的“蒙版”，选择蒙版类型。
3. 把“编辑”设为“ON”。
4. 设定画笔的“大小”“硬度”，拖动涂抹想隐藏（或想显示）的地方。

| 项目 | 内容 |
| --- | --- |
| 画笔：涂抹／擦除 | 涂抹＝增加蒙版，擦除＝减少蒙版 |
| 以红色显示隐藏部分 | 用半透明红色显示被隐藏的地方 |
| 应用蒙版 | 取消勾选后，蒙版暂时失效（想对比时使用） |
| 反转 | 互换涂抹和未涂抹的地方 |
| 清除 | 清除所有涂抹 |
| 全面涂抹 | 涂抹整体 |
| ＋添加图层／删除图层 | 一个对象上可以叠加多层蒙版 |

> **提示**
> 想让图像边缘变模糊时，先降低“硬度”再涂抹，边界就会变柔和。

## 7-5 添加漫画风格的效果

漫画风格的效果位于2个地方。

| 位置 | 按钮 | 能做的事 |
| --- | --- | --- |
| 工具栏的“图像” | 🎨 网点 | 把图像转换为网点，或生成网点图案 |
| 工具栏的“漫画” | ✨ 漫画效果 | 暗角（四周变暗）、网屏纸质噪点、集中线 |
| 工具栏的“漫画” | 🎴 背景图案 | 条纹、圆点、和风纹样等背景图案 |

无论哪个，点击按钮后都会打开带预览的界面。在预览上用“选中的图像／默认／白色”切换背景，可以确认实际叠加时的效果。

### 网点（半色调）

| 模式 | 内容 |
| --- | --- |
| 转换图像 | 把所选图像替换为网点图像。可用亮度、对比度、二值化、最小浓度调整色调 |
| 生成图案 | 只生成网点图案，大小与所选分格（或覆盖层）相同。可以像贴网点纸一样使用 |

不选择图像、只选择分格时打开，会以“生成图案”模式打开。

| 共同项目 | 内容 |
| --- | --- |
| 颜色模式 | 黑白／双色（油墨色和纸张色2种颜色） |
| 网点形状 | 圆点、线条、方形、十字 |
| 网点尺寸、角度、覆盖率 | 网点的大小、方向、密度 |
| 明暗反转 | 互换网点的深浅 |
| 浓度、渐变 | （生成图案）整体的浓度，以及逐渐变淡的网点 |
| 背景透明 | （生成图案）把没有网点的地方变为透明 |

### 漫画效果：暗角、网点噪点、集中线

生成一张与所选分格（或覆盖层）大小相同的透明效果图像，用“添加到分格”放入。

| 效果 | 内容 |
| --- | --- |
| 暗角 | 让四周变暗，把视线引向中心。也可以选择颜色 |
| 网屏纸质噪点 | 纸张般的颗粒感。用“颗粒大小”调整 |
| 集中线 | 从放射状、海胆闪、海胆（环）、线性（流线）中选择 |

集中线的主要项目如下。

| 项目 | 内容 |
| --- | --- |
| 密度 | 线条的多少 |
| 范围、长度 | 中心空白的大小。数值越大，线条越靠近中心 |
| 外框侧粗细 | 线条根部的粗细。调大后线条会连在一起，像涂黑一样 |
| 中心X、中心Y | 集中线中心的位置（放射状、海胆） |
| 外侧长度 | 尖刺向外延伸的长度（海胆） |
| 角度 | 流动的方向（线性） |

> **提示**
> 把海胆闪的颜色设为白色，就能表现灵光一闪或惊讶的“闪光”效果。

添加的效果可以像普通图像一样，在图层面板中移动、修改不透明度或删除。

### 背景图案

生成一张与所选分格（或覆盖层）大小相同的图案图像。

| 图案 | 种类 |
| --- | --- |
| 条纹 | 横条纹、竖条纹、斜条纹 |
| 图形 | 圆点、格纹 |
| 和风纹样 | 麻叶纹、市松纹（棋盘格）、七宝纹（连环圆）、鳞纹 |
| 自定义SVG | 排列自己准备的 SVG 图像（标志等） |

可以指定颜色、不透明度、尺寸（图案重复的间隔）、旋转。取消勾选“透明背景”后，图案会用背景色填充。

> **本章小结**
> - 对话气泡有7种。用“内嵌文字”放入台词，较长的台词用“添加延长气泡”拆分
> - 只放文字时，打开“文字”的“T”后点击。用“样式”设置勾边字、阴影、渐变
> - 用“绘制”画图形，用“绘画”以画笔绘画。支持数位板笔压
> - 用“蒙版”隐藏、显示图像的一部分。原图不会被删除，可以反复修改
> - 网点在“图像”中，集中线、暗角、背景图案在“漫画”中
