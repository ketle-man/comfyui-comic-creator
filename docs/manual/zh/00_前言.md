# 前言

本书是 ComfyUI 自定义节点“ComfyUI Comic Creator”（以下简称 Comic Creator）的入门指南，面向初次使用的读者，按步骤讲解其使用方法。

Comic Creator 是一款在 ComfyUI 中运行的漫画制作应用。从在分好格的页面上排列图像、添加对话气泡和台词，到导出为图像或 PDF、EPUB，全部都可以在浏览器的一个界面中完成。

## 本书的目标读者

- **想用 ComfyUI 制作漫画的人**
  希望把 ComfyUI 生成的图像，整理成带有分格、对话气泡、台词的漫画页面的人。
- **想对图像进行加字等编辑的人**
  即使没有画漫画的打算，也想给一张图像加上标题或台词，或者叠加图层进行加工的人。

不需要有漫画制作经验，也不需要了解图像编辑软件。只要能启动 ComfyUI，就可以继续阅读本书。

> **提示**
> 如果你只想给一张图像加字或编辑图像，建议先通过第4章“制作第一页”了解整体流程，然后重点阅读第7章（对话气泡、文字）和第9章（Image 标签页）。

## Comic Creator 的特色

- **从制作页面到导出，在一个界面中完成**
  作品管理、分格、图像排布、对话气泡与台词、最终效果、导出，全部无需切换应用即可完成。
- **可以直接使用 ComfyUI 生成的图像**
  只需将 ComfyUI 的输出图像拖放到分格中即可完成排布。与 Workflow Studio 配合使用时，还可以一边看页面一边当场重新生成图像。
- **竖排台词与漫画风格的对话气泡**
  提供竖排、横排文字，椭圆、思考、爆炸、云朵等对话气泡，以及半色调（网点）等漫画表现手法。
- **支持图层编辑的图像编辑器**
  “Image”标签页是一个具备图层、绘制、蒙版、滤镜功能的图像编辑器，也可用于漫画以外的图像加工。
- **用 AI 从脚本生成页面**
  “Auto”标签页可以根据题目生成故事和脚本，并自动完成分格（需要准备 AI）。
- **支持多种导出格式**
  可以导出为 JPEG、PNG、WebP、SVG、PDF、EPUB。导出所需的库已随应用附带，即使没有联网也能导出。
