# 第11章 从脚本开始制作：脚本标签页与 Auto

本章将为示例作品“猫咖啡馆的早晨”编写脚本，并把台词和对话气泡填入页面。

## 11-1 两种方法

| | 脚本标签页 | Auto 标签页 |
| --- | --- | --- |
| 编写脚本的人 | 自己 | AI（自己修改生成的结果） |
| AI | 没有也能用 | 需要本地 LLM（Ollama 等）或 Gemini。不过“示例”无需 AI 也能试用 |
| 分格 | 填入事先在排版标签页中插入了模板的页面 | 根据脚本自动生成 |
| 结果 | 在现有作品的页面中放入对话气泡和台词 | 作为新作品，生成带有分格、对话气泡的页面 |

想给第10章制作的作品添加台词时使用脚本标签页（11-2、11-3），想根据脚本一次性生成时使用 Auto（11-4〜11-6）。

## 11-2 在脚本标签页中编写脚本

### 创建作品

1. 打开“脚本”标签页。
2. 点击“新建”。
3. 在“作品名”中输入 `猫咖啡馆的早晨`，在“媒体类型”中选择“漫画”。

> **注意**
> 媒体类型在创建后无法更改。“漫画”和“半自动漫画”是同一个界面，只是保存的数据彼此独立。“小说”“脚本”在 v1.59.0 中仍在开发中，无法使用情节界面。

> **提示**
> 在左侧素材面板“S”的“页面作品”中，先点击页面标签页中的作品名，再点击“新建”，该名称就会填入作品名。

### 登记登场人物（要素）

在“要素”子标签页中登记登场人物或专有名词后，在情节中只需选择即可输入。

1. 打开“要素”子标签页，点击“＋ 添加要素”。
2. 在要素中输入 `三花`，在详情中输入 `三花猫店员。做事可靠，但早上起不来` 之类的内容。
3. 用同样的方法登记 `客人`。

右侧的栏中可以写整部作品的梗概。

### 编写情节

在“情节”子标签页中，按页面、按分格编写脚本。

| 列 | 要写的内容 |
| --- | --- |
| 场景 | 该页面中发生的事（跨该页的所有行显示） |
| 分格号 | 分格的编号 |
| 图像提示词 | 对该分格画面的描述（用于图像生成） |
| 台词号 | 分格中台词的编号 |
| 要素 | 说话的人。可以从登记的要素名称中选择（也可自由输入） |
| 台词/说明等 | 台词，或分格的情况说明 |
| 对话气泡形状 | 默认、普通（椭圆）、圆角矩形、思考（气泡）、爆炸、云（蓬松）、云（波浪） |

示例的第1页可以这样写。

| 分格 | 要素 | 台词 | 对话气泡形状 |
| --- | --- | --- | --- |
| 1 | （旁白） | 开店前30分钟 | 圆角矩形 |
| 2 | 三花 | 呼啊…今天也要加油喵 | 普通（椭圆） |
| 3 | 三花 | 诶！？客人已经来了！？ | 爆炸 |

| 操作 | 方法 |
| --- | --- |
| 切换页面 | ◀ ▶ |
| 添加、删除页面 | “＋ 添加页面”／“删除页面” |
| 改变分格数 | “分格数”的 ▲ ▼（初始为4格） |
| 让分格数与排版一致 | “从排版获取”。与排版标签页中当前显示页面的分格数一致 |
| 添加、删除台词行 | 点击选择行，然后点击台词的“＋”“−” |

> **提示**
> 点击“图像提示词”旁边的“L”按钮，会使用 Workflow Studio 的 AI 设置（Ollama 等），根据场景和台词生成图像提示词的方案。

### 保存

输入作品名后点击“保存”。保存的作品可以从素材面板“S”的“已保存作品”中选择，然后点击“读取”打开。

在“预览 横”“纵向预览”子标签页中，可以以易读的文章形式确认所有页面的脚本。

> **注意**
> 脚本作品保存在浏览器中。也包含在备份（第13章）中。

## 11-3 将脚本填入页面

根据脚本标签页中的脚本，自动在排版标签页的页面中放入对话气泡和台词。

1. 在“排版”标签页中，显示作品“猫咖啡馆的早晨”的第1页（事先插入模板）。
2. 回到“脚本”标签页，显示情节的第1页。
3. 点击“从排版获取”，让分格数与排版的页面一致。
4. 点击“将此页流式填入版面”。会以列表显示各分格号的对应关系。
5. 点击“自动生成对话气泡”。在有台词的分格中，会按台词数量生成对话气泡，并切换到排版标签页。

对话气泡的形状按“对话气泡形状”列的设置生成，保持“默认”的行为圆角矩形。对话气泡和文字的大小会根据台词量自动决定。之后用第7章的方法调整位置和形状即可。

> **注意**
> 分格的对应关系只按分格编号的顺序决定。脚本和页面的分格数不同时会显示警告，只按较少的一方对应。请先用“从排版获取”使两者一致。

> **提示**
> 台词默认横排。中文漫画一般为横排，保持即可；如果需要竖排，请在排版标签页中修改文字的设置（第7章）。

### 一次性生成图像

脚本标签页中还有根据各分格的“图像提示词”一次性生成图像的按钮。

| 按钮 | 使用的东西 |
| --- | --- |
| 批量生成图像（T2I） | Workflow Studio（根据文字生成） |
| 批量生成图像（I2I） | Workflow Studio（以当前图像为基础重新生成） |
| 批量生成图像（Nanobanana） | Nanobanana（第10章） |

> **注意**
> 使用 Workflow Studio 的功能，使用的是嵌入在 Comic Creator 中“workflow studio”标签页里的 Workflow Studio。即使在浏览器的其他标签页中打开 Workflow Studio 并切换工作流，也不会生效。

## 11-4 Auto 的准备

在“Auto”标签页中，AI 会根据题目生成故事和脚本，还会自动完成分格。

### 设置 AI 引擎

1. 打开“Auto”标签页，选择右侧窗格中的“设置”标签。
2. 在“AI引擎”中选择“本地LLM”或“Gemini”。
3. 设置必要的项目，点击“保存设置”。

| AI 引擎 | 要设置的内容 |
| --- | --- |
| 本地LLM | BACKEND（Ollama／LM Studio／Lemonade／Unsloth）、URL、MODEL。可以用“连接测试”确认 |
| Gemini | Gemini 模型。API 密钥与 Nanobanana 共用（`.env` 中的 `NANOBANANA_API_KEY`） |

> **注意**
> 本地 LLM 的 URL，请与打开 Comic Creator 的地址保持一致。如果用 `127.0.0.1` 打开，就设为 `http://127.0.0.1:11434`（Ollama 的情况）。与 `localhost` 混用时，可能会被浏览器拦截，出现“Failed to fetch”。

> **注意**
> Gemini 会按使用量收费。

> **提示**
> 即使没有准备 AI，也可以用 11-5 中的“示例”把 Auto 的流程完整试一遍。

## 11-5 用 Auto 生成故事和脚本

### 生成故事

1. 在“故事・脚本”子标签页中，点击“输入主题・提示词”。
2. 输入主题和页数，点击“创建”。

   ```
   主题：开店前的猫咖啡馆里，三花猫店员三花正在做早上的准备，客人却提前到了，一部温馨的喜剧
   页数：2
   ```

3. 中央的“故事”标签中会生成标题、登场人物、梗概、页面分配。也可以直接修改。

> **提示**
> 没有 AI 时，在主题界面中点击“示例”。会使用预设的主题（宇航员柴犬的故事），立即读取故事和2页的脚本。

> **提示**
> AI 会被指示用“设置”标签页中所选的显示语言编写故事和脚本。把显示语言设为“中文”，就会生成中文的故事和脚本。

### 生成脚本

1. 在中央的“脚本”标签中，点击“根据故事创建脚本”。
2. 会以页面 → 分格 → 台词的形式生成脚本。

| 分格的项目 | 内容 |
| --- | --- |
| 重要度 | 高、中、低。用于在自动布局中决定分格的大小 |
| 背景描写、演技指示 | 对该分格画面的描述（可作为草稿的指引，也可用作图像生成的提示词） |
| 台词 | 说话人、正文、对话气泡的类型 |

页面、分格、台词也可以添加或删除。

> **提示**
> 即使 AI 的输出格式混乱，也会在可读取的范围内还原脚本。不顺利时，打开“LLM原始输出”确认内容，然后重新生成。

### 用 Chat 商量

在右侧窗格的“Chat”标签中，可以就故事或脚本向 AI 咨询。

| 功能 | 内容 |
| --- | --- |
| 将当前故事、脚本作为上下文 | 开启后，会结合正在编辑的内容进行回答 |
| 工具 | 将故事转为脚本／台词润色／整理故事／创建角色设定 |
| 回复下方的按钮 | “应用到故事”“应用到脚本”“转到图像提示词”“复制” |
| 撤销应用 | 恢复到应用之前的状态（最多10次） |

例如：发送“让三花的台词更像猫一点”，然后把回复“应用到脚本”。

### 保存

在上方的工作栏中输入作品名，点击“保存”。正在编辑的内容也会自动保存。

## 11-6 用自动排版生成页面

在“自动布局”子标签页中，根据脚本生成分格，并发送到排版标签页。

### 生成分格

1. 打开“自动布局”子标签页。
2. 在左侧的“页面设置”中，确定尺寸、样式、阅读顺序、边距。
3. 点击“生成（全部页面）”。会生成脚本所有页面的分格。

| 项目 | 内容 |
| --- | --- |
| 样式 | 均衡／非对称／斜线接缝／单列／单行 |
| 阅读顺序 | 从右到左（日本漫画）／从左到右 |
| 格间距、外侧边距 | 分格之间的间隙，以及页面外侧的留白 |

分格的大小由脚本的“重要度”决定。非对称、斜线接缝每次点击排列都会变化，可以反复点击直到满意。

> **提示**
> 中文漫画通常按从左到右阅读。制作中文作品时，请在“阅读顺序”中选择“从左到右”。

> **提示**
> 想使用自己的模板时，在页面标签页的模板中点击“发送到自动布局”，然后在左侧的“模板”标签中点击，分配给页面。

### 手动修改

| 操作 | 方法 |
| --- | --- |
| 分割分格 | 用中央的“分割(纵)”“分割(横)”工具点击分格 |
| 修改台词 | 选中分格，在右侧属性中选择台词并点击“修改”，用“添加”增加 |
| 放入图像 | 在右侧属性中输入描述，点击“生成并分配” |

在左侧的“详细设置”中，可以设定对话气泡文字的默认字体、默认字号、分格边框宽度（也可以用字体标签页的“设为默认字体”修改）。

### 发送到排版标签页

点击“详细编辑（转移到布局标签）”。

- 会创建一个名为“Auto 的作品名＋日期时间”的新作品，并放入所有页面
- 分格、对话气泡、台词、分配的图像会成为页面
- 对话气泡会放在图像的前面
- 会自动切换到排版标签页

之后用第6〜7章的方法放入画面、调整对话气泡，完成作品。使用第10章“Generate”中的“从Auto获取”，可以把脚本的“背景描写・演技指示”用作各分格的图像提示词。

> **提示**
> 在“设置”标签中启用“决策模型”后，AI 会根据台词推断对话气泡的形状（普通、心声、呐喊、旁白）以及分格的重要度。决策模型的连接目标使用 Workflow Studio 的设置。

> **本章小结**
> - 自己写就用脚本标签页，让 AI 写就用 Auto
> - 在脚本标签页中依次执行“从排版获取”→“将此页流式填入版面”→“自动生成对话气泡”
> - Auto 在“设置”中选择 AI。没有 AI 也可以用“示例”试用流程
> - Auto 的顺序是 故事 → 脚本 → 自动布局 →“详细编辑（转移到布局标签）”。转移后会生成新作品
