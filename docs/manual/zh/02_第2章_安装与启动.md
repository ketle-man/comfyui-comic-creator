# 第2章 安装与启动

本章将把 Comic Creator 安装到 ComfyUI 中，并打开它的第一个界面。

## 2-1 需要准备的东西

| 需要的东西 | 说明 |
| --- | --- |
| ComfyUI | 请准备好可以启动的 ComfyUI。本书不介绍其安装方法 |
| 浏览器 | Chrome、Edge 等。Comic Creator 会在浏览器的新标签页中打开 |
| 网络连接 | 安装时需要。安装后的基本操作和导出可以离线使用 |

### ComfyUI 文件夹的位置

本书将 ComfyUI 的文件夹写作 `ComfyUI/`。请根据你的环境进行替换。

| 环境 | 相当于 `ComfyUI/` 的文件夹示例 |
| --- | --- |
| 便携版（Windows） | `ComfyUI_windows_portable/ComfyUI/` |
| ComfyUI Desktop | 安装时选择的文件夹（`custom_nodes` 文件夹所在的位置） |
| Stability Matrix | `StabilityMatrix/Data/Packages/ComfyUI/`（因设置而异） |
| 用 git 安装 | 执行 `git clone` 的文件夹 |
| 秋叶整合包等其他整合包 | 整合包中 `custom_nodes` 文件夹所在的 ComfyUI 文件夹 |

无论哪种环境，自定义节点都放在 `ComfyUI/custom_nodes/` 中。

## 2-2 用自定义节点管理器安装

ComfyUI 中有一个可以搜索并安装自定义节点的“自定义节点管理器（Nodes Manager）”。这是最简单的方法。

1. 启动 ComfyUI，点击界面右上角的“管理扩展功能（Manage extensions）”按钮（拼图形状的图标）。
2. 会打开“自定义节点管理器（Custom Nodes Manager）”界面。
3. 在搜索框中输入 `comic creator`。

4. 安装搜索结果中的“ComfyUI Comic Creator”。
5. 安装完成后，重启 ComfyUI。

> **提示**
> 上述按钮的名称和位置以 ComfyUI 前端 v1.58.5 的中文界面为准。旧版 ComfyUI 中，需要从界面上方的“Manager”按钮或“扩展（Extensions）”菜单打开。找不到时，请以鼠标悬停时显示的名称为线索查找。

> **提示**
> 如果搜索结果中出现名称相似的节点，请选择作者为“statsu”（GitHub 上为 ketle-man）的节点。

## 2-3 手动安装

如果不使用自定义节点管理器，或者无法顺利安装，可以把 Comic Creator 的文件夹放到 `custom_nodes` 文件夹中。

1. 在命令提示符（终端）中进入 `ComfyUI/custom_nodes/`。
2. 执行以下命令。
   ```
   git clone https://github.com/ketle-man/comfyui-comic-creator
   ```
   不使用 git 的话，可以从 GitHub 页面下载 ZIP 并解压，然后放到 `custom_nodes` 中。
3. 重启 ComfyUI。

放好之后，文件夹结构如下。

```
ComfyUI/
└── custom_nodes/
    └── comfyui-comic-creator/
        ├── __init__.py
        ├── py/
        ├── static/
        ├── templates/
        └── web/
```

> **注意**
> 解压 ZIP 时，有时会出现文件夹嵌套两层的情况（`comfyui-comic-creator/comfyui-comic-creator/__init__.py`）。请确保 `custom_nodes` 正下方的文件夹中直接有 `__init__.py`。

### 关于附加软件包

基本功能不需要额外的 Python 软件包。

只有“Image”标签页中打开、保存 PSD（Photoshop 格式）文件的功能，会用到名为 `psd-tools` 的软件包。用自定义节点管理器安装时会自动安装。手动安装时，请使用 ComfyUI 所用的 Python 执行以下命令。

```
pip install -r requirements.txt
```

（在 `comfyui-comic-creator` 文件夹中执行。便携版等环境请使用 ComfyUI 附带的 Python。）

即使没有安装 `psd-tools`，PSD 以外的功能也可以照常使用。

## 2-4 打开 Comic Creator

重启 ComfyUI 后，界面上方的栏（顶部栏）中会增加一个 **CC** 按钮。

1. 在浏览器中打开 ComfyUI。
2. 点击顶部栏的 **CC** 按钮。
3. Comic Creator 会在浏览器的新标签页中打开。

打开的标签页地址，是在 ComfyUI 的地址后面加上 `/ccc`。例如，如果 ComfyUI 的地址是 `http://127.0.0.1:8188`，那么 Comic Creator 就是 `http://127.0.0.1:8188/ccc`。

地址中的 `:8188` 部分称为“端口号”，因环境不同可能是别的数字（例如 ComfyUI Desktop）。只要记住 **在打开 ComfyUI 的地址后面加上 `/ccc`**，在任何环境下都能打开。

> **提示**
> 把 `/ccc` 的地址加入浏览器书签，下次就可以不经过 ComfyUI 界面直接打开（ComfyUI 需要处于启动状态）。

> **注意**
> 正如第1章所述，作品数据保存在浏览器中，并且 **按地址分别保存**。`127.0.0.1` 和 `localhost` 虽然指向同一台电脑，但会被当作不同的地址。请始终使用同一个地址打开。

## 2-5 切换显示语言

Comic Creator 的界面可以用日语、英语、中文显示。第一次打开时，会根据浏览器的语言显示（支持日语、英语、中文，其他语言时显示为日语）。

1. 打开“设置”标签页。
2. 在“语言”中选择要显示的语言（中文为“中文”）。
3. 整个界面会重新加载，并以所选语言显示。

所选语言会记录在浏览器中，下次打开时也会使用同一语言。

> **提示**
> 如果浏览器语言是中文，第一次打开时会自动以中文显示。如果显示成了日语，请按上面的步骤切换为“中文”。

## 2-6 推荐搭配的联动节点

安装以下自定义节点后，Comic Creator 的功能会增加。即使不安装，也不会影响其他功能。需要时再安装即可。

| 自定义节点 | 启用的功能 | 本书章节 |
| --- | --- | --- |
| ComfyUI-Workflow-Studio | 使用 ComfyUI 工作流的图像生成（Generate、I2I、Inpaint、Outpaint）、“workflow studio”标签页的图库显示 | 第10章 |
| comfyui-vrm-pose-editor | 3D 姿势、3D 文字 | 第12章 |
| comfyUI-particle-pixijs | PixiJS FX（粒子、滤镜效果） | 第12章 |

> **注意**
> comfyui-vrm-pose-editor 的文件夹名必须是 `comfyui-vrm-pose-editor`，否则 Comic Creator 找不到它。手动安装时请不要修改文件夹名。

与 AI 图像生成服务（Nanobanana）以及外部软件（Eagle、G'MIC）的联动设置，会在使用到的章节中分别说明。

## 2-7 无法正常启动时

| 症状 | 可能的原因 | 处理方法 |
| --- | --- | --- |
| 不显示 CC 按钮 | 没有重启 ComfyUI | 重启 ComfyUI，并刷新浏览器 |
| 不显示 CC 按钮 | 文件夹放置位置不对（嵌套两层等） | 确认是否存在 `ComfyUI/custom_nodes/comfyui-comic-creator/__init__.py` |
| 不显示 CC 按钮 | ComfyUI 的界面（前端）版本过旧 | 更新 ComfyUI。即使没有按钮，在地址后加上 `/ccc` 也能打开 |
| 打开 `/ccc` 时出现“404”等错误 | Comic Creator 没有被加载 | 查看启动 ComfyUI 时的窗口（控制台）中是否有以 `[ccc] ERROR` 开头的行 |
| 不显示以前制作的作品 | 用了不同的浏览器或不同的地址打开 | 用平时使用的浏览器和地址打开（第1章） |
| “workflow studio”标签页中显示“未找到 Workflow Studio” | 没有安装 ComfyUI-Workflow-Studio | 需要使用时，安装后重启 ComfyUI。不使用的话保持原样即可 |

> **本章小结**
> - 用界面右上角的“管理扩展功能”按钮打开自定义节点管理器，搜索 `comic creator` 并安装。手动安装则放到 `custom_nodes` 中
> - 安装后重启 ComfyUI。用顶部栏的 **CC** 按钮打开
> - Comic Creator 的地址是“ComfyUI 的地址＋`/ccc`”。请始终使用同一个地址打开
> - 语言在“设置”标签页的“语言”中切换
> - 联动节点等需要时再安装即可
