# 附录

## A 术语表

| 术语 | 含义 | 本书章节 |
| --- | --- | --- |
| 作品 | 带有宽度和高度的一组页面 | 第1章、第5章 |
| 页面 | 作品中的一页 | 第1章 |
| 模板 | 页面分格的样板 | 第4章、第5章 |
| 分格 | 页面中的格子。其中的内容会按分格形状裁切 | 第1章 |
| 子画格 | 在分格中制作的小分格 | 第6章 |
| 覆盖层 | 覆盖整个页面的前景层 | 第6章 |
| 草稿图层 | 位于最前面、用于打草稿的层。不会被导出 | 第6章 |
| stock | 存放不属于任何作品的页面、一开始就有的组 | 第5章 |
| 素材 | 可以从素材面板中放入的素材 | 第6章 |
| 对话气泡 | 放台词的气泡 | 第7章 |
| 延长气泡 | 通过收窄部分相连的后续对话气泡 | 第7章 |
| 勾边字 | 在文字外侧加上粗边的文字 | 第7章、第8章 |
| 样式 | 文字外观（填充、描边、勾边字、阴影等）的设置 | 第8章 |
| 预设 | 把字体＋大小＋样式组合在一起的设置 | 第8章 |
| 蒙版 | 用来隐藏、显示图像一部分的层 | 第7章、第9章 |
| 网点（半色调） | 网点纸那样的点状图案 | 第7章 |
| 图层 | 叠放图像或文字的层 | 第6章、第9章 |
| 调整图层 | 在不改变原图的情况下，调整下方图像亮度或颜色的层（Image 标签页） | 第9章 |
| T2I | 根据文字生成图像（Text to Image） | 第10章 |
| I2I | 以图像为基础重新生成图像（Image to Image） | 第10章 |
| Inpaint | 只用 AI 重绘图像的一部分 | 第10章 |
| Outpaint | 用 AI 在图像外侧扩展绘制 | 第10章 |
| Denoise | I2I 中，与原图相比改变的程度 | 第10章 |
| API 密钥 | 使用 Gemini 等服务所需的、自己专用的钥匙 | 第10章 |
| 本地 LLM | 在自己电脑上运行的文本生成 AI（Ollama 等） | 第11章 |
| 决策模型 | 不生成文章，而是以带概率的形式回答问题的 AI | 第11章、第10章 |
| OCR | 读取图像中的文字。在 OCR 标签页中，位置（框）也会一起获取 | 第10章 |
| bbox（框） | 图像中的矩形范围。用于 MOSS-Image 的布局和 OCR 的检测结果 | 第10章 |
| Chat TE | 可以把 ComfyUI 的文本编码器（Qwen3-VL 等）用于聊天的自定义节点。用于 OCR 的“整图识读” | 第10章 |
| 显存（VRAM） | GPU 的内存 | 第13章 |
| dpi | 每英寸的点数。表示印刷的精细程度 | 第5章 |

## B 键盘、鼠标操作

### 排版标签页

| 操作 | 作用 |
| --- | --- |
| Delete／Backspace | 删除选中的图像、对话气泡等 |
| Alt＋拖动控制点 | 改变图像的纵横比进行变形 |
| Shift＋拖动蓝色控制点 | 让文字斜向倾斜 |
| Alt＋点击图层面板的 👁 | 一次性显示／隐藏同类对象 |
| 双击（文字、对话气泡） | 重新输入文字 |
| 双击（图像） | 在 Image 标签页中打开 |
| Ctrl＋Enter | 在“文字输入”界面中确定（按 Esc 关闭） |
| Esc（多边形、矢量曲线） | 取消上一个点 |
| Enter（矢量曲线） | 不闭合直接结束绘制 |

在排版标签页中，撤销请使用操作栏的“撤销”按钮。

### MOSS-Image 标签页（排版编辑器）

| 操作 | 作用 |
| --- | --- |
| Shift＋拖动 | 任何时候都绘制新框 |
| Shift＋点击（不拖动） | 把框加入／移出当前选择（可以一起移动） |
| Delete | 删除选中的框 |
| Ctrl＋Z | 恢复删除的框 |
| Esc／Ctrl＋Enter | 确定文字框的输入 |
| 快速点击文字框两次 | 重新输入文字 |

### OCR 标签页

| 操作 | 作用 |
| --- | --- |
| Shift＋点击 | 把框加入／移出当前选择 |
| Delete | 删除选中的框 |
| Ctrl＋Z | 恢复删除的框 |
| Ctrl＋V | 粘贴并打开图像 |

### 页面标签页

| 操作 | 作用 |
| --- | --- |
| Ctrl（Mac 为 ⌘）＋点击 | 选择多个页面 |
| 双击作品卡片 | 打开作品 |

### Image 标签页

| 按键 | 作用 |
| --- | --- |
| V／B／T／S／G | 切换为 Select／Draw／Text／Shape／Fill |
| Space＋拖动 | 移动显示位置 |
| Ctrl＋Z／Ctrl＋Y | 撤销／重做 |
| Delete／Backspace | 删除选中的图层（Select 工具） |
| Enter／Ctrl＋Enter | 在文字输入框中换行／确定 |
| Esc | 停止吸管 |
| D／E | 切换为绘画／擦除（Draw 工具） |
| X | 互换颜色1和颜色2（Draw 工具） |
| [／] | 让画笔变细／变粗（Draw 工具） |

### 3D 姿势、3D 文字

| 操作 | 作用 |
| --- | --- |
| 左键拖动／右键拖动／滚轮 | 相机的旋转／平移／缩放 |
| 拖动蓝色球 | 旋转关节（Alt＋上下为 Z 轴） |
