# 第3章 界面介绍

本章说明 Comic Creator 界面中各部分的位置。无需全部记住，请把它当作迷路时回来查看的“地图”。

## 3-1 标签页一览

打开 Comic Creator 后，界面上方排列着12个标签页。第一次打开时显示的是“页面”标签页。

按作用将12个标签页分为3组，会更容易理解。

### 制作

用于制作漫画页面和图像的标签页，使用频率最高。

| 标签页 | 能做的事 | 本书章节 |
| --- | --- | --- |
| 页面 | 作品的创建、管理、模板的管理、导出（输出） | 第4章、第5章 |
| 排版 | 在页面的分格中放置图像、对话气泡、文字并进行编辑。主要的工作区 | 第4章、第6章、第7章 |
| Image | 用图层编辑图像的图像编辑器。也用于给一张图像加字 | 第9章 |
| 字体 | 查看字体，并保存文字的外观（样式） | 第8章 |

### 用 AI 制作

用 AI 生成图像或脚本的标签页。使用前需要准备 AI。

| 标签页 | 能做的事 | 本书章节 |
| --- | --- | --- |
| Nanobanana+ | 使用 Google 的 Gemini API（Nanobanana），或 Workflow Studio 的工作流（本地）生成图像 | 第10章 |
| MOSS-Image | 在自己电脑上的 ComfyUI 中，指定物体、角色、文字的位置来生成图像 | 第10章 |
| OCR | 用 AI 读取图像中的文字和位置，并传给 MOSS-Image 或排版 | 第10章 |
| Auto | 根据题目用 AI 生成故事、脚本、分格 | 第11章 |
| 脚本 | 编写并管理脚本（梗概、情节、每个分格的台词）。不使用 AI 也能用 | 第11章 |

### 辅助

辅助工作的标签页。

| 标签页 | 能做的事 | 本书章节 |
| --- | --- | --- |
| workflow studio | 显示 Workflow Studio 的图库（需要 ComfyUI-Workflow-Studio） | 第10章 |
| 设置 | 显示语言、备份与恢复、与外部软件联动的设置 | 第13章 |
| 帮助 | 应用内的说明书。可以用关键词搜索 | 本章 3-4 |

> **提示**
> 标签栏右端的“ws刷新”“在新标签页打开ws”是 Workflow Studio 用的按钮。如果不使用 Workflow Studio，可以不用理会。

## 3-2 排版标签页的界面

使用时间最长的是“排版”标签页。界面从左到右分为以下几个部分。

| 编号 | 位置 | 作用 |
| --- | --- | --- |
| ① | 素材面板（最左侧） | 图像素材、页面、模板等的列表。从这里选择并放入页面 |
| ② | 工具栏（①的右侧） | 切换“对话框”“文字”等工具的纵向按钮列 |
| ③ | 操作栏（上方） | 翻页、保存、选择分格等，任何工具都会用到的操作 |
| ④ | 工具设置（③的下方） | 在②中选择的工具的设置项目 |
| ⑤ | 预览（中央） | 正在编辑的页面。直接在这里点击、拖动进行编辑 |
| ⑥ | 图层面板（最右侧） | 页面中的分格、图像、对话气泡等的列表与叠放顺序 |

### ① 素材面板

素材面板上方排列着用一个英文字母表示的标签。把鼠标移上去会显示名称。

| 标签 | 名称 | 内容 |
| --- | --- | --- |
| A | 素材 | 图像素材和组素材。用“插入到分格”放入当前选中的分格 |
| P | 页面 | 页面缩略图列表 |
| T | 模板 | 分格模板列表。用“作为页面插入”生成新页面 |
| F | 字体 | 在字体标签页中制作的样式、预设 |
| I | Image | 在 Image 标签页中保存的图像项目 |

列表不是最新时，点击右上角的“↺”（刷新素材列表）。

“页面”标签页中不显示素材面板。“Image”标签页中只显示 A、F、I，“脚本”标签页中只显示 S（已保存作品、页面作品）。

### ② 工具栏

工具栏只在排版标签页中显示。点击按钮后，④的设置会随之切换。

| 按钮 | 用途 | 本书章节 |
| --- | --- | --- |
| 对话框 | 放置对话气泡 | 第7章 |
| 文字 | 放置文字 | 第7章 |
| 绘制 | 绘制图形或线条、涂绘 | 第7章 |
| 图像 | 去除背景等图像处理、半色调、PixiJS FX | 第6章、第7章、第12章 |
| 视频 | 在分格中放置视频（实验性功能） | 第12章 |
| 蒙版 | 隐藏、显示图像或分格的一部分 | 第7章 |
| 3D姿势／3D文字 | 放置 3D 模型或立体文字 | 第12章 |
| 漫画 | 漫画效果（集中线等）、背景图案 | 第7章 |
| 子画格／分割／变形 | 事后调整分格 | 第6章 |

### ③ 操作栏

| 项目 | 作用 |
| --- | --- |
| 页面 ◀ ▶ | 切换到正在编辑的作品的上一页、下一页 |
| “3 / 12”的显示 | 当前页码／作品的页数 |
| 删除页面 | 把当前显示的页面移到回收站 |
| 保存 | 保存当前显示的页面，并登记到作品中 |
| 分格 | 选择要操作的分格（在预览中点击分格也能选择） |
| 分格边框宽度 | 分格边框的粗细 |
| 删除 | 删除选中的图像、对话气泡等 |
| 撤销 | 取消上一步操作 |
| 插入图像 | 把选择的图像文件放入分格 |
| 在Image标签页编辑 | 在 Image 标签页中打开选中的图像 |
| Generate | 用 Workflow Studio 生成图像（第10章） |
| OC | 把选中的对象移动到分格的中央（如果是覆盖层，则移动到页面中央） |
| 关闭 | 关闭正在编辑的作品。已保存的数据不会消失 |

> **提示**
> 也可以从电脑的文件夹中把图像拖放到预览中放入。

### ⑥ 图层面板

页面中的对象以列表显示。越靠上的对象显示得越靠前。

- 点击某一行，会选中该对象（以及它所在的分格）
- 用“↑”“↓”调整叠放顺序
- 用“G+”编组，用“G-”取消编组
- 用“不透明度”改变选中对象的透明程度
- 最下方的“显示大小”可以放大、缩小预览（25〜300%）

详细用法将在第6章说明。

## 3-3 其他标签页的界面

其他标签页的界面会在各自的章节中说明。这里只介绍如何辨认。

| 标签页 | 界面特征 |
| --- | --- |
| 页面 | 上方有“作品管理”“模板”“输出”3个子标签页。不显示素材面板 |
| Image | 左侧为素材面板（A、F、I），上方为工具按钮，右侧为图层 |
| 字体 | 字体列表和预览 |
| Nanobanana+ | 上方有“Nanobanana／本地”切换。有“生成设置”“Nanobanana历史”2个子标签页（生成设置的右半部分是参考图像） |
| OCR | 左侧为图像和框，右侧为模式、设置、检测结果 |
| MOSS-Image | 左侧为排版编辑器，中央为“提示词”“JSON”“模型・采样器”3个标签，右侧为生成按钮和结果 |
| Auto | “故事・脚本”“自动布局”2个子标签页 |
| 脚本 | 左侧为素材面板（S），中央为情节 |

## 3-4 使用帮助标签页

“帮助”标签页是 Comic Creator 内置的说明书，写有比本书更细致的功能说明。

1. 打开“帮助”标签页。
2. 在左上角的搜索框（“搜索功能...”）中输入要查找的词。例如：`对话框`、`备份`
3. 从左侧列表中选择项目，右侧会显示说明。
4. 点击说明中的“打开标签 →”，会跳转到该功能所在的标签页。

帮助支持日语、英语、中文显示，会根据“设置”标签页中所选的语言切换。

> **提示**
> 本书基于 v1.70.0 版本编写。按钮名称或位置与本书不同时，在帮助标签页中搜索，可以找到当前版本的说明。

> **本章小结**
> - 标签页（共12个）分为“制作”“用 AI 制作”“辅助”3组。最常用的是“页面”和“排版”
> - 排版标签页从左到右依次为：素材面板、工具栏、操作栏和工具设置、预览、图层面板
> - 素材面板的 A、P、T、F、I 分别是素材、页面、模板、字体、Image
> - 不明白的地方就在帮助标签页中搜索
