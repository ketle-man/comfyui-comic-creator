# 第12章 进阶与扩展功能

本章介绍与其他自定义节点或外部软件组合使用的功能。以示例作品“猫咖啡馆的早晨”的收尾为例说明流程。

| 功能 | 需要的东西 | 在示例中的用途 |
| --- | --- | --- |
| 3D 姿势 | comfyui-vrm-pose-editor，以及 VRM 等 3D 模型 | 确定客人的姿势，作为作画的底稿 |
| 3D 文字 | comfyui-vrm-pose-editor | 把第1页的标题文字做成立体字 |
| PixiJS FX | comfyUI-particle-pixijs | 添加咖啡的热气或闪光 |
| 视频工具（实验性） | 无（从 Workflow Studio 发送时需要 Workflow Studio） | 从视频中截取一帧 |
| Eagle 联动 | 图像管理软件 Eagle | 把制作的图像整理保存到 Eagle |
| G'MIC 联动 | 图像处理软件 G'MIC（G'MIC Qt） | 给图像应用 G'MIC 的滤镜 |

> **注意**
> 本章不深入介绍各个自定义节点或软件的用法。详情请参阅各自的说明书。

## 12-1 3D 姿势、3D 文字

### 3D 姿势：给模型摆姿势并放入分格

把 VRM、GLB、GLTF 格式的 3D 模型放到分格上，摆好姿势后以图像形式放入分格。便于绘制人物底稿或确定构图。

1. 点击选择要放入姿势的分格。
2. 点击工具栏中的“3D姿势”，再点击“放置到分格”。分格上会叠加显示一个带红框的 3D 画面。
3. 如果没有显示模型，用“加载模型”读取电脑中的 .vrm／.glb／.gltf 文件。
4. 调整姿势和相机。
5. 点击“确定到分格”，当前的画面就会以图像形式放入分格。

| 操作 | 方法 |
| --- | --- |
| 旋转／平移／拉近相机 | 左键拖动／右键拖动／滚轮 |
| 旋转关节 | 拖动蓝色球（左右＝Y轴，上下＝X轴，Alt＋上下＝Z轴） |
| 左右翻转姿势 | “↔ 镜像” |
| 保存、读取姿势 | “保存姿势”（下载 JSON）／“加载姿势” |
| 详细编辑 | “🎛 Editor”。姿势库、灯光、表情、关键帧等 |

> **提示**
> 把 3D 模型放在 comfyui-vrm-pose-editor 的 `model/` 文件夹中，第一次用“放置到分格”打开时就会自动读取。

> **提示**
> 在示例中，制作第2页客人开门的姿势，把“确定到分格”得到的图像作为底稿。可以在 Image 标签页中添加线条，或用第10章的“Generate”（I2I）转换为漫画风格的图像。

### 用 VRM Pose Studio 详细制作

安装了 ComfyUI 自定义节点“ComfyUI-VRM-Pose-Studio”（VRM Pose Studio，以下简称 VPS）后，可以把“🎛 Editor”切换为打开 VPS。VPS 是可以处理多个模型、相机、时间轴的 3D 工作室。切换的只有“🎛 Editor”，“放置到分格”“确定到分格”等照常使用。在 VPS 的界面中，Comic Creator 显示为“CC”。

1. 在设置标签页的“3D姿势编辑器”中选择“VRM Pose Studio（新标签页）”（第13章）。
2. 选择要放入姿势的分格，点击“3D姿势”中的“🎛 Editor”。VPS 会在新标签页中打开（Shift＋点击则在新窗口中打开）。
3. VPS 的界面中，所选分格的形状会以红色虚线框（带分格名称）显示。输出尺寸也会按分格固定。
4. 在框内确定姿势和相机，点击“📤 发送到CC的分格”，当前画面就会放入分格（按分格形状裁切）。

| 这种时候 | 会怎样 |
| --- | --- |
| 想保持 VPS 打开并放入另一个分格 | 在 CC 中选择另一个分格并点击“🎛 Editor”，无需重新打开 VPS，只会更换框 |
| 发送前在 CC 中打开了其他页面 | 发送目标是点击“🎛 Editor”时的分格，所以不会放入（回到那一页，或重新选择分格） |
| 背景和地面 | 从 CC 打开时，以背景透明、不显示地面的状态开始 |
| 想取消分格尺寸 | 用 VPS 上方的“解除”，恢复为 VPS 项目的输出尺寸（分格尺寸不会保存到项目中） |

> **提示**
> VPS 中的按钮名称以 VPS 实际显示为准。

### 3D 文字：立体文字

把文字（支持中文、日文）或 SVG 形状做成立体挤出的图像，放入分格。

1. 选择要放文字的分格（或覆盖层）。
2. 点击工具栏中的“3D文字”，再点击“放置到分格”。一开始会以立体形式显示 "text" 这个词。
3. 点击“⚙ 3D设置”，在右侧的“文字”栏中输入文字，调整字体、颜色、灯光等。
4. 用“厚度”“倒角”调整立体感。
5. 点击“确定到分格”。

| 项目 | 内容 |
| --- | --- |
| 文字／SVG | 把文字做成立体，还是把 SVG 文件的形状做成立体 |
| 厚度 | 挤出的厚度 |
| 倒角 | 把边角斜切，产生光泽 |
| ⚙ 3D设置 | 文字、字体、对齐、行距，材质（颜色、质感、正面和侧面的颜色），灯光，相机 |

双击确定后的图像（或点击“重新编辑”），可以用相同的设置重新制作。

> **提示**
> 3D 文字需要字体中包含所用的字符。输入中文时，请选择支持中文的字体。

> **提示**
> 在示例中，用 3D 文字在第1页的覆盖层中放入“猫咖啡馆的早晨”的标题，页面就会更像封面。

## 12-2 PixiJS FX：粒子与滤镜

安装了 comfyUI-particle-pixijs 后，可以在图像上合成粒子或滤镜效果。

| 打开的位置 | 结果 |
| --- | --- |
| 排版标签页的“图像”子标签页 ＞“✨ PixiJS FX” | 背景保持透明并确定时，会新增一张只有粒子的图像。显示背景并确定时，所选图像会被替换为结果 |
| Image 标签页的操作栏 ＞“✨ PixiJS FX” | 所选图层的内容会被替换为结果 |

1. 选择要添加效果的图像，点击“✨ PixiJS FX”。
2. 点击预览中的空白处，放置发射点（Emitter）。
3. 调整形状、大小、扩散、风等，用“▶ 播放”确认动态。
4. 用“■ 停止 & 捕获”把那一瞬间确定为静止图像。

用“🎬 滤镜库”可以叠加应用色彩调整、模糊、故障、浮雕等滤镜。组合可以保存为预设。

> **提示**
> 在示例中，试着在第2格的咖啡杯上方放置发射点，添加像热气一样的粒子。

## 12-3 视频工具（实验性功能）

可以把 MP4 视频放到分格中播放，并把喜欢的帧截取为静止图像。

1. 把 MP4 文件拖放到分格中。第一帧会显示在分格中，图层面板中以 🎬 显示。
2. 在图层面板中选择视频，点击工具栏中的“视频”。
3. 用 ▶ 播放、■ 停止、进度条找到想用的画面。
4. 点击“将此帧作为静止图像”，该画面会作为图像添加到同一个分格中。

想移动视频或改变大小时，点击播放按钮（▶）左侧的“✥”（移动模式）。开启期间视频预览会停止，可以像普通图像一样拖动移动、调整大小、旋转。关闭后，会在移动后的位置恢复播放预览。

在 Workflow Studio 的图库中选择视频并点击“Send CC”，也可以发送到分格。

> **注意**
> 视频工具是实验性功能，只支持 MP4（不能使用 GIF 动图）。视频文件保存在 ComfyUI 端，除非删除，否则会一直保留。

## 12-4 与外部软件联动：Eagle、G'MIC

### Eagle：整理保存图像

可以把制作的图像保存到图像管理软件“Eagle”中。

1. 事先启动 Eagle。
2. 在“设置”标签页的“Eagle 设置”中，确认 Eagle API URL（初始为 `http://localhost:41595`）。
3. 点击 Image 标签页操作栏中的“Eagle”，会加上文件名保存到 Eagle 中。

在“Eagle 设置”中，还可以设置把 Nanobanana 生成的图像或 G'MIC 处理的结果自动保存到 Eagle。

> **提示**
> “Eagle 设置”中的“自动保存 ComfyUI 生成的图像”为灰色，这里无法选择。想把 Generate 或 I2I 等通过 Workflow Studio 生成的图像自动保存到 Eagle 时，请在 Workflow Studio 的设置标签页＞“Eagle”中勾选自动保存生成图像的选项。

### G'MIC：使用大量滤镜

可以打开图像处理软件“G'MIC”（G'MIC Qt）的界面，给图像应用 G'MIC 的大量滤镜。

1. 在电脑中安装 G'MIC Qt。
2. 在“设置”标签页的“G'MIC 设置”中，以包含文件夹的形式（完整路径）输入 G'MIC Qt 可执行文件（`gmic_qt.exe`）的位置并保存。无需重启 ComfyUI。
3. 在排版标签页中，选中图像后点击“图像”子标签页中的“在G'MIC GUI中编辑”。在 Image 标签页中，使用 Filter（★）工具。
4. 在 G'MIC 的界面中选择滤镜，应用后关闭。
5. 在排版标签页中点击“插入结果”，结果会作为新图像放入分格（原图会保留）。

> **注意**
> 在指定位置找不到 G'MIC Qt 时，“G'MIC 设置”中会显示红色的警告。

> **本章小结**
> - 3D 姿势、3D 文字需要 comfyui-vrm-pose-editor。“放置到分格”→ 调整 →“确定到分格”
> - PixiJS FX 需要 comfyUI-particle-pixijs。放置发射点并播放，用“停止 & 捕获”确定
> - 视频工具把 MP4 放入分格，用“将此帧作为静止图像”截取一帧
> - Eagle、G'MIC 需要先在“设置”标签页中设置连接目标后再使用
