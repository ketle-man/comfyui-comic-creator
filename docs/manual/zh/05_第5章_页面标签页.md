# 第5章 页面标签页：作品、模板、输出

“页面”标签页用于整理作品和页面、管理模板，以及导出完成的页面。这里将详细介绍第4章中用到的操作。

“页面”标签页上方有3个子标签页。

| 子标签页 | 能做的事 |
| --- | --- |
| 作品管理 | 作品的创建、打开、删除，页面的排序、复制、移动、删除，回收站 |
| 模板 | 模板的创建、读取、重命名、删除，分组 |
| 输出 | 把页面导出为图像、SVG、PDF、EPUB |

## 5-1 作品管理

作品管理的界面分为上方的工具栏，以及左、中、右3个区域。

| 编号 | 位置 | 作用 |
| --- | --- | --- |
| ① | 工具栏 | “新建”“打开”“输出”。右端显示正在编辑的作品名和尺寸 |
| ② | 左：作品一览／组 | 选择作品或组 |
| ③ | 中：页面列表 | 所选作品、组的页面缩略图 |
| ④ | 右：面板 | 所选页面的信息，以及页面、组、作品的操作 |

### 创建、打开作品

| 按钮 | 作用 |
| --- | --- |
| 新建 | 输入作品名和尺寸来创建作品。创建后切换到“排版”标签页 |
| 打开 | 在“排版”标签页中打开所选作品的第1页。双击作品卡片也能打开 |
| 输出 | 只把所选作品（或组）的页面显示在“输出”子标签页中（5-3） |

“新建”中可选的尺寸如下。

| 尺寸 | 大小 |
| --- | --- |
| A4 纵向 | 210×297mm |
| A4 横向 | 297×210mm |
| B5 纵向 | 182×257mm |
| B4 纵向 | 257×364mm |
| A5 纵向 | 148×210mm |
| 正方形 | 210×210mm |

列表中没有的尺寸，可以直接在“宽×高”中输入（单位为 0.01mm。A4 为 21000×29700）。常用的尺寸可以用输入框右侧的按钮保存为自定义预设。

> **提示**
> 作品尺寸决定的是页面的大小。导出图像的像素数由 5-3 中的“分辨率”决定。

### 作品一览与组

左侧区域上方有“作品一览”和“组”的切换按钮。

| 显示 | 内容 |
| --- | --- |
| 作品一览 | 作品卡片（第1页缩略图、尺寸、页数）。正在编辑的作品带有标记 |
| 组 | 不是作品、用于给页面分类的组。stock 和回收站也在这里 |

“作品”与“组”的区别在于是否带有尺寸。

- **作品**：带有宽和高。插入模板时，会按作品尺寸伸缩
- **组**：不带尺寸。用于存放没用上的页面等

页面可以在作品和组之间自由移动。

> **提示**
> **stock** 是一开始就有的组，不能删除或重命名。没有打开作品就制作的页面会自动进入这里（第1章 1-3）。

### 页面的排序、选择

在中间的页面列表中操作页面。

| 操作 | 作用 |
| --- | --- |
| 点击 | 选择一页 |
| Ctrl（Mac 为 ⌘）＋点击 | 选择多页 |
| 全选／取消选择 | 一次选中显示中的所有页面／取消选择 |
| ↑ ↓ | 把所选页面的顺序前后移动（仅在选中一页时） |
| 批量删除 | 把所选页面一起移到回收站 |

这里排列的顺序，就是排版标签页中“◀”“▶”的顺序、“打开”时最先打开的页面，以及导出的顺序。

### 页面的操作（右侧面板）

| 按钮 | 作用 |
| --- | --- |
| 重命名 | 修改所选页面的名称（仅在选中一页时） |
| 连号重命名 | 把所选页面重命名为“名称_000”形式的连续编号 |
| 复制页面 | 复制所选页面，并插入到其后面（名称为“原名称_copy”） |
| 目标组＋移动 | 把所选页面移到其他作品或组 |
| 移至stock | 把所选页面移到 stock |
| 删除（回收站） | 把所选页面移到回收站 |
| 删除作品 | 删除所选作品。其中的页面会移到回收站 |

在右侧面板的“组管理”中，可以添加组、重命名（✎）、删除（✕）。

### 从回收站恢复

删除的页面不会立即消失，而是进入回收站。

1. 在左侧区域切换到“组”，选择“回收站”。
2. 选择要恢复的页面。
3. 选择要恢复到的组（或作品），点击“恢复”。

从回收站中“彻底删除”的页面无法恢复。

> **注意**
> 回收站也和作品一样保存在浏览器中。清除浏览器的网站数据后，回收站中的内容也会消失。

## 5-2 模板

模板列表中，每张卡片的名称下方显示尺寸和分格边框宽度（例如：`21000×29700 / 枠幅 63`）。

| 按钮 | 作用 |
| --- | --- |
| 从SVG创建模板 | 读取 SVG 文件并制作成模板 |
| 创建模板 | 在向导中画线来制作模板 |
| 快速 | 根据所选模板立即生成一页，并在排版标签页中打开（分格线宽保持模板原样。不会登记到作品中。参见下面的注意） |
| 重命名 | 修改所选模板的名称 |
| 删除 | 删除所选模板（无法恢复） |
| 作为页面插入 | 把所选模板作为新页面放入当前打开的作品 |
| 发送到自动布局 | 把所选模板发送到“Auto”标签页的自动布局（第11章） |

> **注意**
> 给作品添加页面时，请使用 **“作为页面插入”**，而不是“快速”。“快速”会按模板原本的尺寸生成页面，也不会登记到作品中。想修改分格线宽时，请在排版标签页上方的“分格边框宽度”中修改（第4章 4-3）。

### 用向导制作

除了第4章 4-1 的步骤外，还有以下设置。

| 项目 | 内容 |
| --- | --- |
| 页面方向 | 纵向／横向 |
| 宽、高 | 模板的大小（单位 0.01mm）。插入作品时会按作品尺寸伸缩，所以只要比例一致即可 |
| 边框宽度 | 页面外侧的留白，以及分格之间间隙的宽度 |
| 设计 | 开启后，会生成没有留白和间隙的模板（适合传单等） |
| 分割模式 | 整体分割：分割线经过的所有分格／单格分割：只分割开始画线的那个分格 |
| 参考网格、吸附 | 显示网格线，并让线的端点吸附到网格上。设置会记录在浏览器中 |

> **提示**
> 开启“设计”制作的模板，分格之间的分界线没有粗细。放入页面后，在排版标签页的“分格边框宽度”中设定粗细。设为 0 时分界线会消失。

### 从 SVG 文件制作

可以用 Inkscape、Affinity Designer、Illustrator 等绘图软件画出分格的分界，保存为 SVG 后制作成模板。

1. 点击“从SVG创建模板”，选择 SVG 文件。
2. 为了与其他模板的边框粗细一致而需要调整倍率时，会出现确认界面。按显示的倍率直接点击 OK 即可完成调整。不调整时输入 `1`。
3. 已有同名模板时，会要求输入别的名称。

> **提示**
> GitHub 上 Comic Creator 的页面中，有按绘图软件分类的示例 SVG（`sample_svg` 文件夹）。用自定义节点管理器安装时不包含这个文件夹，需要时请从 GitHub 下载。各绘图软件中的制作方法，写在应用内帮助的附录中。

### 分组

模板变多后，分组会更便于查找。

1. 在右侧“组管理”中输入组名，点击“添加”。
2. 选择模板，选择组，然后点击“添加到组”。

在列表上方的下拉菜单中选择组，就只会显示该组的模板。排版标签页素材面板的“T”标签中，也会按组折叠显示。

## 5-3 输出

### 输出的流程

1. 在“作品管理”中选择作品，点击“输出”按钮（第4章 4-7）。
2. 选择“格式”。
3. 选择“分辨率”。宽、高（px）会自动计算。
4. 在“输出页面”中指定范围。
5. 根据需要输入“文件名”和“元数据”。
6. 点击“保存”。

### 格式的选择

| 格式 | 适合的用途 |
| --- | --- |
| JPEG | 发布到社交平台等。文件较小 |
| PNG | 想无损保存画质时 |
| WebP | 想减小文件同时保持画质时 |
| SVG | 想之后在 Inkscape 等软件中编辑文字或形状时 |
| PDF | 用于印刷，或想把多页合成一个文件交付时 |
| EPUB | 想作为电子书阅读时 |

### 分辨率与大小

在“分辨率”中选择 72〜600dpi，会根据作品尺寸计算出导出图像的像素数。例如，把 A4 作品设为 300dpi，就是 2480×3508px。

| 分辨率参考 | 用途 |
| --- | --- |
| 72〜150dpi | 在屏幕上查看、发布到社交平台 |
| 300〜350dpi | 印刷 |
| 600dpi | 精细印刷黑白线稿 |

- 直接输入宽、高时，“分辨率”会变为“手动”
- 勾选“保持纵横比”时，会保持宽和高的比例
- 可导出的最大尺寸为 8000px。超过时会保持纵横比缩小
- PDF 会根据所选分辨率计算纸张大小。把 A4 作品以 300dpi 导出时，PDF 的纸张也是 A4（210×297mm）

### 输出页面与文件名

| 项目 | 内容 |
| --- | --- |
| 输出页面 | 要导出的页面范围（从第几页到第几页） |
| 文件名 | 留空时，以页面名称作为文件名 |
| 连续编号 | 导出2页以上时，文件名开头会加上 `01_`、`02_`… |
| zip保存 | 把所有页面打包成一个 zip（适用于 JPEG、PNG、WebP、SVG。选择 PDF、EPUB 时会变灰，无法选择） |

> **注意**
> “输出页面”会根据列表的页数自动填入“1 〜 最后一页”。只导出部分页面时，请修改范围。有正在编辑的作品时，即使直接打开“输出”子标签页，列表中也只会列出该作品的页面（想列出全部页面时，点击筛选显示中的“解除”）。

### 元数据

在“元数据”中输入标题、作者、主题、关键词后，会嵌入到导出的文件中（SVG 除外）。关键词可以用逗号或顿号分隔输入多个。输入的内容下次也会保留。

### 其他项目

| 项目 | 内容 |
| --- | --- |
| 仅背景 | 只导出去掉图像、对话气泡、文字后的分格边框等页面底板（适用于 JPEG、PNG、WebP、SVG。选择 PDF、EPUB 时会变灰，无法选择） |
| ＋ 导入图像 | 把电脑中的图像作为页面导入 |
| 排序 | 按页面列表编号栏中输入的顺序重新排列（未按作品筛选时） |

### 导出为 SVG，在其他软件中修改

SVG 格式不会把页面转成图像，而是以形状和文字数据的形式导出。文字保持为文字，对话气泡保持为形状，所用的字体也会嵌入文件中。

| 软件 | 再编辑的难易程度 |
| --- | --- |
| Inkscape、Affinity Designer/Publisher | 几乎可以直接编辑 |
| Adobe Illustrator | 可以打开，但图像链接会断开，需要逐张重新指定 |
| CorelDraw | 读取过程中会卡住，无法使用 |

> **提示**
> 导出所用的库已包含在应用中，即使没有联网也能导出所有格式。但是，使用了 Google Fonts 等网络字体的页面，如果字体尚未加载完成，可能会用其他字体导出。

> **本章小结**
> - 在“作品管理”中创建、打开、输出作品，以及排序、移动、删除页面。删除的页面可以从回收站恢复
> - 在“模板”中制作、读取模板。给作品添加页面用“作为页面插入”
> - 在“输出”中确认格式、分辨率、输出页面后再点击“保存”。印刷用设为 300〜350dpi
> - 导出为 SVG 后，可以在 Inkscape 等软件中重新编辑文字和形状
