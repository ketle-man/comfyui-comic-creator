# 第8章 字体标签页

在“字体”标签页中，可以比较并选择可用的字体，还可以保存文字的外观（样式）。保存的样式可以在排版标签页或 Image 标签页中一键使用。

界面分为3个区域。

| 位置 | 作用 |
| --- | --- |
| 左 | 字体列表（Google／系统／类别） |
| 中 | 预览，以及样式、预设的制作 |
| 右 | 所选字体的信息、标签、类别的管理、应用按钮 |

## 8-1 查找并比较字体

### 字体的种类

在左侧列表上方切换要显示的字体。

| 标签 | 内容 |
| --- | --- |
| Google | 预先登记的 Google Fonts 列表 |
| 系统 | 电脑中安装的字体。点击“加载系统字体”进行读取 |
| 类别 | 自己分类的字体（8-2） |

在列表上方的搜索框中输入名称并点击“搜索”，可以筛选字体。

> **注意**
> 读取系统字体的功能可在 Chrome 或 Edge 中使用。第一次读取时，浏览器会询问是否允许访问字体，请选择“允许”。在其他浏览器中，系统字体列表可能不会显示。

> **注意**
> Google Fonts 的字体需要从互联网读取。离线时，尚未读取过的字体可能不会显示。

> **提示**
> 预先登记的 Google Fonts 以日文字体为主。中文字体建议通过“加载系统字体”使用电脑中已安装的中文字体（微软雅黑、思源黑体、思源宋体等）。

### 切换预览

用中央上方的标签切换预览内容。

| 标签 | 内容 |
| --- | --- |
| 基本 | 英文、平假名、片假名、汉字、数字、符号的示例。用复选框选择要显示的文字种类 |
| 文章 | 横排、竖排的例句 |
| 自定义 | 输入任意文字进行预览。可以分别为日文和英文指定不同的字体 |
| 类别一览 | 把所选类别的字体全部排列出来进行比较 |
| 样式 | 样式、预设的制作（8-3） |

> **提示**
> 想确认中文的显示效果时，请使用“自定义”标签输入中文文字进行预览。

也可以修改“大小”，以及横排、竖排的显示方式（横竖同时／仅横排／仅竖排）。

## 8-2 用标签和类别整理

字体太多不好找时，可以用标签或类别整理。在左侧列表中选择字体后，右侧会显示字体名称。

### 类别

类别就像存放字体的“架子”。按“手写风”“台词用”“拟声词用”等分好类后，在排版标签页中也可以从类别中选择。

1. 点击右侧的“+ 类别”，输入类别名称进行创建。
2. 在左侧列表中选择字体。
3. 在右侧的下拉框中选择类别，点击“添加”。

要从类别中移除时点击“移除”，要删除类别本身时点击“- 类别”。

### 标签

标签是给字体加上的、类似备注的标记。在“添加标签”栏中输入标签，加到所选字体上。用过的标签会显示在列表中，点击即可添加。

## 8-3 制作样式和预设

### 样式与预设的区别

| 名称 | 内容 | 使用场景 |
| --- | --- | --- |
| 样式 | 文字的外观（填充、描边、勾边字、阴影等）。不包含字体 | “红色勾边字”“带阴影”等与字体无关的外观 |
| 预设 | 字体＋大小＋是否竖排＋样式 | “台词用”“拟声词用”等每次都以相同设置使用的文字 |

### 制作样式

1. 打开中央的“样式”标签。
2. 在“预览文字”中输入要确认的文字。
3. 设置填充、描边、勾边字、阴影等。项目与排版标签页的“样式”界面相同（第7章 7-2）。
4. 输入名称，点击“保存”。

| 项目 | 内容 |
| --- | --- |
| 填充 | 单色、渐变、纹理。取消勾选则无填充 |
| 描边 | 文字的轮廓线 |
| 粗体、斜体、下划线 | 文字的装饰 |
| 行距、上下、对齐 | 多行文字的排列方式 |
| 勾边字 | 文字外侧的粗边 |
| 阴影 | 阴影的颜色、模糊、阴影位置（X、Y） |

保存的样式可以从“已登记”中选择，读取后进行修改。

| 操作 | 结果 |
| --- | --- |
| 不改名称直接“保存” | 覆盖保存 |
| 修改名称后“保存” | 原样式保持不变，另存为新的样式 |
| “新建” | 清空输入栏，开始新建 |
| “删除” | 删除当前选择的样式 |

### 制作预设

1. 在左侧列表中，选择预设要使用的字体。
2. 在“样式”标签下方的“预设”栏中，选择“大小(pt)”、是否竖排，以及要使用的样式。
3. 输入名称，点击“保存”。

操作方法（从已登记中选择、另存为、删除）与样式相同。

## 8-4 使用制作好的样式

### 在排版标签页中使用

保存的样式和预设，会以示例图像（缩略图）的形式排列在排版标签页素材面板的“F”标签中。

| 状态 | 点击缩略图后 |
| --- | --- |
| 未选中文字 | 作为新文字放到所选分格的中央 |
| 选中了文字 | 把样式（预设）应用到该文字上 |

用缩略图上方的“背景”，可以修改示例的背景色（默认、黑色、白色、灰色、自定义）。白色文字的样式等不易看清时，可以切换。

> **提示**
> 为了便于比较外观，样式的缩略图全部使用同一种字体（Zen Antique）显示。预设的缩略图则使用登记的字体显示。

### 从字体标签页直接使用

点击右侧的“应用到选中文字”，会把所选字体应用到排版标签页中选中的文字上。

### 设为 Auto 的默认字体

点击右侧“自动排版”栏中的“设为默认字体”，所选字体会成为 Auto 标签页的自动布局中使用的默认字体（第11章）。不需要确认，会立即保存。

> **提示**
> 导出时，所用的字体会自动嵌入文件中（SVG、PNG 等）。即使在没有安装该字体的电脑上查看，外观也相同。

> **本章小结**
> - 在左侧选择字体，在中央预览。系统字体在 Chrome、Edge 中用“加载系统字体”读取
> - 用类别按“台词用”“拟声词用”等分类后，在排版标签页中也更容易找到
> - 样式＝仅外观，预设＝字体＋大小＋样式
> - 保存的样式可以从素材面板的“F”标签中一键使用
