# 第9章 Image 标签页：图层图像编辑器

“Image”标签页是一个通过叠加图层来编辑图像的图像编辑器。它在一张独立于排版标签页页面的画布上工作。

- 给一张图像加上标题或台词
- 裁剪图像、添加边距、去除背景
- 叠加图层，进行绘画或加工
- 把编辑后的图像送回排版标签页的分格中

> **提示**
> 即使切换为中文显示，Image 标签页的工具名称和按钮名称大多仍是英文。本书也按界面上的英文书写。另一方面，输入对话框和界面上的提示信息会按显示语言翻译。

## 9-1 界面介绍

| 编号 | 位置 | 作用 |
| --- | --- | --- |
| ① | 工具栏（左） | 工具按钮。把鼠标移到图标上会显示名称 |
| ② | 操作栏（上） | 打开、新建、关闭、撤销、保存、发送 |
| ③ | 选项栏（②的下方） | 所选工具的设置 |
| ④ | 画布（中央） | 正在编辑的图像 |
| ⑤ | 右侧面板 | 所选对象的属性，以及图层列表 |

画布下方的“Fit”会缩放到适合界面的大小，“100%”则以实际尺寸显示。按住 Space 键拖动，可以移动显示位置。

素材面板（A、F、I）也会显示在左侧。“A”中的素材可以用“作为图层插入”作为新图层放入。

## 9-2 给一张图像加字

首先，把最常用的“给图像加字并保存”的流程完整走一遍。

1. 打开“Image”标签页。
2. 把要加字的图像文件拖放到画布上（或用“File Open”选择）。
3. 点击工具栏中的“T”（Text）。
4. 在选项栏中选择 Color（文字颜色）、Size（大小）、Font（字体）。需要竖排时勾选“竖排”。
5. 点击要放置文字的位置。会打开输入框，输入文字后点击“OK”。

6. 要调整文字的位置时，点击“▲”（Select），然后拖动文字。
7. 要添加勾边字或阴影时，选中文字并点击选项栏中的“样式”（与第7章 7-2 是同一个界面）。
8. 点击操作栏的“PNG”进行保存。

> **注意**
> 在文字输入框中，**按 Enter 键换行**，**按 Ctrl＋Enter（Mac 为 ⌘＋Enter）确定**。与排版标签页的“文字输入”操作相同。按 Esc 可以取消。

> **提示**
> 点击文字工具选项栏中的“Insert”，会打开“插入文字”界面，可以放入脚本标签页的单元格或 OCR 标签页读取的文字（第10章 10-8）。OCR 的文字会以文字图层的形式放到读取时框的位置（2条以上时会归入“OCR”组）。

> **提示**
> 双击放入的文字可以重新输入。在字体标签页中保存的样式，可以从素材面板的“F”标签中点击应用。

## 9-3 打开图像、新建图像

| 按钮 | 作用 |
| --- | --- |
| File Open | 打开电脑中的图像。也可以拖放到画布上打开。已打开图像时，会作为新图层（以适合画布的大小）添加 |
| Open PSD | 连同图层一起打开 PSD（Photoshop 格式）文件（最大 50MB） |
| New | 以 `宽x高`（例如 `1024x1024`）输入尺寸，创建空白画布（最大 8192） |
| 草稿 | 创建一个与正在编辑的作品纵横比相同的轻量画布（用于草图。未打开作品时无法使用） |
| Close | 关闭正在编辑的图像。会确认是否保存 |
| ↩ ↪ | 撤销（Ctrl＋Z）／重做（Ctrl＋Y） |

> **提示**
> 在排版标签页中双击分格中的图像，或点击“在Image标签页编辑”，该图像就会在 Image 标签页中打开。编辑完成后点击“排版”，结果会写回原图像（9-6）。

> **注意**
> “Open PSD”和以 PSD 保存需要 `psd-tools` 软件包（第2章 2-3）。

| 按钮 | 工具 | 快捷键 | 能做的事 |
| --- | --- | --- | --- |
| ▲ | Select | V | 图层的选择、移动、缩放、旋转。裁剪和添加边距 |
| ✏ | Draw | B | 用画笔绘画 |
| T | Text | T | 添加文字 |
| ◪ | 3D Text | — | 立体文字（需要 comfyui-vrm-pose-editor。第12章） |
| □ | Shape | S | 绘制图形 |
| 🪣 | Fill | G | 油漆桶填充（单色、渐变） |
| 🎭 | Mask | — | 制作蒙版 |
| ≈ | Blur | — | 模糊、马赛克 |
| ★ | Filter | — | G'MIC 的滤镜（第12章） |
| ⬚ | BG Remove | — | 去除背景 |
| ⤢ | Upscale | — | 放大、降噪、锐化 |

### Select：裁剪、添加边距

在 Select 工具中，除了移动图层，还可以改变画布的大小。

| 按钮 | 内容 |
| --- | --- |
| ✂ 裁剪 | 裁剪画布。拖动虚线框，或在右侧面板中输入 X、Y、宽、高后点击“执行” |
| ⛶ 扩展画布 | 在画布的上下左右添加边距。用“联动四边”让4条边的宽度相同。边距颜色可从“边缘像素（延伸边缘的颜色）”“透明”“白色”“黑色”中选择 |

选中的图层可以按 Delete 键删除（只有一个图层时不会删除）。

### Draw：用画笔绘画

设定画笔的颜色、粗细、不透明度，拖动进行绘画。点击取色器右侧的吸管，再点击画布，就可以把该处的颜色设为画笔颜色。也支持数位板笔压。

选择 Draw 工具后，工具下方一栏会出现调色板。

| 位置 | 内容 |
| --- | --- |
| 颜色1、颜色2 | 当前使用的颜色（颜色1）和备用颜色（颜色2）。初始为黑色和白色 |
| 基本色 | 常用的20种颜色。点击即可使用该颜色 |
| 自定义 | 自己登记的20个色块。点击空色块，会登记当前颜色 |

在颜色上右键单击，可以选择“登记当前颜色”“编辑颜色…”“删除”（自定义颜色）、“恢复初始颜色”（修改过的基本色）。登记的颜色保存在浏览器中，不会包含在作品数据中。

使用 Draw 工具期间，可以使用以下按键（在文字输入框中时无效）。

| 按键 | 作用 |
| --- | --- |
| D／E | 切换为绘画（Draw）／擦除（Erase） |
| X | 互换颜色1和颜色2 |
| [／] | 让画笔变细／变粗 |
| B | 打开、关闭画笔选择界面（在其他工具中按下时切换到 Draw） |

### Shape：绘制图形

可以绘制矩形、椭圆、线条、锁链、绳索、My Curve 等。选项栏左侧的“Same Layer”开启时（初始为开启），每次绘制图形不会增加图层，而是在同一图层上继续绘制。矩形和椭圆的填充可以使用单色、渐变、纹理。

### Fill：油漆桶填充

填充点击位置以及与之相连的相近颜色范围。调大“Tolerance”（容差）后，颜色稍有不同的地方也会被填充。切换为“Gradient”后，可以用渐变填充。

### Mask：蒙版

制作蒙版图层，用来隐藏图像的一部分，或者确定用 AI 重绘的范围。除了用画笔涂抹的 Paint 之外，还有通过颜色、透明度、文字、图形来确定范围的子工具。

安装了 Workflow Studio 时，Mask 工具中会显示“Inpaint”（用 AI 重绘范围）和“Outpaint”（用 AI 在图像外侧扩展绘制）（第10章）。

### Blur、BG Remove、Upscale

| 工具 | 内容 |
| --- | --- |
| Blur | 对整体或所选矩形范围进行模糊、马赛克处理 |
| BG Remove | 去除背景。用 Quality 选择品质（42MB／84MB／168MB）。首次使用时下载模型需要联网 |
| Upscale | 放大图像。也可以降噪、锐化 |

> **注意**
> BG Remove 的“BiRefNet”模型，只有在安装了自定义节点“Mask Editor One”和 BiRefNet 模型时才能选择。没有安装时会变灰，请使用轻量模型。

## 9-5 图层面板

| 按钮 | 作用 |
| --- | --- |
| ＋ | 添加新图层 |
| M | 添加蒙版图层 |
| − | 删除所选图层 |
| ↑ ↓ | 改变叠放顺序 |
| 📁 分组 | 按住 Shift 点击选择2个以上图层后点击，像文件夹一样归为一组 |
| 合并 | 选择2个以上图层后点击，把所选图层合并为一个。选择1个以下时，把全部图层合并为一个 |

在各图层的行中，可以切换显示、隐藏、锁定，以及修改不透明度。用不透明度下方的复制按钮，可以复制所选图层。

在面板下方，可以添加亮度、对比度、饱和度等12种 **调整图层**。调整图层会在不改变原图的情况下，调整其下方图像的色调。

## 9-6 保存、发送

操作栏的右侧排列着保存和发送的按钮。

### 保存

| 按钮 | 保存的内容 | 保存位置 |
| --- | --- | --- |
| PNG | 合并所有图层后的一张图像 | 下载到电脑 |
| PSD | 保留图层的 PSD 文件（调整图层会合并到下方图层中） | 下载到电脑 |
| Project | 包括图层结构在内的编辑状态。之后可以继续编辑 | 素材面板的“I”标签 |
| Gallery | 合并所有图层后的图像 | ComfyUI 的 `output/cc` 文件夹 |

> **提示**
> 之后可能还要修改的图像，请用“Project”保存。在素材面板的“I”标签中选择并点击“Open”，就会连同图层恢复到原来的状态。用 PNG 保存的图像，无法重新编辑文字。

### 发送

| 按钮 | 发送目标 |
| --- | --- |
| 排版 | 排版标签页。如果是从“在Image标签页编辑”打开的图像，会写回原图像；否则作为新图像放入所选分格 |
| Eagle | 图像管理软件 Eagle（第12章） |
| wsI2I | Workflow Studio 的 I2I（以图生图）输入（第10章） |
| LI Node | ComfyUI 界面中选中的 Load Image 节点（仅在通过 CC 按钮打开时可用） |

> **提示**
> 用“草稿”创建的画布通过“排版”发送时，不会放入分格，而是放入整个页面的草稿图层。

> **本章小结**
> - Image 标签页是用图层编辑的一张画布。图像通过拖放或“File Open”打开
> - 加字的流程是“T”→ 点击 → 输入 → OK。换行用 Enter，确定用 Ctrl＋Enter
> - 用 Select 的“✂ 裁剪”进行裁剪，用“⛶ 扩展画布”添加边距
> - 保存用“PNG”，之后还要修改则用“Project”。用“排版”可以送回分格
