# 第13章 设置与备份

本章介绍“设置”标签页的项目，以及用来保护作品的备份与恢复。

## 13-1 设置标签页的项目

“设置”标签页中，从上到下排列着以下项目。

| 项目 | 内容 | 本书章节 |
| --- | --- | --- |
| 语言 | 显示语言（日本語／English／中文）。切换后界面会重新加载 | 第2章 |
| 备份与恢复 | 把全部数据保存为 zip／从 zip 恢复 | 本章 13-2 |
| 显存调整（Ollama） | 在生成图像前卸载 Ollama 的模型，腾出 GPU 内存 | 见下表 |
| Nanobanana 设置 | Nanobanana 的生成方式（Gemini API／ComfyUI 原生节点）。Nanobanana+ 标签页（Nanobanana 模式）、半自动漫画、Auto 共用 | 第10章 |
| 3D姿势编辑器 | 排版标签页“3D姿势”中“🎛 Editor”打开的编辑器（3D Pose Editor／VRM Pose Studio） | 第12章 |
| Eagle 设置 | Eagle 的连接目标，以及自动保存 | 第12章 |
| G'MIC 设置 | G'MIC Qt 可执行文件的位置 | 第12章 |
| Inpaint设置 | Image 标签页的 Inpaint 使用的工作流 | 第10章 |
| Outpaint设置 | Image 标签页的 Outpaint 使用的工作流 | 第10章 |

### 显存调整（Ollama）

在同一台电脑上同时使用本地 AI（Ollama），以及 Workflow Studio、MOSS-Image、Nanobanana+（本地）的图像生成时，GPU 的内存（显存）可能会不足。通过这个设置，可以在生成图像之前卸载（unload）Ollama 的模型。

| 项目 | 内容 |
| --- | --- |
| 生成前的操作 | 不做任何操作（默认）／仅在空闲显存低于目标时卸载所需的部分／每次全部卸载 |
| 目标空闲显存（GB） | 选择“仅卸载所需的部分”时，要腾出多少显存 |
| 立即全部卸载 | 立即卸载当前已加载的 Ollama 模型 |

卸载的模型在下次使用时会重新加载。对象只有自己电脑上的 Ollama（LM Studio 等以及 ComfyUI 自身的模型不在对象范围内）。

在 OCR 标签页中，执行检测之前、用决策模型判定之前，以及用 ComfyUI 的 Chat TE 进行整图识读之前，这个设置也会生效（第10章 10-8）。

### Inpaint设置、Outpaint设置

指定执行 Image 标签页的 Inpaint、Outpaint 时，让 Workflow Studio 自动读取的工作流。

1. 勾选“使用默认工作流”。
2. 在“工作流文件名”中，输入保存在 Workflow Studio 中的工作流名称。

取消勾选时，使用 Workflow Studio 中当前打开的工作流。

> **提示**
> I2I、T2I 的工作流不在设置标签页中指定，而是在排版标签页“Generate”界面下方的“工作流设置”，或 Image 标签页 Select 工具的“I2I 设置”中指定（第10章）。

## 13-2 备份与恢复

正如第1章所述，Comic Creator 的作品保存在浏览器中。清除浏览器数据或更换电脑后，作品就看不到了。请定期备份。

### 进行备份

1. 打开“设置”标签页。
2. 点击“备份与恢复”中的“备份”。
3. 会保存一个名为 `ccc_backup_日期时间.zip` 的 zip 文件。

### 备份包含与不包含的内容

| 包含（浏览器中的数据） | 不包含（电脑文件夹中的内容） |
| --- | --- |
| 作品、页面、组、回收站 | `assets` 文件夹中的素材（素材面板“A”） |
| 模板和模板的组 | 用 Image 标签页的“Project”保存的内容（素材面板“I”） |
| 脚本标签页的作品 | 保存在 `ComfyUI/output/` 中的图像（Nanobanana、Gallery 等） |
| Auto 的作品和 AI 设置 | `.env`（API 密钥） |
| 字体标签页的样式、预设、类别 | G'MIC 设置 |
| 联动的设置（Eagle、工作流、PixiJS FX、显存调整等） | ComfyUI 本体的设置 |
| 显示语言、输出的设置等 | |

> **注意**
> “不包含”的内容无法通过 Comic Creator 的备份来保护。尤其是 `ComfyUI/custom_nodes/comfyui-comic-creator/assets/` 文件夹（素材和 Image 标签页的 Project），请另外复制到其他位置。

### 恢复

1. 在“设置”标签页的“备份与恢复”中点击“恢复”。
2. 选择备份的 zip 文件。
3. 在确认界面中点击 OK。完成后，界面会自动重新加载。

恢复采用“覆盖并追加”的方式。同名的数据会被 zip 中的内容覆盖，其余现有数据保持不变。

> **提示**
> 想删除当前所有数据、完全恢复为备份时的状态时，请在恢复之前先清除浏览器的“网站数据”，然后再恢复。

### 迁移到另一台电脑

1. 在原来的电脑上进行备份。同时复制 `assets` 文件夹。
2. 在新电脑上安装 ComfyUI 和 Comic Creator（第2章）。
3. 把 `assets` 文件夹复制到新电脑的 Comic Creator 文件夹中。
4. 打开 Comic Creator，在“设置”标签页中“恢复”。

> **注意**
> 请用平时使用的浏览器、平时使用的地址进行恢复。用其他地址打开并恢复时，数据会保存到那个地址下（第1章）。

> **本章小结**
> - “设置”标签页中有语言、备份、显存调整、Eagle、G'MIC、Inpaint／Outpaint 的设置
> - 用“备份”可以把浏览器中的全部数据保存为一个 zip
> - `assets` 文件夹（素材、Image 标签页的 Project）和 `output` 中的图像，请另外复制保存
> - “恢复”采用覆盖同名数据、保留其他数据的方式
