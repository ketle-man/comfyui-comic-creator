# 第4章 制作第一页

本章将实际动手，制作一页漫画并导出为 PNG 图像。细节设置留到后面的章节，先从头到尾完整走一遍吧。

本章要做的是以下7件事。

| 顺序 | 要做的事 | 使用的标签页 |
| --- | --- | --- |
| 4-1 | 制作一个分格模板 | “页面”标签页＞“模板” |
| 4-2 | 创建作品 | “页面”标签页＞“作品管理” |
| 4-3 | 将模板作为页面插入 | “排版”标签页 |
| 4-4 | 在分格中放入图像 | “排版”标签页 |
| 4-5 | 添加对话气泡和台词 | “排版”标签页 |
| 4-6 | 保存并增加页面 | “排版”标签页 |
| 4-7 | 导出为 PNG | “页面”标签页＞“作品管理”＞“输出” |

需要准备的东西：2〜3张要放入分格的图像（ComfyUI 生成的图像等，PNG 或 JPEG）。

## 4-1 制作分格模板

第一次启动 Comic Creator 时，会自动登记“A4竖_3格”和“A4横_3格”两个模板。这里为了了解向导的用法，我们自己制作一个模板。直接使用“A4竖_3格”也可以。

1. 打开“页面”标签页，选择上方的“模板”子标签页。
2. 点击“创建模板”。向导会打开。

3. 在“页面方向”中选择“纵向”。宽、高、边框宽度一开始保持默认即可。
4. 点击“创建基底”。会显示一个页面形状的白色框（画布）。
5. 确认“分割模式”为“整体分割”。
6. 在画布上从左向右横向拖动画线。分格会在线的位置分成两个。

7. 用同样的方法，用竖线把下面的分格分成两个。此时把“分割模式”切换为“单格分割”，就只会分割开始画线的那个分格。
8. 变成3个分格后，点击“保存为模板”。
9. 会询问模板名称，输入 `3格` 之类容易辨认的名称，然后点击 OK。

模板列表中显示出你制作的模板，就完成了。

> **提示**
> 线画错了就点“撤销一步”，想从头再来就点“重新开始”。

> **提示**
> 勾选“参考网格”后画布上会显示网格线，勾选“吸附”后线的端点会吸附到网格上。想让分格大小一致时很方便。

## 4-2 创建作品

接下来，创建用来放页面的“作品”。

1. 选择“页面”标签页的“作品管理”子标签页。
2. 点击“新建”。“新建作品”界面会打开。

3. 在“作品名”中输入名称。例如：`我的第一部作品`
4. 在“尺寸”中选择纸张大小。这里选择“A4 纵向 (210×297mm)”。
5. 点击“创建”。

作品创建完成后，会自动切换到“排版”标签页。此时页面数还是0。

> **提示**
> 作品名后面会自动附加创建日期时间（第1章 1-3）。

## 4-3 将模板作为页面插入

用 4-1 中的模板，给刚创建的作品添加页面。

1. 点击“排版”标签页最左侧素材面板中的“T”（模板）标签。
2. 点击选择 4-1 中制作的模板。
3. 点击素材面板下方的“作为页面插入”。

预览中会显示一个3格的页面。模板已经按作品尺寸（A4纵向）自动伸缩。也请确认操作栏的页码变成了“1 / 1”。

> **注意**
> “页面”标签页＞“模板”子标签页中还有一个“快速”按钮。它会根据所选模板立即生成一页并在排版标签页中打开。但是，它按模板原本的尺寸生成页面，而且不会自动登记到作品中。要给作品添加页面时，请使用 **“作为页面插入”**。

## 4-4 在分格中放入图像

最简单的方法是从电脑的文件夹中拖放图像。

1. 在资源管理器（Mac 上为 Finder）中打开存放图像的文件夹。
2. 把图像文件拖到预览中想放入的分格上，然后松开。

图像会对齐分格的左上角，以撑满分格宽度的大小放入。超出分格的部分不会显示。

### 调整图像的位置和大小

| 想做的事 | 操作 |
| --- | --- |
| 移动位置 | 拖动图像 |
| 改变大小 | 拖动选中图像后周围出现的控制点（圆点） |
| 放到分格中央 | 选中图像，点击操作栏的“OC” |
| 操作错了想取消 | 点击操作栏的“撤销” |
| 删除图像 | 选中图像，点击操作栏的“删除”（也可以按 Delete 键） |

其余的分格也用同样的方法放入图像吧。

> **提示**
> 一次只能拖放一张图像。即使同时拖放多个文件，也只会放入第一张。

> **注意**
> 拖放时，请在想放入的分格上松开。如果在分格外（页面空白处等）松开，图像可能会进入之前选中的分格，或者覆盖整个页面的覆盖层。

## 4-5 添加对话气泡和台词

### 放置对话气泡

1. 点击工具栏中的“对话框”。
2. 在预览中点击选择要放对话气泡的分格。分格会被蓝色框包围。
3. 在类型中选择“普通（椭圆）”。
4. 点击“插入”。对话气泡会放在所选分格的中央。

拖动对话气泡周围的控制点可以改变大小。尾巴（尖角部分）的方向和长度，可以在“尾巴”的“角度”“长度”中修改。

> **提示**
> 插入对话气泡后，会切换为“编辑：ON”，进入可以移动对话气泡或改变形状的状态。切换为“编辑：OFF”后，就不会误移动对话气泡了。

### 添加台词

1. 点击选择要添加台词的对话气泡。
2. 点击“内嵌文字”。“内嵌文字”界面会打开。

3. 在“文字”中输入台词。可以换行。
4. 想竖排时，勾选“竖排”。
5. 调整“字号”等，然后点击“创建”。

台词会自动换行并放入对话气泡中。之后想修改时，双击对话气泡，就会再次打开这个界面。

> **提示**
> 竖排适合日文漫画。中文漫画一般用横排，不勾选“竖排”即可。

## 4-6 保存并增加页面

### 保存

点击操作栏的“保存”。当前显示的页面会被保存，并登记到作品中。

> **提示**
> 图像和对话气泡的操作会随时记录在浏览器中。尽管如此，养成在告一段落时点击“保存”的习惯会更放心。

### 制作第2页

1. 在素材面板的“T”标签中选择模板。
2. 点击“作为页面插入”。第2页生成，页码变为“2 / 2”。
3. 与 4-4、4-5 一样，放入图像和对话气泡，然后点击“保存”。

用操作栏的“◀”“▶”可以在第1页和第2页之间切换。

## 4-7 导出为 PNG

把完成的页面导出为 PNG 图像。

1. 打开“页面”标签页的“作品管理”子标签页。
2. 在左侧的作品列表中，点击选择刚才制作的作品。
3. 点击上方的“输出”按钮。会切换到“输出”子标签页，列表中只显示这个作品的页面。

4. 在“格式”中选择“PNG”。
5. 在“输出页面”中输入要导出的页面范围。两页都导出的话，设为 `1` 〜 `2`。
6. 点击“保存”。
7. 询问保存位置时，选择保存的地方。

> **注意**
> “输出页面”中会根据列表的页数自动填入“1 〜 最后一页”。只导出部分页面时，请修改范围。

> **注意**
> 即使不通过“作品管理”的“输出”按钮打开“输出”子标签页，只要有正在编辑的作品，列表中也只会列出该作品的页面。想列出包括其他作品在内的全部页面时，请点击列表上方筛选显示中的“解除”。“输出页面”的编号就是列表中排列的顺序。

> **提示**
> 导出多个页面时，在 Chrome 或 Edge 中只会询问一次保存文件夹，各页的文件会保存到那里。勾选“zip保存”后，可以把所有页面打包成一个 zip 文件保存。

用图片查看器打开导出的 PNG，确认页面已经做好。这样，第一页就完成了。

> **本章小结**
> - 一开始就自带“A4竖_3格”“A4横_3格”。自己制作时使用“页面”标签页＞“模板”＞“创建模板”
> - 作品在“页面”标签页＞“作品管理”＞“新建”中创建。创建后会切换到“排版”标签页
> - 页面通过素材面板的“T”标签＞“作为页面插入”添加到作品中
> - 图像拖放到分格中。对话气泡用“对话框”＞“插入”，台词用“内嵌文字”
> - 导出时在“作品管理”中选择作品并点击“输出”。务必确认“输出页面”的范围
