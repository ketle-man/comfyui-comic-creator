# 第6章 排版标签页（上）：分格与排布

本章介绍在排版标签页中如何选择放置图像的位置、如何用图层面板整理、如何事后调整分格，以及如何登记素材。对话气泡、文字、绘制将在第7章介绍。

## 6-1 放置图像的位置与放入方法

### 放置位置有3种

在排版标签页中，图像可以放在以下3个位置。

| 放置位置 | 特点 | 是否包含在导出中 |
| --- | --- | --- |
| 分格 | 按分格形状裁切。通常放在这里 | 包含 |
| 覆盖层（全面） | 覆盖整个页面的前景层。会跨越分格边框显示（不会超出页面之外） | 包含 |
| 草稿（全面） | 位于覆盖层更前面、用于打草稿的层。只能放置图像 | **不包含** |

放置位置可以通过在预览中点击分格来选择，或者在图层面板中点击“覆盖层（全面）”“草稿（全面）”所在的行来选择。选中的分格会被蓝色框包围。

> **提示**
> 草稿图层只有在被选中时才会响应点击或拖动。未选中时，点击会直接穿透到下面的覆盖层或分格。这样就可以把草图或构图底稿放在上面，同时在其下方继续工作。

### 放入图像的方法有3种

| 方法 | 步骤 |
| --- | --- |
| 拖放 | 把电脑中的图像文件拖放到想放入的分格上（第4章 4-4） |
| 插入图像 | 选中分格，用操作栏的“插入图像”选择文件 |
| 素材面板 | 在素材面板的“A”标签中选择素材，点击“插入到分格”（6-5） |

图像会对齐分格的左上角，以撑满分格宽度的大小放入。

### 移动、缩放、旋转图像

点击图像后，周围会显示控制点。

| 操作 | 方法 |
| --- | --- |
| 移动 | 拖动图像 |
| 放大、缩小 | 拖动绿色控制点（保持纵横比） |
| 自由变形 | 按住 Alt 键拖动绿色控制点（图像也会随之拉伸） |
| 旋转 | 拖动黄色控制点 |
| 回到中央 | 点击操作栏的“OC” |
| 删除 | 操作栏的“删除”，或按 Delete／Backspace 键 |

> **提示**
> 如果把图像移到分格外而无法再抓取，可以在图层面板中选择该图像所在的行，然后点击“OC”，图像会回到分格中央。

## 6-2 图层面板

图层面板中，页面中的对象按“分格 → 其中的对象”的顺序排列。

### 分格行的按钮

| 按钮 | 作用 |
| --- | --- |
| ✕ | 删除该分格（其中的图像、对话气泡、子画格也会一起删除。可以用“撤销”恢复） |
| □／− | 显示（□）／隐藏（−）该分格的边框 |
| 🔓／🔒 | 一次性锁定／解锁分格中的所有对象 |

### 图像、对话气泡等行的按钮

| 按钮 | 作用 |
| --- | --- |
| 👁 | 显示／隐藏 |
| Alt＋点击 👁 | 一次性显示／隐藏整个页面中同一类型的对象（只有对话气泡、只有图像等） |
| 🔓／🔒 | 锁定／解锁。锁定后无法选择、移动、删除 |
| ✕ | 删除 |

> **提示**
> 用 Alt＋点击 👁“隐藏所有对话气泡”后，就可以只查看画面。再次 Alt＋点击即可恢复。

### 面板上方、下方的操作

| 位置 | 操作 | 作用 |
| --- | --- | --- |
| 上方 | ↑ ↓ | 上下移动所选对象的叠放顺序（越靠上越在前） |
| 上方 | G+／G- | 编组／取消编组（6-3） |
| 上方 | 📦+ | 把勾选的一个对象登记为素材（6-5） |
| 上方 | 不透明度 | 所选对象的透明程度 |
| 下方 | 复制／移动 | 把所选对象复制／移动到下拉菜单中选择的分格（或覆盖层、草稿） |
| 下方 | 显示大小 | 放大、缩小预览（25〜300%） |

## 6-3 编组

想把多个对象一起移动时，可以把它们编为一组。

1. 在图层面板中，勾选2个以上要编组的对象所在行的复选框。
2. 点击上方的“G+”。

点击组的行（带有 [G] 标记）后，会显示橙色虚线框。拖动可以整体移动，拖动控制点可以整体缩放、旋转。要取消编组时，选中组并点击“G-”。

> **注意**
> 只有同一个分格中的对象才能编为一组。

## 6-4 事后调整分格

用模板制作的分格，即使放入页面后也可以修改。使用工具栏中的“子画格”“分割”“变形”。

### 子画格：在分格中制作小分格

在分格中制作一个用于插入其他镜头的小分格（子画格）。子画格中可以像普通分格一样放入图像或对话气泡。

1. 点击工具栏中的“子画格”。
2. 把“添加子画格”设为“ON”，从“矩形”或“圆形”中选择形状。
3. 在预览中，在想制作子画格的分格内拖动。

制作完成后，“添加子画格”会自动回到“OFF”。

| 操作 | 方法 |
| --- | --- |
| 移动 | 拖动子画格的边框（黑线） |
| 大小、旋转 | 拖动选中时出现的圆形控制点／黄色控制点 |
| 边框粗细 | 在“选中子画格的边框宽度”中输入 |
| 删除 | 点击图层面板中子画格行的 ✕ |

> **提示**
> 在子画格内点击时，通常会选中其中的图像。想连同子画格边框一起移动时，请勾选图层面板中子画格行的复选框。

### 分割：把一个分格分成两个

1. 点击工具栏中的“分割”。
2. 把“画格分割”设为“ON”。
3. 在预览中，在想分割的分格内沿着分割线拖动。斜线也可以。

只有所选的分格会被分成两个，其他分格不变。

| 项目 | 内容 |
| --- | --- |
| 画格间距 | 分割后两个分格之间的间隙。会自动采用页面现有的间隙，通常无需修改 |
| 原有的对象 | 只有完全落在新分格范围内的对象才会移到新分格。其余的留在原分格中 |
| 分格编号 | 新分格的编号紧接在原分格之后，之后的编号依次后移一位 |

### 变形：改变分格的形状、删除分格

1. 点击工具栏中的“变形”。
2. 把“画格变形”设为“ON”，点击想修改的分格。会显示角（●）和边。
3. 拖动角时，只有该角会移动。拖动边时，该边会平行移动。

| 操作 | 方法 |
| --- | --- |
| 减少角 | 点击选中角，然后点击“删除所选顶点”（或按 Delete 键）。可以把四边形变成三角形 |
| 删除分格 | 点击“删除所选画格”。其中的图像等也会一起删除 |
| 也移动页面外周 | 关闭“外周锁定”（初始为开启，外周上的角显示为灰色，无法移动） |

> **注意**
> 变形时只有所选的分格会移动。即使与相邻分格重叠或超出页面，也不会停止。如果结果不理想，请用“撤销”恢复。

> **提示**
> 已锁定（🔒）的分格无法分割或变形。子画格也不在分割、变形的范围内。

## 6-5 使用素材

把常用的图像，或制作好的对话气泡组合登记为“素材”，就可以从素材面板的“A”标签中快速放入。

### 把自己的图像文件夹作为素材

素材面板的“A”标签中，显示的是 Comic Creator 文件夹中 `assets` 文件夹的内容。

```
ComfyUI/custom_nodes/comfyui-comic-creator/assets/
└── （任意文件夹名）/
    ├── 背景01.png
    └── 效果线.png
```

1. 在 `assets` 文件夹中新建文件夹，放入图像（PNG、JPEG、WebP、SVG）。直接放在 `assets` 下的图像不会显示。
2. 点击素材面板的“↺”，图像就会显示在列表中。
3. 点击选择素材，然后点击“插入到分格”。

> **注意**
> 在素材面板中 Alt＋点击素材，确认后 **会连同电脑中的文件一起删除**（无法恢复）。

> **注意**
> `assets` 文件夹位于 Comic Creator 的文件夹中。删除并重新安装 Comic Creator 时，其中的素材也会消失。重新安装前，请把 `assets` 文件夹复制到其他位置。

### 把制作好的对象登记为素材

在排版标签页中制作的对话气泡、文字、图形，以及它们的组，都可以登记为素材。

| 要登记的对象 | 方法 |
| --- | --- |
| 组 | 图层面板中组所在行的 📦 按钮 |
| 单个对象（图像、对话气泡、文字、图形） | 只勾选一个复选框，然后点击上方的 📦+ 按钮 |

点击按钮后，选择或新建登记目标文件夹，输入文件名，点击“注册”。素材会立即显示在素材面板中。

登记的是对话气泡或文字时，之后“插入到分格”时，也会以可作为对话气泡或文字编辑的状态放入。

### 素材面板的其他标签

| 标签 | 用法 |
| --- | --- |
| P（页面） | 正在编辑的作品的页面列表。点击即可切换到该页面 |
| T（模板） | 选择后点击“作为页面插入”（或双击）来添加页面 |
| F（字体） | 在字体标签页中制作的样式列表。点击后会以文字的形式放入所选分格（选中文字时，会应用到该文字上）（第8章） |
| I（Image） | 在 Image 标签页中保存的图像项目。在排版标签页中，会把该图像放入分格（第9章） |

## 6-6 加工图像（图像子标签页）

在工具栏的“图像”中，可以对所选图像进行简单的加工。

| 项目 | 内容 |
| --- | --- |
| 去除背景 | 勾选后，保留人物等主体，把背景变为透明 |
| 模型 | 使用“轻量 (@imgly)” |
| 品质 | 低品质、轻量 (42MB)／标准品质 (84MB)／高品质 (168MB)。品质越高轮廓越干净，但首次下载的文件也越大 |
| 倍率 | 把图像放大到几倍（最多 4 倍） |
| 锐化 | 让轮廓更清晰的强度 |
| 降噪 | 勾选后减少颗粒感 |
| 执行 | 按上面的设置进行加工 |

1. 点击选择要加工的图像。
2. 设置各项目后点击“执行”。

加工后的图像会以与原图相同的位置、大小（旋转也相同）**作为新图像添加**，原图会自动 **隐藏**。原图并没有被删除，想比较时，可以用图层面板的 👁 重新显示。不需要的那张请删除。

> **注意**
> 去除背景在首次使用时需要下载模型，因此需要联网。另外，要使用“BiRefNet”模型，需要自定义节点“Mask Editor One”以及 BiRefNet 模型。没有安装时，“BiRefNet”会变灰，无法选择。

图像子标签页中还有以下按钮。

| 按钮 | 内容 | 本书章节 |
| --- | --- | --- |
| ↔ ↕ | 左右／上下翻转图像 | — |
| 在G'MIC GUI中编辑／插入结果 | 用外部软件 G'MIC 编辑图像 | 第12章 |
| ✨ PixiJS FX | 添加粒子或滤镜效果 | 第12章 |
| 🎨 网点 | 转换为网点（网点纸风格） | 第7章 |

> **本章小结**
> - 图像的放置位置有分格、覆盖层（全面）、草稿（全面）3种。草稿不会被导出
> - 用绿色控制点缩放（按住 Alt 自由变形），用黄色控制点旋转
> - 在图层面板中管理叠放顺序、显示、锁定、编组。Alt＋点击 👁 可以一次隐藏同类对象
> - 分格可以用“子画格”“分割”“变形”事后调整
> - 把图像放进 `assets` 文件夹下的子文件夹，就能从素材面板的“A”标签中使用
> - “图像”子标签页的加工结果会以与原图相同的位置、大小添加，原图会被隐藏（可用 👁 恢复）
