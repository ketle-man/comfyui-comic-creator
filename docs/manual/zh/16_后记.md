# 后记

感谢你读到最后。

Comic Creator 起源于“想把用 ComfyUI 生成的图像，直接做成漫画页面”这个想法。我让分格、对话气泡、台词到导出都能在一个界面中完成，并在此基础上一点点加入了图像编辑器以及与 AI 的联动。

本书从制作第一页开始，依次介绍了用 AI 制作作品，以及收尾效果。无需一次掌握所有功能。请从给一张图像加字、制作一部2页的短篇漫画这样的小作品开始尝试。

Comic Creator 仍在持续更新。如果本书与界面有不同之处，请同时参考应用内的“帮助”标签页。问题反馈和“希望增加这样的功能”之类的意见，欢迎在 GitHub 仓库中提出。

如果 Comic Creator 能对你的创作有所帮助，我将非常高兴。
