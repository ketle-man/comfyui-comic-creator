# 第1章 漫画制作基础知识

本章介绍使用 Comic Creator 时会出现的术语，以及作品完成前的整体流程。本章暂不进行操作，目的是帮助你把握全貌。

## 1-1 需要记住的术语

以下是 Comic Creator 的界面和本书中反复出现的术语。先掌握这些，后面的章节会更容易读懂。

| 术语 | 含义 |
| --- | --- |
| 作品 | 由若干页面组成的整体，相当于一本书或一话漫画。作品带有 **宽度和高度（纸张尺寸）** |
| 页面 | 作品中的一页。导出时会成为一张图像（或 PDF 的一页） |
| 模板 | 页面分格的样板。选择模板并点击“作为页面插入”，就会生成带有该分格的页面 |
| 分格 | 页面中的格子。图像、对话气泡、文字都放在分格中。超出分格的部分不会显示 |
| 覆盖层 | 覆盖整个页面的最前面一层。用于放置需要跨越分格边框的内容（例如大号的拟声词文字） |
| 草稿图层 | 位于覆盖层更前面、专门用于打草稿的一层。**不会包含在导出的图像中** |
| 对话气泡 | 用来放台词的气泡。有椭圆、圆角矩形、思考、爆炸、云朵等形状 |
| 图层 | 图像、对话气泡、文字等的叠放顺序。可在右侧的“图层面板”中调整叠放顺序 |

> **提示**
> 分格与覆盖层的区别在于“是否会被边框裁切”。放在分格中的图像会按分格的形状裁切；放在覆盖层上的内容会显示在整个页面上（不会超出页面之外）。

> **提示**
> 中文界面中，“分格”有时显示为“分镜”“画格”，“对话气泡”有时显示为“对话框”“气泡”。本书正文统一写作“分格”“对话气泡”，引用按钮名称时则以界面上的实际文字为准。

## 1-2 Comic Creator 能做什么

在 Comic Creator 中制作作品，按以下流程进行。

| 顺序 | 要做的事 | 使用的标签页 | 本书章节 |
| --- | --- | --- | --- |
| 1 | 创建作品（确定作品名和纸张尺寸） | “页面”标签页＞“作品管理” | 第4章、第5章 |
| 2 | 选择模板，作为页面插入 | “排版”标签页 | 第4章、第5章 |
| 3 | 在分格中放置图像 | “排版”标签页 | 第6章 |
| 4 | 添加对话气泡、台词、效果 | “排版”标签页 | 第7章 |
| 5 | 重复 2〜4，增加页面 | “排版”标签页 | 第4章 |
| 6 | 导出（PNG、PDF、EPUB 等） | “页面”标签页＞“输出” | 第5章 |

在这个基本流程的基础上，可根据需要组合以下操作。

| 想做的事 | 使用的标签页 | 本书章节 |
| --- | --- | --- |
| 想用图层精细加工图像，或给图像加字 | “Image”标签页 | 第9章 |
| 想选择字体，并保存文字的外观（描边字、阴影等） | “字体”标签页 | 第8章 |
| 想用 AI 生成图像 | “Nanobanana+”标签页、“MOSS-Image”标签页、Workflow Studio 联动 | 第10章 |
| 想读取图像中的文字，或把读取的文字用于排版 | “OCR”标签页 | 第10章 |
| 想先写脚本再生成页面，或用 AI 生成脚本和分格 | “脚本”标签页、“Auto”标签页 | 第11章 |

## 1-3 容易出错的地方

先把初学者容易困惑的地方总结如下。

### 作品数据保存在浏览器中

作品、页面、模板等数据，并不保存在 ComfyUI 的文件夹中，而是保存在 **打开 Comic Creator 的浏览器中**。

因此，在以下情况下，之前的作品不会显示（数据并没有消失）。

- 用了与平时不同的浏览器打开（例如：在 Chrome 中制作，却用 Edge 打开）
- 用了与平时不同的地址打开（例如：混用了 `127.0.0.1` 和 `localhost`，或端口号发生了变化）

> **注意**
> 如果在浏览器中“清除浏览数据”时删除了网站数据（Cookie 等），作品也会一起被删除。此外，作品无法直接迁移到另一台电脑。重要的作品请定期通过“设置”标签页的“备份与恢复”保存为 zip（第13章）。

### 作品尺寸与模板的关系

创建作品时设定的“宽×高”就是该作品页面的大小。插入模板时，模板会自动按作品尺寸伸缩。

尺寸的单位不是 mm，而是 **以 0.01mm 为 1 的数值**。例如 A4（210mm×297mm）为 `21000×29700`。从预设中选择的话，无需自己计算。

### 先打开作品再制作页面

原则上，应在打开作品的状态下制作页面。如果没有打开作品就插入模板并保存，该页面会进入“页面”标签页＞“作品管理”中“组”标签页里名为 **stock** 的组。它不会显示在“作品一览”中，找不到时请查看 stock。

### “保存”按钮的作用

排版标签页的“保存”按钮会保存当前显示的页面，并将页面登记到正在编辑的作品中。建议养成在编辑途中告一段落时点击保存的习惯，这样更放心。

### 作品名后面会附加日期时间

新建作品时，输入的作品名后面会附加创建日期时间（例如：`mycomic` → `mycomic_20261013153000`，即年月日时分秒共14位）。如果作品名留空，名称会是 `name`。这样即使多次创建同名作品也能区分。

> **本章小结**
> - 容器从大到小依次为 作品 ＞ 页面 ＞ 分格。模板是页面分格的样板
> - 覆盖层是位于整个页面最前面的一层，草稿图层是不会被导出的打草稿用图层
> - 基本流程是“创建作品 → 插入模板 → 图像・对话气泡・台词 → 导出”
> - 数据保存在浏览器中。换浏览器或换地址就看不到。别忘了备份
