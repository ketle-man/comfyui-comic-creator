# 第10章 用 AI 生成图像：Nanobanana+、Workflow Studio、MOSS-Image、OCR

第10章到第12章将一边制作一个示例作品，一边依次使用与 AI 联动的功能。

## 10-1 从本章开始制作的示例作品

示例作品是下面这样一部2页的短篇漫画。

| 项目 | 内容 |
| --- | --- |
| 作品名 | 猫咖啡馆的早晨 |
| 尺寸 | A4 纵向 |
| 页数 | 2页 |
| 登场人物 | 猫店员“三花”，以及第一次来店的客人 |
| 梗概 | 开店前的咖啡馆里，三花正在做早上的准备。这时客人却提前到了…… |

各章要做的事如下。

| 章 | 要做的事 |
| --- | --- |
| 第10章（本章） | 用 AI 制作背景和角色的图像，放入分格 |
| 第11章 | 编写脚本，用 AI 生成分格和台词 |
| 第12章 | 用 3D 姿势和效果进行收尾 |

首先，按照第4章的步骤创建作品“猫咖啡馆的早晨”（A4 纵向），并用3格的模板插入2页。

## 10-2 两种方法的区别

在 Comic Creator 中用 AI 生成图像的方法有两种。

| | Nanobanana | Workflow Studio 联动 |
| --- | --- | --- |
| 生成的地方 | Google 的服务器（Gemini API） | 自己电脑上的 ComfyUI |
| 需要的东西 | Gemini 的 API 密钥 | ComfyUI-Workflow-Studio，以及图像生成的模型、工作流 |
| GPU | 不需要 | 需要 |
| 费用 | 视用法可能产生 Google 的费用 | 不产生（只有电费） |
| 擅长的事 | 轻松尝试、用参考图像统一角色 | 用喜欢的模型生成、一边看分格一边重绘、局部修改 |

只使用其中一种也可以。本章会依次介绍两者。

> **提示**
> “Nanobanana+”标签页上方还有“本地”模式。可以在与 Nanobanana 相同的界面中，使用保存在 Workflow Studio 中的工作流（Flux.3 Image Klein、Qwen Image 2.1 等）（10-7）。

> **提示**
> 除此之外，还有使用 ComfyUI 本体所支持的图像生成模型的“MOSS-Image”标签页（10-6）。它同样在自己的电脑上运行，特点是可以指定物体、角色、台词的位置，一次生成整个页面。

> **注意**
> Gemini API 等海外服务，在部分国家或地区可能无法直接使用。请在遵守当地法律法规和服务条款的前提下使用。无法使用时，请使用在自己电脑上运行的 Workflow Studio 联动或 MOSS-Image。

## 10-3 Nanobanana 的准备

Nanobanana 是用 Google 的 Gemini API 生成图像的功能。使用时需要 API 密钥。标签页的名称是“Nanobanana+”（因为也可以使用本地工作流了。10-7）。本书把用 Gemini API 生成的用法称为“Nanobanana”模式。

1. 在 Google AI Studio 等处获取 Gemini 的 API 密钥（获取方法本书不作介绍）。
2. 在 Comic Creator 的文件夹中，新建一个名为 `.env` 的文件。

   ```
   ComfyUI/custom_nodes/comfyui-comic-creator/.env
   ```

3. 在 `.env` 中写入下面一行并保存（把 `你的API密钥` 部分替换为获取的密钥）。

   ```
   NANOBANANA_API_KEY=你的API密钥
   ```

4. 重启 ComfyUI。

打开“Nanobanana+”标签页，在选择上方“Nanobanana”的状态下，如果没有出现未设置 API 密钥的提示，就准备完成了。

> **注意**
> API 密钥是不能给别人看的重要信息。请不要把 `.env` 文件交给他人，也不要公开到网上。

> **注意**
> `.env` 在 ComfyUI 启动时读取。写入或修改密钥后，请务必重启 ComfyUI。

### 切换生成方式：ComfyUI 原生节点

Nanobanana 除了用自己的 Gemini API 密钥生成之外，还可以使用 ComfyUI 本体的 Nano Banana 节点。在“设置”标签页的“Nanobanana 设置”中的“生成方式”里切换。

| 生成方式 | 内容 | 需要的东西 |
| --- | --- | --- |
| Gemini API（自己的API密钥）（默认） | 直接用 Google 的 Gemini API 生成。历史记录写入 `history.jsonl` | `.env` 中的 `NANOBANANA_API_KEY` |
| ComfyUI原生节点（Comfy积分） | 用 ComfyUI 本体的 Nano Banana 节点生成。会消耗 Comfy 积分 | `.env` 中的 `COMFY_API_KEY`（在 platform.comfy.org 发行） |

这个设置除了 Nanobanana+ 标签页之外，对脚本标签页的半自动漫画，以及 Auto 标签页（图像生成引擎为 Gemini 时）也同样有效。Nanobanana+ 标签页的基本设置中也有同样的选择栏，与设置标签页联动。

| 区别 | 内容 |
| --- | --- |
| 历史记录 | 原生节点会把生成条件嵌入输出的 PNG 中，因此不会自动记录历史，也不显示“记录到历史”按钮 |
| 保存位置 | Nanobanana+ 标签页的图像保存在 `ComfyUI/output/cc_nanobanana_native/` |
| 不能使用的模型 | 不支持 Nano Banana Pro（gemini-3-pro-image）。Nano Banana 2 Lite 仅支持 1K |

> **注意**
> `COMFY_API_KEY` 同样需要写入 `.env` 并重启 ComfyUI 后才会生效。没有密钥时，连接状态会显示“未设置COMFY_API_KEY”。

## 10-4 用 Nanobanana 制作背景和角色

### 制作背景

界面分为左右两部分。左侧是提示词和基本设置，右侧是参考图像（Image-to-Image）。上方的标签页名称下有“Nanobanana／本地”的切换，子标签页有“生成设置”和“Nanobanana历史”2个。

1. 打开“Nanobanana+”标签页，选择上方的“Nanobanana”。
2. 输入 Positive Prompt（对想要生成的图像的描述）。英文或中文都可以。
   ```
   氛围安静的咖啡馆店内，清晨的光线，木质吧台，漫画背景，黑白
   ```
3. 选择“模型”和“分辨率”（纵横比）。分格是横长形时，选择 3:2 或 16:9。
4. 点击“生成图像”。稍等片刻会显示结果。

| 项目 | 内容 |
| --- | --- |
| 模型 | gemini-3.1-flash-lite-image ／ gemini-3.1-flash-image ／ gemini-3-pro-image ／ gemini-nano-banana-2.1 |
| 分辨率 | 纵横比（1:1、2:3、3:2、9:16、16:9） |
| 输出分辨率 | 1K（默认）／2K／4K。不支持的模型可能仍为 1K |
| 生成数量 | 一次生成的张数 |
| Negative Prompt | 对不想出现的内容的描述 |

### 放入分格

1. 在“排版”标签页中，点击选择要放背景的分格（例如：第1页的第1格）。
2. 回到“Nanobanana+”标签页，点击结果下方的“插入到分格”。

> **注意**
> “生成数量”设为2张以上时，结果下方会排列缩略图。点击缩略图选中的图像会显示在预览中，并通过“插入到分格”放入（初始选中第1张）。生成的图像也会全部保留在下面的保存文件夹中。

生成的图像会自动保存到 ComfyUI 的以下文件夹。

```
ComfyUI/output/cc_nanobanana/
```

### 用参考图像统一角色（I2I）

漫画中，需要在多个分格中画同一个角色。在界面右侧的“Image-to-Image”中放入参考图像，就可以一边参考该图像一边生成，更容易统一角色的外观。

1. 首先，制作一张三花的全身图。
   ```
   三花猫女孩角色，咖啡馆店员的围裙，全身，白色背景，漫画风格
   ```
2. 在右侧的“Image-to-Image”中，点击“添加图像”，添加刚才制作的三花图像（最多14张。也可以把电脑中的图像拖放到这里添加）。
3. 在左侧的 Positive Prompt 中写下场景并生成。
   ```
   参考图像中的角色正在吧台冲咖啡。漫画分格，黑白
   ```

> **提示**
> Gemini 的图像生成没有用数值决定“在多大程度上改变原图”的设置。变化的强度通过提示词的写法来调整（例如“只改变姿势”“服装保持不变”）。

### 保留历史记录

开启“生成时自动记录到历史”后，会记录生成的日期时间、模型、提示词等。即使关闭，也可以用结果中的“记录到历史”只记录满意的结果。记录可以在“历史”子标签页中查看。

> **提示**
> 历史记录以每行一条的形式追加到 `ComfyUI/output/cc_nanobanana/history.jsonl` 中。应用内无法删除，想删除时，请用文本编辑器打开这个文件，删除对应的行。

## 10-5 与 Workflow Studio 联动

安装了 ComfyUI-Workflow-Studio（以下简称 Workflow Studio）后，就可以用自己的 ComfyUI 生成图像。在 Comic Creator 中，可以一边看页面和分格一边下达生成指令。

> **注意**
> Workflow Studio 的用法，以及模型和工作流的准备，本书不作介绍。请在 Workflow Studio 中准备好可以生成图像的状态。

### 排版标签页的“Generate”

点击排版标签页操作栏中的“Generate”，会打开生成界面。

| 项目 | 内容 |
| --- | --- |
| 对象 | 选中图像／整页／选中标签（见下表） |
| 提示词标签 | “全体”以及“分格1”“分格2”…的标签。可以为每个分格写不同的提示词 |
| T2I | 开启后，不使用当前图像，仅根据文字重新生成。关闭（默认）时以当前图像为基础重新生成（I2I） |
| Denoise | I2I 时，与原图相比改变的程度（越大变化越大） |
| batch | 仅在“整页”时显示。开启后按分格依次生成 |
| Run | 开始生成 |

| 对象 | 使用的提示词 | 结果放入的位置 |
| --- | --- | --- |
| 选中图像 | “全体”标签 | 作为新图像添加 |
| 整页（batch 关闭） | “全体”标签 | 以整页大小添加到覆盖层（适合确认草图） |
| 整页（batch 开启） | “全体”＋各分格的标签 | 以分格大小添加到各分格 |
| 选中标签 | 仅所选分格的标签 | 以分格大小添加到该分格 |

> **注意**
> 无论哪种对象，原图都不会消失，生成的图像会叠加在其上方。不需要的原图，请在图层面板中删除。

### 用示例试一试：按分格重绘

用每个分格的提示词来生成第1页的3个分格。

1. 打开“Generate”，在“对象”中选择“整页”，开启“batch”和“T2I”。
2. 在“全体”标签中写下整个作品的氛围。
   ```
   manga style, monochrome, cafe interior, morning
   ```
3. 在“分格1”“分格2”“分格3”标签中分别写下各自的场景。
   ```
   分格1：wide shot of an empty cafe before opening
   分格2：a calico cat girl in an apron wiping the counter
   分格3：the door opens, surprised cat girl
   ```
4. 点击“Run”。会从分格1开始依次生成，并放入分格。

只重新生成效果不理想的分格时，把“对象”设为“选中标签”，选择该分格的标签后点击“Run”。

> **提示**
> 先用第11章的“Auto”生成脚本，就可以用“从Auto获取”把脚本中各分格的“背景描写・表演指示”自动填入分格的标签。

> **提示**
> 在界面下方的“工作流设置”中指定 I2I 用、T2I 用的工作流文件名后，每次生成时都会自动读取该工作流。不指定时，使用 Workflow Studio 中当前打开的工作流。

### 在 Image 标签页中局部修改

在 Image 标签页中，可以使用 Workflow Studio，只用 AI 重绘图像的一部分（第9章）。

| 功能 | 位置 | 内容 |
| --- | --- | --- |
| I2I | Select 工具右侧的面板 | 以整体（All）或所选图层（Layer）为基础重新生成。结果成为新图层 |
| Inpaint | Mask 工具 | 只重绘蒙版中涂白的范围 |
| Outpaint | Mask 工具 | 在上下左右添加边距，在图像外侧扩展绘制 |

例如：三花的手形不自然时，用 Mask 工具涂抹手的部分，在“Inpaint”中输入“cat paw holding a coffee cup”等，然后点击“Run”。

### 其他联动

| 功能 | 内容 |
| --- | --- |
| “workflow studio”标签页 | 显示 Workflow Studio 的图库。用上方的“ws刷新”重新加载，用“在新标签页打开ws”在另一个标签页中打开 |
| Image 标签页的“wsI2I” | 把正在编辑的图像发送到 Workflow Studio 的 I2I 输入。在 Workflow Studio 的图库中点击“Send CC（Image）”，结果会返回 Image 标签页（有正在编辑的图层时作为新图层，没有时作为新画布）。需要 Workflow Studio v0.8.11 以上 |

### 与 Ollama 同时使用时

一边用本地 AI（Ollama）生成脚本一边生成图像时，GPU 的内存（显存）可能会不足。在“设置”标签页的“显存调整（Ollama）”中，可以设置在生成图像之前先卸载 Ollama 的模型（第13章）。

## 10-6 用 MOSS-Image 标签页生成整页

“MOSS-Image”标签页是使用 ComfyUI 本体所支持的图像生成模型“MOSS-Image”，在自己的电脑上生成图像的功能。不需要 Comfy 积分，也不需要 API 密钥。

最大的特点是“排版编辑器”。可以在图像中放置“物体”“角色”“文字”的框（矩形），指定在哪里画什么。连台词和拟声词的位置都可以决定，因此可以一次生成整个页面（分格和台词）。

### 需要的东西

- 支持 MOSS-Image 的 ComfyUI（旧版 ComfyUI 会显示“ComfyUI 不支持”。请更新 ComfyUI）
- 把模型文件放入 ComfyUI

| 种类 | 放置位置 | 文件示例 |
| --- | --- | --- |
| 扩散模型 | `ComfyUI/models/diffusion_models/` | `moss_image_sft_int8_convrot.safetensors` 等 |
| 文本编码器 | `ComfyUI/models/text_encoders/` | `qwen3.5_9b_w4a8_gptq.safetensors` |
| VAE | `ComfyUI/models/vae/` | `flux2-vae.safetensors` |
| LoRA（可选） | `ComfyUI/models/loras/` | 高速生成用的 DMD 8step 等 |

标签页上方会显示“MOSS-Image：可用”“MOSS-Image：未找到模型”“ComfyUI 不支持”“MOSS-Image：无法连接 ComfyUI”中的一种状态。刚放入模型后，请点击“重新加载模型列表”。

> **提示**
> 模型的文件名和获取途径，请在模型的发布页面确认。本书不作介绍。MOSS-Image 官方支持的语言是英文和中文，因此中文台词也可以作为文字绘制。但框中的文字不一定能准确画出，生成后请务必确认。

### 界面构成

| 位置 | 内容 |
| --- | --- |
| 左 | 排版编辑器。绘制框，放置物体、角色、文字 |
| 中 | “提示词”“JSON”“模型・采样器”3个标签 |
| 右 | 生成图像的按钮、种子、结果、放到页面上的按钮 |

### 第一张图：生成整页

1. 在“排版”标签页中，打开已经放入台词的页面。
2. 打开“MOSS-Image”标签页，在中央“提示词”标签的“生成对象”中，把模式设为“整页”。
3. 点击左侧的“导入当前页面的分镜”。页面的分格会作为“物体”框放入，画布会按页面的纵横比（约 2MP）改变。
4. 点击“导入气泡和台词”。放有台词的对话气泡会作为“文字”框放入。
5. 在“提示词”中写下对整幅图像的描述（建议用英文）。
6. 点击右侧的“生成图像”。
7. 出现结果后，点击“布局覆盖层”。图像会放入整页的覆盖层。不满意的地方，可以用“在Image标签页中打开”送到 Image 标签页中修改。

> **提示**
> 想避免在图像中画出文字时，勾选“生成图像”下方的“禁用文字生成”。这个设置不会删除布局中的文字框，只是在生成时不发送。整体提示词中含有“封面”“杂志”“排版”之类的词时，更容易画出文字。

> **提示**
> 优先考虑速度时，在“模型・采样器”标签的预设中选择“高速 DMD 8步”（需要 LoRA）。标准为 50 步，比较耗时。

### 生成模式

| 模式 | 作用 |
| --- | --- |
| 整页 | 把整个画布作为一张图生成，结果放到整个页面（用布局指定所有分格和文字） |
| 按分镜 | 对所选的每个分格，按分格的纵横比生成，并放入该分格。可以输入每个分格的内容（建议用英文） |
| 自由尺寸 | 只生成，不放置 |

### 排版编辑器的用法

用上方的“绘制类型”选择要画物体（绿色）、角色（粉色）、文字（浅蓝色）、分镜（黄色）中的哪一种，然后在画布上拖动绘制框。

| 操作 | 作用 |
| --- | --- |
| 在空白处拖动 | 以所选类型绘制新框 |
| 拖动框的边缘、编号、选中框的内部 | 移动框 |
| 拖动框的角 | 放大、缩小框 |
| 按住 Shift 键点击框（不拖动） | 把该框加入（或移出）当前选择。选中的框可以一起移动 |
| 在未选中框的内部拖动 | 在其上方绘制新框（可以在分格上放置台词框） |
| 点击未选中框的内部 | 选择该框 |
| 按住 Shift 键拖动 | 任何时候都绘制新框 |
| Delete 键 | 删除选中的框 |
| Ctrl＋Z（或“撤销”按钮） | 恢复删除的框 |

用“置于顶层”“置于前面”“置于后面”“置于底层”改变叠放顺序（“置于顶层”“置于底层”会一次移到最上、最下）。点击绘制类型左侧的“新建”，会删除所有框，回到空白状态。选中框后，中央会出现“选中的元素”，可以修改类型、描述（caption，建议用英文）等。

### 只移动框时：“选择”

选择绘制类型最左侧的“选择”后，拖动（包括 Shift＋拖动）也不会绘制新框。可以防止本想移动框却画出了小框。

| 操作（“选择”时） | 作用 |
| --- | --- |
| 拖动框的内部 | 即使是未选中的框，也会直接移动 |
| 拖动框的角 | 放大、缩小框 |
| 点击空白处 | 取消选择（不绘制框） |

要绘制框时，重新选择“物体”“分镜”“角色”“文字”中的一种。所选类型会保存在浏览器中，下次打开时保持不变。

### 撤销删除

用删除按钮右侧的“撤销”（或 Ctrl＋Z），可以把删除的框恢复到原来的位置和叠放顺序。最多可以追溯到30次之前。

- 可以恢复的，是用删除按钮、Delete 键、“新建”、“清除导入”删除的框。
- 恢复的只有删除操作。删除之后移动了其他框，这些移动会保留。
- 执行“导入当前页面的分镜”等导入操作，或从 OCR 标签页发送后，之前的删除将无法恢复。
- 可恢复的记录在重新加载页面后会消失。

### 文字框

- “文字”框在绘制后可以直接在框中输入文字。按 Esc／Ctrl＋Enter／点击框外确定（Enter 为换行）。
- 快速点击文字框两次，可以重新输入。
- 可以设定字号（图像上的 px）。框会配合输入文字的大小（为估算值）。
- “文字”右侧的“横排”“竖排”是之后要绘制的框的书写方向。绘制后要修改时，在“选中的元素”的“书写方向”中修改。

> **提示**
> MOSS-Image 的机制中没有竖排的指定，因此竖排的框会在描述（caption）末尾自动加上指示竖排的英文。可以在 JSON 标签中确认。

> **注意**
> 文字为空的“文字”框在生成时不会发送（发送后可能在该位置画出类似带格线的纸张）。在界面上以浅色虚线显示。

### 从页面导入

| 按钮、项目 | 作用 |
| --- | --- |
| 导入当前页面的分镜 | 把当前打开页面的分格边框作为框导入。勾选“以 panel 标签导入分镜”时为“分镜”类型（黄色），取消勾选时为“物体” |
| 导入气泡和台词 | 把带台词的对话气泡，以对话气泡轮廓大小的“文字”框导入。也会继承对话气泡的形状（普通、思考、喊叫等）、竖排和文字大小 |
| 同时导入没有气泡的文字（默认开启） | 用文字工具放置的、不在对话气泡中的文字也作为“文字”框导入 |

- 导入的框按阅读顺序（从上到下，同一行从右到左）排列。
- 重新导入时，只会替换之前导入的框，自己添加的框会保留。
- 点击“清除导入”，只会删除导入的分格、对话气泡、台词框，自己绘制的框会保留。用旧版本导入的分格框不会被删除，这时请使用“新建”。
- 画布的纵横比与页面不同时，会确认是否让现有的框也按页面缩放。
- 导入的框即使修改了文字也不会缩小（“使框适应文字大小”为关闭）。
- 旋转过的文字，会以旋转后的外接矩形导入。MOSS-Image 的框无法表示旋转。
- 不在对话气泡中的文字，其描述（caption）全部为“旁白”。以前会把6个字以下的文字当作拟声词，但名字等也会被当成拟声词，因此已经取消。想让它作为拟声词绘制时，请在“选中的元素”的描述（caption）中用英文补充说明这是拟声词。

### 种子的行为

用右侧的“种子”选择每次图像的变化方式。

| 行为 | 内容 |
| --- | --- |
| 随机（默认） | 每次用不同的种子生成。不使用输入框中的值 |
| 固定 | 用输入框中的值生成。设置相同时会得到相似的结果 |
| 每次生成+1 | 从输入框中的值开始，每次生成加1 |

随机使用的种子会显示在“上一次的种子”中。出现满意的图像时，点击旁边的“固定此种子”，就会切换为固定。

### 其他设置

- 勾选“提示词扩展”后，会先用 ComfyUI 的文本编码器（LLM）把简短的指示改写为详细的英文描述，然后再生成。适合只想用一句话试试的情况。在使用布局框的“整页”模式中无效（因为会破坏框的指定）。改写后的文章不会显示在界面上。
- 中央的“JSON”标签显示实际发送的内容（布局 JSON）。勾选“直接编辑并发送 JSON”后，可以直接发送手写的 JSON（忽略布局）。
- 在“模型・采样器”标签中，选择预设（标准、轻量、高速 DMD 8步、高速 Turbo 4步），以及模型、LoRA、步数、CFG 等。
- 生成的图像保存在 ComfyUI 的 `output/cc_moss/` 中。
- 设置和布局保存在浏览器中，重新打开后也会恢复。
- “设置”标签页的“显存调整（Ollama）”（第13章）在 MOSS-Image 生成前也会生效。

## 10-7 Nanobanana+ 的本地模式

在“Nanobanana+”标签页上方的“Nanobanana／本地”切换中选择“本地”后，可以在自己电脑上的 ComfyUI 中，使用保存在 Workflow Studio 中的工作流生成图像。特点是可以在与 Nanobanana 相同的界面（提示词、参考图像、结果、“插入到分格”）中使用。不需要 Gemini 的 API 密钥。

> **注意**
> 本地模式需要 Workflow Studio（支持此功能的版本），以及准备好可以生成图像的工作流。工作流的制作方法和模型的安装方法，本书不作介绍。

### 注册工作流

1. 在“Nanobanana+”标签页上方选择“本地”。
2. 点击旁边出现的“⚙”（齿轮按钮）。
3. 选择“显示名”（例如：Flux.3 Klein）和保存在 Workflow Studio 中的工作流，点击“添加”。可以注册多个。
4. 点击“关闭”，在下拉菜单中选择要使用的工作流。

可以注册的是带有用于放入图像的 LoadImage 节点的 Image Edit 类工作流（例如：Flux.3 Image Klein、Qwen Image 2.1）。注册的内容保存在浏览器中。

### 用法

1. 在左侧写下 Positive Prompt。
2. 在右侧的“Image-to-Image”中放入参考图像（作为基础的图像）。在本地模式中，**最多可以放入工作流能使用的张数**（上限可以通过“Image-to-Image”标题中的“(张数/上限)”确认）。
3. 点击“生成图像”。结果与 Nanobanana 一样保存在 `ComfyUI/output/cc_nanobanana/` 中，可以用“插入到分格”使用。

参考图像会从第1张开始依次放入工作流的图像输入。

| 工作流 | 可以放入的图像 |
| --- | --- |
| Qwen Image 2.1（图像输入最多10个） | 最多10张。会根据放入的张数自动增减输入（也可以只放1张图像，当作“替换”来用） |
| 图像输入数量固定的工作流（Flux.3 Image Klein 等） | 最多到该数量。超出的部分不会使用，并显示警告 |

> **提示**
> 即使注册的工作流像“Qwen2.1（2张）”这样只有2个图像输入，只要是 Qwen Image 2.1 的工作流，第3张以后的图像也会被使用。

### 基本设置与种子

| 项目 | 内容 |
| --- | --- |
| 生成数量 | 一次生成的张数。多张时，种子每张 +1 |
| 图像尺寸 | 工作流默认／预设／自定义 |
| Steps、CFG、采样器、调度器、Denoise | 保持“默认”或留空时，直接使用工作流中的值 |
| 种子 | 随机／固定／每次生成+1（与 MOSS-Image 标签页相同）。用“上一次的种子”和“固定此种子”可以复现满意的结果 |

> **注意**
> 有些工作流中，图像尺寸等设置可能不起作用。例如 Flux.3 Image Klein 的输出尺寸由输入图像决定。提示词和图像、Steps、CFG、种子是有效的。

在“Nanobanana”模式中可以看到模型、分辨率、API 密钥、历史记录等，在本地模式中这些会被隐藏（种子只在本地模式中显示）。

## 10-8 用 OCR 标签页读取图像中的文字和位置

“OCR”标签页是读取图像中的文字，并连同其位置（框）一起列出的功能。不仅是漫画页面，杂志封面和海报也能读取。读取的结果可以作为 MOSS-Image 标签页的布局发送，或者以文字形式放入排版标签页或 Image 标签页。

文字和框的检测使用 Ollama（本地 AI）的模型。不需要云端的 API 密钥。

### 需要的东西

- Ollama 正在运行（连接目标在界面的“URL”中指定。默认为自己的电脑）
- 读取文字的模型。按如下方式安装（模型名称在界面的“OCR模型”中选择）。

  ```
  ollama pull maternion/LightOnOCR-3:4b
  ```

- 用于“布局检测”的支持图像的模型（默认为 `gemma4:e4b`）。用于获取分格、角色、对话气泡等的框。
- 想更准确地读取竖排或装饰文字时，可以准备用于重新识别的模型（可选。见下面的“重新识别”）。

标签页上方会显示“OCR: 可用”“OCR: 未找到 OCR 模型”“OCR: 无法连接 Ollama”中的一种状态。刚放入模型后，请点击“重新加载模型列表”。

> **提示**
> OCR 模型和布局检测模型主要是在日文漫画上进行验证的。中文图像也可以读取，但准确度因模型而异，请实际确认结果。

### 界面构成

| 位置 | 内容 |
| --- | --- |
| 左 | 要读取的图像，以及检测出的框。把图像拖放（或用 Ctrl＋V 粘贴）到这里 |
| 右上 | “模式”和各种设置（模型、重新识别、判定、整图识读、整体提示词、检测类别） |
| 右下 | “执行检测”、检测结果列表、复制以及发送到 MOSS-Image |

### 第一次读取

1. 把图像拖放到左侧的框中（也可以用“打开图像”选择）。
2. 在右侧的“模式”中，选择适合该图像的模式（拿不准时选“自动（推荐）”）。
3. 点击“执行检测”。稍等片刻，图像上会显示框，右侧的“检测结果”中会列出文字。
4. 识别错误的文字，可以直接在列表的文字栏中修改。框可以拖动移动，拖动角来放大、缩小。

### 修改框：“选择”“绘制”和“撤销”

图像上方的工具栏中有用来修改框的按钮。

| 按钮 | 作用 |
| --- | --- |
| 选择／绘制 | “绘制”时，在空白处拖动会绘制“绘制类型”的框。“选择”时，拖动也不会绘制框，点击只会取消选择（框的移动、缩放两种模式下都可以）。改变“绘制类型”后会回到“绘制” |
| 删除 | 删除选中的框（按 Delete 键也一样）。按住 Shift 键点击可以选择多个框 |
| 全部清除 | 删除所有框 |
| 撤销 | 恢复用删除、全部清除删除的框（按 Ctrl＋Z 也一样。最多30次之前）。打开其他图像或重新检测后，之前的删除将无法恢复 |

选择了“选择”还是“绘制”，会保存在浏览器中。

> **注意**
> 第一次使用的模型，加载需要时间。切换模型时，GPU 的内存（显存）也可能不足。“设置”标签页的“显存调整（Ollama）”（第13章）开启时，会在检测前卸载 Ollama 的其他模型。

### 模式

选择右上的“模式”后，下方的各项设置会一并切换。手动修改各项设置后，会自动变为“自定义”。

| 模式 | 适合的图像 | 内容 |
| --- | --- | --- |
| 自动（推荐） | 拿不准时 | 纵横比极端时选择长页面，否则由 AI 看图选择。无法判定时选“漫画页面”。实验性功能 |
| 漫画页面 | 有分格的漫画 | 除了检测文字，还检测分格、角色、对话气泡等的框。也会进行重新识别、类型判定、整体提示词 |
| 杂志封面、海报 | 彩色背景上密集排列大小文字的图像 | 只检测文字。失败时会自动以黑白（灰度）重试。也会进行整图识读和整体提示词 |
| 仅文字（文档、招牌） | 以文字为主的图像 | 只检测文字，速度最快的设置。也会进行整图识读 |
| 插画（无文字） | 没有文字的画、照片 | 不读取文字，生成分格、角色、脸部、物体的框和整体提示词 |
| 长页面（分块读取） | 纵向很长的页面（Webtoon 等） | 纵向分块读取，再还原位置合并 |
| 自定义 | 想自己细致设定时 | 直接使用各项设置 |

### 检测内容与框的类型

框有类型（类别）。可以在列表左侧的选择栏中事后修改。

| 类型 | 内容 |
| --- | --- |
| text | 读取的文字本身。由 OCR 模型检测 |
| balloon／sfx／caption | 对话气泡、拟声词、旁白框（放文字的框）。由布局检测（另一个 AI）获取 |
| panel／character／face／object | 分格、角色、脸部、物体（画面的框）。由布局检测获取 |

用“检测类别”的勾选，选择布局检测要查找的对象（文字由 OCR 负责，总会被检测）。

### 提高准确度的设置

| 设置 | 内容 |
| --- | --- |
| 裁剪文字框并用另一个模型重新识别 | 把检测出的文字框逐个裁剪，用另一个模型重新识别。擅长竖排和装饰文字。框越多耗时越长。重新识别用的模型推荐 `ollama pull hf.co/LunarOilRig/PaddleOCR-VL-manga-GGUF:Q4_K_M`（专门针对漫画的 PaddleOCR-VL） |
| 重新识别所选框 | 只重新识别选中的框（工具栏的按钮） |
| 检测后用决策模型判定裁剪图（可选） | 用支持图像的判定模型，判定文字框的类型（对话气泡、旁白框、拟声词、文字），并去除没有文字的框。比较耗时，仅在需要时使用 |
| OCR 预处理 | 在杂志封面等密集的图像中，OCR 结果为空或同一个词重复时，会自动转为灰度并重试一次 |
| 整图识读（Chat TE / ComfyUI） | 见下一节 |
| 整体提示词 | 用2〜3句英文描述整幅图像。开启时，发送到 MOSS-Image 后，提示词会被替换为这段文字。可以手动修改 |

### 用整图识读（Chat TE）准确读取竖排

像杂志封面这样有很多竖排大标题的图像，OCR 模型可能读不出来。这时很方便的是“整图识读（Chat TE / ComfyUI）”。

它使用 ComfyUI 的自定义节点“Chat TE”（[comfyui-chat-te](https://github.com/ketle-man/comfyui-chat-te)），让 AI（Qwen3-VL）一次读取整幅图像中的文字。实际用4张杂志封面测试，竖排文字用整图识读比 OCR 模型能读出更多。但是，整图识读 **只能得到文字，无法得到位置**。因此，会把读到的文字与 OCR 的框进行比对，只替换框中的文字。没有匹配到任何框的行，会保留在这一栏中。

1. 事先把 Chat TE 安装到 ComfyUI 中（安装方法请参考 Chat TE 的说明）。
2. 确认“整图识读（Chat TE / ComfyUI）”一栏的“URL”中填写的是 ComfyUI 的地址（默认为当前打开的 ComfyUI）。
3. 在“模型”中，选择 Qwen3-VL-8B（没有的话选 4B）的文本编码器。
4. 勾选“用 Chat TE 读取整张图片，并替换文字框中的文字”，然后点击“执行检测”。模型会在需要时自动加载。

点击“仅执行整图识读”，可以只对已检测的图像执行整图识读。读到的文字会显示在下方的栏中（没有框时，所有行都会原样保留）。

> **提示**
> 在“杂志封面・海报”和“仅文字”模式中，这个勾选会自动开启（找不到 Chat TE 的模型时为关闭）。

> **注意**
> 整图识读会在 ComfyUI 端加载很大的模型。如果 Ollama 的模型还留在 GPU 的内存中，可能会加载失败。开启“显存调整（Ollama）”会更放心。

> **注意**
> 整图识读的模型（Qwen3-VL-8B 约 10GB）与 MOSS-Image 等图像生成的模型同时载入 GPU 内存时，在 GPU 内存约 12GB 的电脑上，ComfyUI 可能会报错停止（一旦停止，在重启 ComfyUI 之前都无法生成）。因此从 v1.69.0 开始，会按以下方式自动整理。即使“显存调整（Ollama）”为关闭也会执行。
>
> - 整图识读之前，卸载 ComfyUI 中已加载的图像生成模型。ComfyUI 正在生成时，会等待其结束（显示“正在等待 ComfyUI 完成生成…”）。
> - 整图识读之后生成图像时，会在生成前卸载整图识读的模型。在整图识读过程中开始生成时，会等整图识读结束后再生成。
>
> 刚切换后的第一次，加载模型会多花几秒钟。

### 结果的用法

| 按钮 | 作用 |
| --- | --- |
| 复制全文 | 按阅读顺序（从上到下，从右到左）复制读取的文字 |
| 复制JSON | 以 JSON 复制框的位置、类型、文字 |
| 发送到MOSS-Image标签页 | 把检测结果作为物体、分镜、角色、文字的框放入 MOSS-Image 的布局（10-6）。上一次从 OCR 导入的部分会被替换。用“将文字合并到气泡/拟声词/旁白框”的勾选，选择是否把框中的文字合并为一个 |

点击排版标签页的“文字”工具，或 Image 标签页文字工具的“Insert”，会打开“插入文字”界面。在插入来源中选择“OCR（OCR标签页检测到的文字）”，就可以把检测到的文字以文字形式放到框的位置（第7章、第9章）。

> **提示**
> 读取的文字和框是每张图像的临时结果。请先完成发送到 MOSS-Image、复制、作为文字放入等想要的用途，再处理下一张图像。

> **本章小结**
> - Nanobanana（Nanobanana+ 标签页的“Nanobanana”模式）用 Google 的 Gemini API 生成。在 `.env` 中写入 `NANOBANANA_API_KEY` 并重启 ComfyUI
> - 用 Nanobanana 生成2张以上时，从缩略图中选择的图像会通过“插入到分格”放入。所有图像也会保留在 `output/cc_nanobanana` 中
> - 在右侧的“Image-to-Image”中放入参考图像，更容易统一角色的外观
> - 有 Workflow Studio 的话，可以用排版标签页的“Generate”按分格生成。原图会保留在下方
> - 用 Image 标签页的 Inpaint、Outpaint，可以局部修改或扩展绘制
> - 在设置标签页的“Nanobanana 设置”中，可以切换 Gemini API 和原生节点（`COMFY_API_KEY`）
> - MOSS-Image 标签页用物体、角色、文字的框指定位置，在自己的电脑上生成整个页面。可以导入页面的分格和对话气泡、台词
> - 布局的“新建”会删除所有框，“清除导入”只删除导入的框。叠放顺序也可以用“置于顶层”“置于底层”修改
> - 在 Nanobanana+ 的“本地”模式中，可以用 Workflow Studio 的工作流生成。Qwen Image 2.1 会按放入的图像张数（最多10张）增减输入
> - OCR 标签页用 Ollama 的模型读取图像中的文字和位置。竖排较多的封面，用“整图识读（Chat TE）”替换文字更容易读准。结果可以发送到 MOSS-Image，或作为文字放入
> - MOSS-Image 和 OCR 的框，切换为“选择”后拖动也不会绘制。删除的框可以用“撤销”（Ctrl＋Z）恢复
> - 连续使用整图识读（Chat TE）和图像生成时，ComfyUI 的模型会自动切换（刚切换后会多花几秒钟）
