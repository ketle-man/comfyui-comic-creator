# 付録

## A 用語集

| 用語 | 意味 | 本書の章 |
| --- | --- | --- |
| 作品 | 幅と高さを持つ、ページのまとまり | 第1章・第5章 |
| ページ | 作品の中の1枚 | 第1章 |
| テンプレート | ページのコマ割りのひな形 | 第4章・第5章 |
| コマ | ページの中の枠。中のものはコマの形で切り取られる | 第1章 |
| サブコマ | コマの中に作る小さなコマ | 第6章 |
| オーバーレイ | ページ全体を覆う手前の層 | 第6章 |
| 下書きレイヤー | いちばん手前の下描き用の層。書き出されない | 第6章 |
| stock | 作品に入っていないページが入る、最初からあるグループ | 第5章 |
| アセット | アセットパネルから入れられる素材 | 第6章 |
| フキダシ | セリフを入れる吹き出し | 第7章 |
| 延長フキダシ | くびれでつながった、続きのフキダシ | 第7章 |
| 袋文字 | 文字の外側を太く縁取った文字 | 第7章・第8章 |
| スタイル | 文字の見た目（塗り・線・袋文字・影など）の設定 | 第8章 |
| プリセット | フォント＋サイズ＋スタイルをまとめた設定 | 第8章 |
| マスク | 画像の一部を隠す・見せるための層 | 第7章・第9章 |
| ハーフトーン | 網点。スクリーントーンのような点の模様 | 第7章 |
| レイヤー | 画像や文字を重ねる層 | 第6章・第9章 |
| 調整レイヤー | 下の画像の明るさや色を、元の画像を変えずに調整する層（Image タブ） | 第9章 |
| T2I | 文章から画像を作ること（Text to Image） | 第10章 |
| I2I | 画像を元に画像を作り直すこと（Image to Image） | 第10章 |
| Inpaint | 画像の一部だけを AI で描き直すこと | 第10章 |
| Outpaint | 画像の外側を AI で描き足すこと | 第10章 |
| Denoise | I2I で、元の画像からどれだけ変えるかの度合い | 第10章 |
| API キー | Gemini などのサービスを使うための、自分専用の鍵 | 第10章 |
| ローカル LLM | 自分のパソコンで動かす文章生成 AI（Ollama など） | 第11章 |
| 意思決定モデル | 文章を作らず、質問に確率つきで答える AI | 第11章 |
| VRAM | GPU のメモリ | 第13章 |
| dpi | 1インチあたりの点の数。印刷の細かさ | 第5章 |

## B キーボード・マウス操作

### レイアウトタブ

| 操作 | 動き |
| --- | --- |
| Delete／Backspace | 選んでいる画像・フキダシなどを削除 |
| Alt＋ハンドルのドラッグ | 画像の縦横比を変えて変形 |
| Shift＋青いハンドルのドラッグ | 文字を斜めにゆがめる |
| レイヤーパネルの 👁 を Alt＋クリック | 同じ種類のものをまとめて表示／非表示 |
| ダブルクリック（文字・フキダシ） | 文字を入力し直す |
| ダブルクリック（画像） | Image タブで開く |
| Ctrl＋Enter | 「テキスト入力」画面で確定（Esc で閉じる） |
| Esc（多角形・ベクター曲線） | 直前の点を取り消す |
| Enter（ベクター曲線） | 閉じずに描き終える |

レイアウトタブでは、元に戻すのは操作バーの「元に戻す」ボタンを使います。

### MOSS-Image タブ（レイアウトエディタ）

| 操作 | 動き |
| --- | --- |
| Shift＋ドラッグ | いつでも新しい枠を描く |
| Delete | 選んでいる枠を削除 |
| Esc／Ctrl＋Enter | 文字枠の入力を確定 |
| 文字枠をすばやく2回押す | 文字を入力し直す |

### ページタブ

| 操作 | 動き |
| --- | --- |
| Ctrl（Mac は ⌘）＋クリック | ページを複数選ぶ |
| 作品カードのダブルクリック | 作品を開く |

### Image タブ

| キー | 動き |
| --- | --- |
| V／B／T／S／G | Select／Draw／Text／Shape／Fill に切り替える |
| Space＋ドラッグ | 表示位置を動かす |
| Ctrl＋Z／Ctrl＋Y | 元に戻す／やり直す |
| Delete／Backspace | 選んでいるレイヤーを削除（Select ツール） |
| Enter／Ctrl＋Enter | 文字の入力欄で改行／確定 |
| Esc | スポイトをやめる |

### 3D ポーズ・3D テキスト

| 操作 | 動き |
| --- | --- |
| 左ドラッグ／右ドラッグ／ホイール | カメラの回転／移動／ズーム |
| 青い球のドラッグ | 関節を回す（Alt＋上下で Z 軸） |
