# 第12章 応用・紹介編

この章では、別のカスタムノードや外部ソフトと組み合わせて使う機能を紹介します。サンプル作品「ねこカフェの朝」の仕上げに使う例で、流れを説明します。

| 機能 | 必要なもの | サンプルでの使い道 |
| --- | --- | --- |
| 3D ポーズ | comfyui-vrm-pose-editor と、VRM などの3Dモデル | お客さんのポーズを決めて、作画の下描きにする |
| 3D テキスト | comfyui-vrm-pose-editor | 1ページ目のタイトル文字を立体にする |
| PixiJS FX | comfyUI-particle-pixijs | コーヒーの湯気やキラキラを足す |
| 動画ツール（実験的） | なし（Workflow Studio から送る場合は Workflow Studio） | 動画から1コマを切り出す |
| Eagle 連携 | 画像管理ソフト Eagle | 作った画像を Eagle に整理して保存する |
| G'MIC 連携 | 画像処理ソフト G'MIC（G'MIC Qt） | 画像に G'MIC のフィルタをかける |

> **注意**
> この章の機能は、それぞれのカスタムノードやソフトの使い方には深入りしません。くわしくは、それぞれの説明書を見てください。

## 12-1 3D ポーズ・3D テキスト

### 3D ポーズ：モデルにポーズを付けてコマに入れる

VRM・GLB・GLTF 形式の3Dモデルをコマに置き、ポーズを付けて、画像としてコマに入れます。人物の下描きや、構図を決めるのに便利です。

1. ポーズを入れたいコマをクリックして選びます。
2. ツールペインの「3Dポーズ」を押し、「コマに配置」を押します。コマの上に、赤い枠の3Dの画面が重なって表示されます。
3. モデルが表示されていなければ、「モデル読込」でパソコンの .vrm／.glb／.gltf ファイルを読み込みます。
4. ポーズとカメラを調整します。
5. 「コマに確定」を押すと、その見た目が画像としてコマに入ります。

［画像：3D ポーズでポーズを付けているところ］

| 操作 | 方法 |
| --- | --- |
| カメラを回す／動かす／寄る | 左ドラッグ／右ドラッグ／ホイール |
| 関節を回す | 青い球をドラッグ（左右＝Y軸、上下＝X軸、Alt＋上下＝Z軸） |
| ポーズを左右反転 | 「↔ ミラー」 |
| ポーズを保存・読み込む | 「ポーズ保存」（JSON をダウンロード）／「ポーズ読込」 |
| 詳しく編集 | 「🎛 Editor」。ポーズライブラリ、ライト、表情、キーフレームなど |

> **ポイント**
> comfyui-vrm-pose-editor の `model/` フォルダに3Dモデルを置いておくと、「コマに配置」で最初に開いたときに自動で読み込まれます。

> **ポイント**
> サンプルでは、2ページ目でお客さんがドアを開けるポーズを作り、「コマに確定」した画像を下描きにします。Image タブで線を描き足したり、第10章の「Generate」（I2I）でマンガ風の絵にしたりできます。

### 3D テキスト：立体の文字

文字（日本語も可）や SVG の形を、立体的に押し出した画像にしてコマに入れます。

1. 文字を入れたいコマ（またはオーバーレイ）を選びます。
2. ツールペインの「3Dテキスト」を押し、「コマに配置」を押します。最初は "text" という文字が立体で表示されます。
3. 「⚙ 3D設定」を押し、右の「テキスト」欄に文字を入力して、フォント・色・ライトなどを調整します。
4. 「厚み」「面取り」で立体の感じを調整します。
5. 「コマに確定」を押します。

| 項目 | 内容 |
| --- | --- |
| テキスト／SVG | 文字を立体にするか、SVG ファイルの形を立体にするか |
| 厚み | 押し出しの厚さ |
| 面取り | 角を斜めに削って、光沢を出す |
| ⚙ 3D設定 | テキスト・フォント・整列・行間、マテリアル（色・質感・表面と側面の色）、ライト、カメラ |

確定した画像をダブルクリック（または「再編集」）すると、同じ設定で作り直せます。

> **ポイント**
> サンプルでは、1ページ目のオーバーレイに「ねこカフェの朝」のタイトルを3Dテキストで入れると、表紙らしいページになります。

## 12-2 PixiJS FX：パーティクルとフィルタ

comfyUI-particle-pixijs を入れていると、画像にパーティクル（粒子）やフィルタの効果を合成できます。

| 開く場所 | 結果 |
| --- | --- |
| レイアウトタブの「画像」サブタブ ＞「✨ PixiJS FX」 | 背景を透明のまま確定すると、パーティクルだけの画像が新しく追加される。背景を表示して確定すると、選んでいる画像が結果に置き換わる |
| Image タブのアクションバー ＞「✨ PixiJS FX」 | 選んでいるレイヤーの内容が、結果に置き換わる |

1. 効果を付けたい画像を選び、「✨ PixiJS FX」を押します。
2. プレビューの空いているところをクリックして、発生点（エミッター）を置きます。
3. 形・大きさ・広がり・風などを調整し、「▶ 再生」で動きを確認します。
4. 「■ 停止 & キャプチャ」で、その瞬間を静止画として確定します。

［画像：PixiJS FX の画面］

「🎬 フィルタライブラリ」からは、色調整・ぼかし・グリッチ・エンボスなどのフィルタを重ねてかけられます。組み合わせはプリセットとして保存できます。

> **ポイント**
> サンプルでは、2コマ目のコーヒーカップの上に発生点を置き、湯気のようなパーティクルを足してみましょう。

## 12-3 動画ツール（実験的な機能）

MP4 の動画をコマに置いて再生し、好きなフレームを静止画として切り出せます。

1. MP4 ファイルをコマにドラッグ＆ドロップします。最初のフレームがコマに表示され、レイヤーパネルに 🎬 で表示されます。
2. レイヤーパネルで動画を選び、ツールペインの「動画」を押します。
3. ▶ 再生・■ 停止・シークバーで、使いたい場面を探します。
4. 「このフレームで静止画作成」を押すと、その場面が画像として同じコマに追加されます。

Workflow Studio のギャラリーで動画を選んで「Send CC」を押しても、コマに送れます。

> **注意**
> 動画ツールは実験的な機能で、MP4 だけに対応しています（アニメーション GIF は使えません）。動画のファイルは ComfyUI 側に保存され、削除しない限り残ります。

## 12-4 外部ソフトとの連携：Eagle・G'MIC

### Eagle：画像を整理して保存する

画像管理ソフト「Eagle」に、作った画像を保存できます。

1. Eagle を起動しておきます。
2. 「設定」タブの「Eagle 設定」で、Eagle API URL（最初は `http://localhost:41595`）を確認します。
3. Image タブのアクションバーの「Eagle」を押すと、ファイル名を付けて Eagle に保存されます。

「Eagle 設定」では、Nanobanana で生成した画像や、G'MIC で処理した結果を、自動で Eagle に保存するようにもできます。

> **ポイント**
> 「Eagle 設定」の「ComfyUI 生成画像を自動保存」はグレーで、ここでは選べません。Generate や I2I など、Workflow Studio 経由で作った画像を自動で Eagle に保存したいときは、Workflow Studio の設定タブ＞「Eagle」で「生成画像をEagleに自動保存」にチェックを入れてください。

### G'MIC：たくさんのフィルタを使う

画像処理ソフト「G'MIC」（G'MIC Qt）の画面を開いて、G'MIC のたくさんのフィルタを画像にかけられます。

1. G'MIC Qt をパソコンに入れます。
2. 「設定」タブの「G'MIC 設定」で、G'MIC Qt の実行ファイル（`gmic_qt.exe`）の場所を、フォルダを含めた形（フルパス）で入力して保存します。ComfyUI の再起動はいりません。
3. レイアウトタブなら、画像を選んで「画像」サブタブの「G'MIC GUIで編集」を押します。Image タブなら、Filter（★）ツールを使います。
4. G'MIC の画面でフィルタを選び、適用して閉じます。
5. レイアウトタブでは「結果を挿入」を押すと、結果が新しい画像としてコマに入ります（元の画像は残ります）。

> **注意**
> 指定した場所に G'MIC Qt が見つからないときは、「G'MIC 設定」に赤字の警告が出ます。

> **この章のまとめ**
> - 3D ポーズ・3D テキストは comfyui-vrm-pose-editor が必要。「コマに配置」→ 調整 →「コマに確定」
> - PixiJS FX は comfyUI-particle-pixijs が必要。発生点を置いて再生し、「停止 & キャプチャ」で確定
> - 動画ツールは MP4 をコマに置き、「このフレームで静止画作成」で1コマを切り出す
> - Eagle・G'MIC は「設定」タブで接続先を設定してから使う
