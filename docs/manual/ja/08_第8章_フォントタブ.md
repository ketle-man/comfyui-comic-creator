# 第8章 フォントタブ

「フォント」タブでは、使えるフォントを見比べて選び、文字の見た目（スタイル）を保存しておけます。保存したスタイルは、レイアウトタブや Image タブでクリック1つで使えます。

画面は3つの領域に分かれています。

| 場所 | 役割 |
| --- | --- |
| 左 | フォントの一覧（Google／システム／カテゴリ） |
| 中央 | プレビューと、スタイル・プリセットの作成 |
| 右 | 選んだフォントの情報、タグ・カテゴリの管理、適用ボタン |

## 8-1 フォントを探して見比べる

### フォントの種類

左の一覧の上で、表示するフォントを切り替えます。

| タブ | 中身 |
| --- | --- |
| Google | あらかじめ登録された Google Fonts の一覧 |
| システム | パソコンに入っているフォント。「システムフォントを読み込む」を押して読み込む |
| カテゴリ | 自分で分類したフォント（8-2） |

一覧の上の検索欄に名前を入れて「検索」を押すと、フォントを絞り込めます。

> **注意**
> システムフォントの読み込みは、Chrome や Edge で使えます。はじめて読み込むときに、ブラウザがフォントへのアクセスを許可するか聞いてくるので、「許可」を選んでください。ほかのブラウザでは、システムフォントの一覧が表示されないことがあります。

> **注意**
> Google Fonts のフォントは、インターネットから読み込みます。オフラインのときは、まだ読み込んでいないフォントが表示されないことがあります。

### プレビューの切り替え

中央の上のタブで、プレビューの内容を切り替えます。

| タブ | 内容 |
| --- | --- |
| 基本 | 英語・ひらがな・カナ・漢字・数字・記号のサンプル。チェックボックスで表示する文字の種類を選ぶ |
| 文章 | 横書き・縦書きの例文 |
| カスタム | 好きな文字を入れてプレビュー。日本語用と英語用で別のフォントを指定できる |
| カテゴリ一覧 | 選んだカテゴリのフォントを全部並べて比べる |
| スタイル | スタイル・プリセットの作成（8-3） |

「サイズ」や、横書き・縦書きの表示（横・縦 同時／横のみ／縦のみ）も変えられます。

## 8-2 タグとカテゴリで整理する

フォントが多くて探しにくいときは、タグやカテゴリで整理します。左の一覧でフォントを選ぶと、右にフォントの名前が表示されます。

### カテゴリ

カテゴリは、フォントを入れる「棚」のようなものです。「手書き風」「セリフ用」「効果音用」のように分けておくと、レイアウトタブでもカテゴリから選べます。

1. 右の「+ カテゴリ」を押し、カテゴリ名を入れて作ります。
2. 左の一覧でフォントを選びます。
3. 右のセレクトでカテゴリを選び、「追加」を押します。

カテゴリから外すときは「解除」、カテゴリ自体を消すときは「- カテゴリ」を押します。

### タグ

タグは、フォントに付けるメモのような目印です。「タグ追加」の欄にタグを入れて、選んだフォントに付けます。作ったことのあるタグは一覧に出るので、クリックで付けられます。

## 8-3 スタイルとプリセットを作る

### スタイルとプリセットの違い

| 名前 | 中身 | 使いどころ |
| --- | --- | --- |
| スタイル | 文字の見た目（塗り・線・袋文字・影など）。フォントは含まない | 「赤い袋文字」「影付き」など、フォントを問わず使う見た目 |
| プリセット | フォント＋サイズ＋縦書きかどうか＋スタイル | 「セリフ用」「効果音用」など、毎回同じ設定で使う文字 |

### スタイルを作る

1. 中央の「スタイル」タブを開きます。
2. 「プレビュー文字」に確認したい文字を入れます。
3. 塗り・線・袋文字・影などを設定します。項目は、レイアウトタブの「スタイル」画面と同じです（第7章 7-2）。
4. 名前を入れて「保存」を押します。

| 項目 | 内容 |
| --- | --- |
| 塗り | 単色・グラデーション・テクスチャ。チェックを外すと塗りなし |
| 線 | 文字の輪郭線 |
| 太字・斜体・下線 | 文字の飾り |
| 行間・上下・文字寄せ | 複数行の並び方 |
| 袋文字 | 文字の外側の太い縁取り |
| 影 | 影の色・ぼかし・影位置（X・Y） |

保存したスタイルは「登録済み」から選ぶと、読み込んで直せます。

| 操作 | 結果 |
| --- | --- |
| 名前を変えずに「保存」 | 上書きされる |
| 名前を変えて「保存」 | 元のスタイルはそのままで、別のスタイルとして保存される |
| 「新規」 | 入力欄を空にして、新しく作り始める |
| 「削除」 | 選んでいるスタイルを削除する |

### プリセットを作る

1. 左の一覧で、プリセットに使うフォントを選びます。
2. 「スタイル」タブの下の「プリセット」欄で、「サイズ(pt)」、縦書きかどうか、使うスタイルを選びます。
3. 名前を入れて「保存」を押します。

操作の方法（登録済みから選ぶ・別名で保存・削除）は、スタイルと同じです。

## 8-4 作ったスタイルを使う

### レイアウトタブで使う

保存したスタイルとプリセットは、レイアウトタブのアセットパネル「F」タブに、見本の画像（サムネイル）で並びます。

| 状態 | サムネイルをクリックすると |
| --- | --- |
| 文字を選んでいない | 選んでいるコマの中央に、新しい文字として入る |
| 文字を選んでいる | その文字にスタイル（プリセット）が適用される |

サムネイルの上の「背景」で、見本の背景色（デフォルト・黒・白・グレー・手動）を変えられます。白い文字のスタイルなどが見にくいときに切り替えます。

> **ポイント**
> スタイルのサムネイルは、見た目を比べやすいように、すべて同じフォント（Zen Antique）で表示されます。プリセットのサムネイルは、登録したフォントで表示されます。

### フォントタブから直接使う

右の「選択テキストに適用」を押すと、レイアウトタブで選んでいる文字に、選んだフォントを適用します。

### Auto の既定フォントに設定する

右の「オートレイアウト」の欄にある「既定フォントに設定」を押すと、選んでいるフォントが、Auto タブのオートレイアウトで使う既定のフォントになります（第11章）。確認なしですぐに保存されます。

> **ポイント**
> 書き出すときは、使ったフォントが自動でファイルに埋め込まれます（SVG・PNG など）。フォントが入っていないパソコンで見ても、同じ見た目になります。

> **この章のまとめ**
> - 左でフォントを選び、中央でプレビュー。システムフォントは Chrome・Edge で「システムフォントを読み込む」
> - カテゴリで「セリフ用」「効果音用」などに分けておくと、レイアウトタブでも探しやすい
> - スタイル＝見た目だけ、プリセット＝フォント＋サイズ＋スタイル
> - 保存したスタイルは、アセットパネルの「F」タブからクリック1つで使える
