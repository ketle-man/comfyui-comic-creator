# 第4章 はじめての1ページ

この章では、実際に手を動かして、マンガを1ページ作って PNG 画像として書き出すところまでを行います。細かい設定はあとの章に回して、まずは最後まで通してみましょう。

この章で行うことは、次の7つです。

| 順番 | やること | 使うタブ |
| --- | --- | --- |
| 4-1 | コマ割りのテンプレートを1つ作る | 「ページ」タブ＞「テンプレート」 |
| 4-2 | 作品を作る | 「ページ」タブ＞「作品管理」 |
| 4-3 | テンプレートをページとして挿入する | 「レイアウト」タブ |
| 4-4 | コマに画像を入れる | 「レイアウト」タブ |
| 4-5 | フキダシとセリフを入れる | 「レイアウト」タブ |
| 4-6 | 保存して、ページを増やす | 「レイアウト」タブ |
| 4-7 | PNG で書き出す | 「ページ」タブ＞「作品管理」＞「出力」 |

用意するもの：コマに入れる画像を2〜3枚（ComfyUI で生成した画像など。PNG や JPEG）。

## 4-1 コマ割りのテンプレートを作る

Comic Creator をはじめて起動すると、「A4縦_3コマ」と「A4横_3コマ」のテンプレートが自動で登録されます。ここでは、ウィザードの使い方を知るために、テンプレートを1つ自分で作ってみます。そのまま「A4縦_3コマ」を使ってもかまいません。

1. 「ページ」タブを開き、上の「テンプレート」サブタブを選びます。
2. 「テンプレートを作成」を押します。ウィザードが開きます。

   ［画像：テンプレート作成ウィザードの最初の画面（ページの向き・幅・高さ・フレーム幅）］

3. 「ページの向き」で「縦長」を選びます。幅・高さ・フレーム幅は、最初はそのままでかまいません。
4. 「ベースを作成」を押します。ページの形をした白い枠（キャンバス）が表示されます。
5. 「分割モード」が「全体分割」になっていることを確認します。
6. キャンバスの上で、左から右へ横にドラッグして線を引きます。線の位置でコマが2つに分かれます。

   ［画像：キャンバスに線を引いてコマを分割したところ］

7. 同じようにして、下のコマを縦の線で2つに分けてみましょう。このとき「分割モード」を「単一コマ分割」に切り替えると、線を引き始めたコマだけが分割されます。
8. 3コマになったら、「テンプレートとして保存」を押します。
9. テンプレート名を聞かれるので、`3コマ` のように分かりやすい名前を入力して OK を押します。

テンプレートの一覧に、作ったテンプレートが表示されれば完了です。

> **ポイント**
> 線を引き間違えたときは「1つ戻す」、最初からやり直したいときは「最初からやり直す」を押します。

> **ポイント**
> 「ガイドグリッド」にチェックを入れるとキャンバスに格子線が表示され、「スナップ」にチェックを入れると線の端が格子にくっつきます。コマの大きさをそろえたいときに便利です。

## 4-2 作品を作る

次に、ページを入れる「作品」を作ります。

1. 「ページ」タブの「作品管理」サブタブを選びます。
2. 「新規作成」を押します。「作品を新規作成」の画面が開きます。

   ［画像：「作品を新規作成」ダイアログ］

3. 「作品名」に名前を入力します。例：`はじめての作品`
4. 「サイズ」で用紙の大きさを選びます。ここでは「A4 縦 (210×297mm)」を選びます。
5. 「作成」を押します。

作品が作られ、自動で「レイアウト」タブに切り替わります。この時点では、まだページは0枚です。

> **ポイント**
> 作品名の後ろには、作成した日時が自動で付きます（第1章 1-3）。

## 4-3 テンプレートをページとして挿入する

作った作品に、4-1 のテンプレートでページを追加します。

1. 「レイアウト」タブの左端、アセットパネルの「T」（テンプレート）タブを押します。
2. 4-1 で作ったテンプレートをクリックして選びます。
3. アセットパネルの下にある「ページとして挿入」を押します。

   ［画像：アセットパネルの T タブでテンプレートを選び「ページとして挿入」を押すところ］

プレビューに、3コマのページが表示されます。テンプレートは、作品のサイズ（A4縦）に合わせて自動で伸び縮みしています。操作バーのページ番号が「1 / 1」になっていることも確認しましょう。

> **注意**
> 「ページ」タブ＞「テンプレート」サブタブには「クイック」というボタンもあります。選んだテンプレートから1ページをすぐに作り、レイアウトタブで開くボタンです。ただし、テンプレートの大きさのままページを作り、作品には自動で登録されません。作品にページを足すときは、**「ページとして挿入」** を使ってください。

## 4-4 コマに画像を入れる

いちばん かんたんなのは、パソコンのフォルダから画像をドラッグ＆ドロップする方法です。

1. エクスプローラー（Mac では Finder）で、画像が入っているフォルダを開きます。
2. 画像ファイルを、プレビューの中の入れたいコマの上までドラッグして、離します。

   ［画像：画像ファイルをコマにドラッグ＆ドロップしたところ］

画像はコマの左上にそろえて、コマの幅いっぱいの大きさで入ります。コマからはみ出した部分は見えません。

### 画像の位置と大きさを直す

| やりたいこと | 操作 |
| --- | --- |
| 位置を動かす | 画像をドラッグする |
| 大きさを変える | 画像を選ぶと周りに出るハンドル（丸い点）をドラッグする |
| コマの中央に置く | 画像を選んで、操作バーの「OC」を押す |
| 間違えたので取り消す | 操作バーの「元に戻す」を押す |
| 画像を消す | 画像を選んで、操作バーの「削除」を押す（Delete キーでも消せる） |

残りのコマにも、同じように画像を入れましょう。

> **ポイント**
> 一度にドロップできる画像は1枚です。複数のファイルをまとめてドロップしても、入るのは最初の1枚だけです。

> **注意**
> ドロップするときは、入れたいコマの上で離してください。コマの外（ページの余白など）で離すと、前に選んでいたコマや、ページ全体を覆うオーバーレイに入ることがあります。

## 4-5 フキダシとセリフを入れる

### フキダシを置く

1. ツールペインの「フキダシ」を押します。
2. プレビューで、フキダシを置きたいコマをクリックして選びます。コマが青い枠で囲まれます。
3. 「種類」で「通常 (楕円)」を選びます。
4. 「挿入」を押します。選んだコマの中央にフキダシが置かれます。

   ［画像：フキダシを挿入したところ（ハンドル付き）］

フキダシの周りのハンドルをドラッグすると、大きさを変えられます。尻尾（とがった部分）の向きと長さは、「尻尾」の「角度」「長さ」で変えます。

> **ポイント**
> フキダシを挿入すると、「編集: ON」に切り替わり、フキダシを動かしたり形を変えたりできる状態になります。「編集: OFF」にすると、フキダシを誤って動かさなくなります。

### セリフを入れる

1. セリフを入れたいフキダシをクリックして選びます。
2. 「テキストを内包」を押します。「テキストを内包」の画面が開きます。

   ［画像：「テキストを内包」の画面］

3. 「テキスト」にセリフを入力します。改行もできます。
4. 縦書きにしたいときは「縦書き」にチェックを入れます。
5. 「文字サイズ」などを調整して、「作成」を押します。

セリフはフキダシの中に、自動で折り返して入ります。あとで直したいときは、フキダシをダブルクリックすると、もう一度この画面が開きます。

## 4-6 保存して、ページを増やす

### 保存する

操作バーの「保存」を押します。表示中のページが保存され、作品に登録されます。

> **ポイント**
> 画像やフキダシの操作は、その都度ブラウザの中に記録されています。それでも、区切りのよいところで「保存」を押す習慣をつけておくと安心です。

### 2ページ目を作る

1. アセットパネルの「T」タブで、テンプレートを選びます。
2. 「ページとして挿入」を押します。2ページ目ができ、ページ番号が「2 / 2」になります。
3. 4-4・4-5 と同じように、画像とフキダシを入れて「保存」を押します。

操作バーの「◀」「▶」で、1ページ目と2ページ目を行き来できます。

## 4-7 PNG で書き出す

できあがったページを、PNG 画像として書き出します。

1. 「ページ」タブの「作品管理」サブタブを開きます。
2. 左の作品一覧で、いま作った作品をクリックして選びます。
3. 上の「出力」ボタンを押します。「出力」サブタブに切り替わり、この作品のページだけが一覧に表示されます。

   ［画像：出力サブタブ（左に設定、右にページ一覧）］

4. 「形式」で「PNG」を選びます。
5. 「出力ページ」に、書き出すページの範囲を入力します。2ページとも書き出すなら `1` 〜 `2` にします。
6. 「保存」を押します。
7. 保存先を聞かれたら、保存する場所を選びます。

> **注意**
> 「出力ページ」には、一覧のページ数に合わせて「1 〜 最後のページ」が自動で入ります。一部のページだけ書き出すときは、範囲を変えてください。

> **注意**
> 「出力」サブタブを、「作品管理」の「出力」ボタンを使わずに開いたときも、作業中の作品があれば、その作品のページだけが一覧に並びます。ほかの作品も含めたすべてのページを並べたいときは、一覧の上に出る絞り込み表示の「解除」を押してください。「出力ページ」の番号は、一覧に並んでいる順番になります。

> **ポイント**
> 複数のページを書き出すとき、Chrome や Edge では保存先のフォルダを1回だけ聞かれ、ページごとのファイルがそこに保存されます。「zip保存」にチェックを入れると、全ページを1つの zip ファイルにまとめて保存できます。

書き出した PNG を画像ビューアーで開いて、ページができていることを確かめましょう。これで、はじめての1ページは完成です。

> **この章のまとめ**
> - 最初から「A4縦_3コマ」「A4横_3コマ」が入っている。自分で作るときは「ページ」タブ＞「テンプレート」＞「テンプレートを作成」
> - 作品は「ページ」タブ＞「作品管理」＞「新規作成」で作る。作ると「レイアウト」タブに切り替わる
> - ページは、アセットパネルの「T」タブ＞「ページとして挿入」で作品に足す
> - 画像はコマにドラッグ＆ドロップ。フキダシは「フキダシ」＞「挿入」、セリフは「テキストを内包」
> - 書き出しは「作品管理」で作品を選んで「出力」。「出力ページ」の範囲を必ず確認する
