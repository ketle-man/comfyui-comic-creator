# 第11章 脚本から作る：スクリプトタブと Auto

この章では、サンプル作品「ねこカフェの朝」の脚本を作り、セリフとフキダシをページに流し込みます。

## 11-1 2つの方法

| | スクリプトタブ | Auto タブ |
| --- | --- | --- |
| 脚本を書く人 | 自分 | AI（できたものを自分で直す） |
| AI | なくても使える | ローカル LLM（Ollama など）または Gemini が必要。ただし「サンプル」は AI なしで試せる |
| コマ割り | 先にレイアウトタブでテンプレートを入れたページに流し込む | 脚本から自動で作る |
| できあがり | 今ある作品のページに、フキダシとセリフが入る | 新しい作品として、コマ割り・フキダシ入りのページができる |

第10章で作った作品にセリフを入れたいときはスクリプトタブ（11-2・11-3）、脚本からまとめて作りたいときは Auto（11-4〜11-6）を使います。

## 11-2 スクリプトタブで脚本を書く

### 作品を作る

1. 「スクリプト」タブを開きます。
2. 「新規作成」を押します。
3. 「作品名」に `ねこカフェの朝` と入力し、「メディア種別」で「漫画」を選びます。

> **注意**
> メディア種別は、作ったあとは変えられません。「漫画」と「半自動マンガ」は同じ画面で、保存されるデータが別々になるだけです。「小説」「脚本」は v1.53.2 では開発中で、プロットの画面は使えません。

> **ポイント**
> 左のアセットパネル「S」の「ページ作品」で、ページタブの作品名をクリックしてから「新規作成」を押すと、その名前が作品名に入ります。

### 登場人物を登録する（要素）

「要素」サブタブで、登場人物や固有名詞を登録しておくと、プロットで選ぶだけで入力できます。

1. 「要素」サブタブを開き、「＋ 要素追加」を押します。
2. 要素に `ミケ`、詳細に `三毛猫の店員。しっかり者だが朝に弱い` のように入力します。
3. 同じように `お客さん` も登録します。

右側の欄には、作品全体のあらすじを書けます。

### プロットを書く

「プロット」サブタブで、ページごと・コマごとに脚本を書きます。

［画像：スクリプトタブのプロット（シーン・コマ番・画像プロンプト・セリフ番・要素・セリフ/説明等・フキダシ形状）］

| 列 | 書くこと |
| --- | --- |
| シーン | そのページで起きること（ページの全行にまたがって表示） |
| コマ番 | コマの番号 |
| 画像プロンプト | そのコマの絵の説明（画像生成に使う） |
| セリフ番 | コマの中のセリフの番号 |
| 要素 | 話す人。要素で登録した名前から選べる（自由入力も可） |
| セリフ/説明等 | セリフや、コマの状況説明 |
| フキダシ形状 | 既定・通常(楕円)・角丸矩形・思考(泡)・バクダン・雲(もこもこ)・雲(なみなみ) |

サンプルの1ページ目は、たとえば次のように書きます。

| コマ | 要素 | セリフ | フキダシ形状 |
| --- | --- | --- | --- |
| 1 | （ナレーション） | 開店30分前 | 角丸矩形 |
| 2 | ミケ | ふわぁ…今日もがんばるにゃ | 通常(楕円) |
| 3 | ミケ | えっ！？もうお客さん！？ | バクダン |

| 操作 | 方法 |
| --- | --- |
| ページを移る | ◀ ▶ |
| ページを足す・消す | 「＋ ページ追加」／「ページ削除」 |
| コマ数を変える | 「コマ数」の ▲ ▼（最初は4コマ） |
| コマ数をレイアウトに合わせる | 「コマ数取得」。レイアウトタブで表示中のページのコマ数に合わせる |
| セリフの行を足す・消す | 行をクリックして選び、セリフの「＋」「−」 |

> **ポイント**
> 「画像プロンプト」の横の「L」ボタンを押すと、Workflow Studio の AI 設定（Ollama など）を使って、シーンやセリフから画像プロンプトの案を作れます。

### 保存する

作品名を入れて「保存」を押します。保存した作品は、アセットパネル「S」の「保存済み作品」から選んで「読込」で開けます。

「プレビュー 横」「プレビュー縦」サブタブでは、全ページの脚本を読みやすい文章の形で確認できます。

> **注意**
> スクリプトの作品は、ブラウザの中に保存されます。バックアップ（第13章）にも含まれます。

## 11-3 脚本をページに流し込む

スクリプトタブの脚本から、レイアウトタブのページにフキダシとセリフを自動で入れます。

1. 「レイアウト」タブで、作品「ねこカフェの朝」の1ページ目を表示します（テンプレートを入れておきます）。
2. 「スクリプト」タブに戻り、プロットの1ページ目を表示します。
3. 「コマ数取得」を押して、コマ数をレイアウトのページに合わせます。
4. 「このページをレイアウトに流し込む」を押します。コマ番号ごとの対応が一覧で表示されます。
5. 「フキダシを自動生成」を押します。セリフの入っているコマに、セリフの数だけフキダシが作られ、レイアウトタブに切り替わります。

［画像：フキダシを自動生成したページ］

フキダシの形は「フキダシ形状」の列のとおりになり、「既定」のままの行は角丸矩形になります。フキダシと文字の大きさは、セリフの量に合わせて自動で決まります。あとは第7章の方法で、位置や形を整えます。

> **注意**
> コマの対応は、コマ番号の順番だけで決まります。脚本とページのコマ数が違うと警告が出て、少ないほうの数だけ対応します。先に「コマ数取得」で合わせておきましょう。

### 画像もまとめて作る

スクリプトタブには、各コマの「画像プロンプト」から画像をまとめて作るボタンもあります。

| ボタン | 使うもの |
| --- | --- |
| 画像を一括生成（T2I） | Workflow Studio（文章から作る） |
| 画像を一括生成（I2I） | Workflow Studio（今の画像を元に作り直す） |
| 画像を一括生成（Nanobanana） | Nanobanana（第10章） |

> **注意**
> Workflow Studio を使う機能は、Comic Creator の中の「workflow studio」タブに埋め込まれた Workflow Studio を使います。ブラウザの別のタブで開いた Workflow Studio でワークフローを切り替えても、反映されません。

## 11-4 Auto の準備

「Auto」タブでは、お題から AI がストーリーと脚本を作り、さらにコマ割りまで自動で作ります。

### AI エンジンを設定する

1. 「Auto」タブを開き、右のペインの「設定」タブを選びます。
2. 「AIエンジン」で「ローカルLLM」か「Gemini」を選びます。
3. 必要な項目を設定し、「設定を保存」を押します。

| AI エンジン | 設定すること |
| --- | --- |
| ローカルLLM | BACKEND（Ollama／LM Studio／Lemonade／Unsloth）、URL、MODEL。「接続テスト」で確認できる |
| Gemini | Gemini モデル。API キーは Nanobanana と共通（`.env` の `NANOBANANA_API_KEY`） |

> **注意**
> ローカル LLM の URL は、Comic Creator を開いているアドレスに合わせてください。`127.0.0.1` で開いているなら `http://127.0.0.1:11434`（Ollama の場合）のようにします。`localhost` と混ざると、ブラウザに止められて「Failed to fetch」になることがあります。

> **注意**
> Gemini は使った量に応じて料金がかかります。

> **ポイント**
> AI を用意していなくても、11-5 の「サンプル」で、Auto の流れを最後まで試せます。

## 11-5 Auto でストーリーと脚本を作る

### ストーリーを作る

1. 「ストーリー・脚本」サブタブで、「お題・プロンプトを入力」を押します。
2. お題とページ数を入力して、「作成」を押します。

   ```
   お題：開店前の猫カフェで、三毛猫の店員ミケが朝の準備をしていると、お客さんが早く来てしまうほのぼのコメディ
   ページ数：2
   ```

3. 中央の「ストーリー」タブに、タイトル・登場人物・あらすじ・ページ配分が作られます。直接書き直してもかまいません。

> **ポイント**
> AI がないときは、お題の画面で「サンプル」を押します。用意されたお題（宇宙飛行士の柴犬の話）で、ストーリーと2ページ分の脚本がすぐに読み込まれます。

> **ポイント**
> ストーリーや脚本は、「設定」タブで選んでいる表示言語で書くように AI に指示されます。

### 脚本を作る

1. 中央の「脚本」タブで、「ストーリーから脚本を作成」を押します。
2. ページ → コマ → セリフの形で脚本ができます。

［画像：Auto の脚本タブ］

| コマの項目 | 内容 |
| --- | --- |
| 重要度 | 高・中・低。オートレイアウトでコマの大きさを決めるのに使う |
| 背景描写・演技指示 | そのコマの絵の説明（下描きのガイド、画像生成のプロンプトにも使える） |
| セリフ | 話者・本文・フキダシの種類 |

ページ・コマ・セリフは、追加や削除もできます。

> **ポイント**
> AI の出力が崩れていても、読み取れる範囲で脚本が復元されます。うまくいかないときは「LLMの生の出力」を開いて中身を確認し、もう一度作成します。

### Chat で相談する

右のペインの「Chat」タブで、ストーリーや脚本について AI に相談できます。

| 機能 | 内容 |
| --- | --- |
| 現在のストーリー・脚本を文脈に含める | オンにすると、編集中の内容をふまえて答える |
| ツール | ストーリーから脚本化／セリフ推敲／ストーリーを整える／キャラクター設定を作成 |
| 返答の下のボタン | 「ストーリーに反映」「脚本に反映」「画像プロンプトへ」「コピー」 |
| 反映を元に戻す | 反映する前の状態に戻す（10回まで） |

例：「ミケのセリフをもっと猫っぽくして」と送り、返答を「脚本に反映」します。

### 保存する

上の作業バーで作品名を付けて「保存」を押します。作業中の内容は自動でも保存されています。

## 11-6 オートレイアウトでページにする

「オートレイアウト」サブタブで、脚本からコマ割りを作り、レイアウトタブへ送ります。

［画像：オートレイアウト（左に設定、中央にプレビュー、右にプロパティ）］

### コマ割りを作る

1. 「オートレイアウト」サブタブを開きます。
2. 左の「ページ設定」で、サイズ・スタイル・読み順・余白を決めます。
3. 「生成（全ページ）」を押します。脚本の全ページのコマ割りが作られます。

| 項目 | 内容 |
| --- | --- |
| スタイル | バランス／非対称／斜め継ぎ目／縦1列／横1列 |
| 読み順 | 右から左（日本のマンガ）／左から右 |
| コマ間余白・外側余白 | コマのすき間と、ページの外側の余白 |

コマの大きさは、脚本の「重要度」で決まります。非対称・斜め継ぎ目は、押すたびに配置が変わるので、気に入るまで押し直せます。

> **ポイント**
> 自分のテンプレートを使いたいときは、ページタブのテンプレートで「オートレイアウトへ送信」を押し、左の「テンプレート」タブでクリックしてページに割り当てます。

### 手で直す

| 操作 | 方法 |
| --- | --- |
| コマを分ける | 中央の「分割(縦)」「分割(横)」ツールで、コマをクリック |
| セリフを直す | コマを選んで、右のプロパティでセリフを選んで「変更」、「追加」で足す |
| 画像を入れる | 右のプロパティで説明文を入れて「生成して割り当て」 |

左の「詳細設定」では、フキダシの文字の既定フォント・既定サイズ・コマ枠線幅を決めます（フォントタブの「既定フォントに設定」でも変えられます）。

### レイアウトタブへ送る

「詳細編集（レイアウトタブへ転送）」を押します。

- 「Auto の作品名＋日時」という名前の新しい作品が作られ、全ページが入ります
- コマ割り・フキダシ・セリフ・割り当てた画像がページになります
- フキダシは、画像より手前に置かれます
- 自動でレイアウトタブに切り替わります

あとは、第6〜7章の方法で絵を入れたり、フキダシを整えたりして仕上げます。第10章の「Generate」の「Autoから取得」を使うと、脚本の「背景描写・演技指示」を、コマごとの画像プロンプトとして使えます。

> **ポイント**
> 「設定」タブで「意思決定モデル」を使うようにすると、セリフからフキダシの形（通常・思考・叫び・ナレーション）や、コマの重要度を AI が推定します。意思決定モデルの接続先は Workflow Studio の設定を使います。

> **この章のまとめ**
> - 自分で書くならスクリプトタブ、AI に作らせるなら Auto
> - スクリプトタブでは「コマ数取得」→「このページをレイアウトに流し込む」→「フキダシを自動生成」
> - Auto は「設定」で AI を選ぶ。AI がなくても「サンプル」で流れを試せる
> - Auto はストーリー → 脚本 → オートレイアウト →「詳細編集（レイアウトタブへ転送）」の順。転送すると新しい作品ができる
