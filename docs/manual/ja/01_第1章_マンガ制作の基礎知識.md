# 第1章 マンガ制作の基礎知識

この章では、Comic Creator を使うときに出てくる言葉と、作品ができあがるまでの流れを説明します。操作はまだしません。全体像をつかむための章です。

## 1-1 覚えておきたい言葉

Comic Creator の画面や本書で何度も出てくる言葉です。最初にここだけ押さえておけば、あとの章が読みやすくなります。

［画像：ページの各部の名前（作品・ページ・コマ・フキダシ・オーバーレイを示した図）］

| 言葉 | 意味 |
| --- | --- |
| 作品 | 何枚かのページをまとめたもの。1冊の本、1話分のマンガにあたります。**幅と高さ（用紙サイズ）** を持っています |
| ページ | 作品の中の1枚。書き出すときの1枚の画像（または PDF の1ページ）になります |
| テンプレート | ページのコマ割りのひな形。テンプレートを選んで「ページとして挿入」すると、そのコマ割りのページができます |
| コマ | ページの中の枠。画像・フキダシ・テキストはコマの中に置きます。コマからはみ出した部分は見えなくなります |
| オーバーレイ | ページ全体を覆う、いちばん手前の層。コマの枠をまたいで置きたいもの（大きな効果音の文字など）を置きます |
| 下書きレイヤー | オーバーレイよりさらに手前にある、下描き専用の層。**書き出した画像には含まれません** |
| フキダシ | セリフを入れる吹き出し。楕円・角丸矩形・思考・バクダン・雲などの形があります |
| レイヤー | 画像・フキダシ・テキストなどを重ねる順番のこと。右側の「レイヤーパネル」で重ね順を入れ替えます |

> **ポイント**
> コマとオーバーレイの違いは「枠で切り取られるかどうか」です。コマに置いた画像はコマの形で切り取られます。オーバーレイに置いたものはページ全体に表示されます（ページの外にははみ出しません）。

## 1-2 Comic Creator でできること

Comic Creator での作品づくりは、次の流れで進みます。

［画像：作業の流れ図（作品を作る → テンプレートを挿入 → 画像・フキダシ・セリフを置く → 書き出す）］

| 順番 | やること | 使うタブ | 本書の章 |
| --- | --- | --- | --- |
| 1 | 作品を作る（作品名と用紙サイズを決める） | 「ページ」タブ＞「作品管理」 | 第4章・第5章 |
| 2 | テンプレートを選んで、ページとして挿入する | 「レイアウト」タブ | 第4章・第5章 |
| 3 | コマに画像を置く | 「レイアウト」タブ | 第6章 |
| 4 | フキダシ・セリフ・効果を入れる | 「レイアウト」タブ | 第7章 |
| 5 | 2〜4 を繰り返してページを増やす | 「レイアウト」タブ | 第4章 |
| 6 | 書き出す（PNG・PDF・EPUB など） | 「ページ」タブ＞「出力」 | 第5章 |

この基本の流れに、必要に応じて次のような作業を組み合わせます。

| やりたいこと | 使うタブ | 本書の章 |
| --- | --- | --- |
| 画像をレイヤーで細かく加工したい、画像に文字を入れたい | 「Image」タブ | 第9章 |
| フォントを選んで、文字の見た目（袋文字・影など）を保存したい | 「フォント」タブ | 第8章 |
| AI で画像を作りたい | 「Nanobanana」タブ、Workflow Studio 連携 | 第10章 |
| 脚本を書いてからページにしたい、AI で脚本とコマ割りを作りたい | 「スクリプト」タブ、「Auto」タブ | 第11章 |

## 1-3 つまずきやすいポイント

はじめての人がとまどいやすい点を、先にまとめておきます。

### 作品のデータはブラウザの中に保存される

作品・ページ・テンプレートなどのデータは、ComfyUI のフォルダではなく、**Comic Creator を開いているブラウザの中** に保存されます。

そのため、次のような場合は、それまでの作品が表示されません（データが消えたわけではありません）。

- いつもと違うブラウザで開いた（例：Chrome で作ったのに Edge で開いた）
- いつもと違うアドレスで開いた（例：`127.0.0.1` と `localhost` を使い分けた、ポート番号が変わった）

> **注意**
> ブラウザの「閲覧履歴データの削除」でサイトデータ（Cookie など）を消すと、作品も一緒に消えます。また、別の PC に作品を移すこともできません。大事な作品は、「設定」タブの「バックアップ・復元」で定期的に zip に保存してください（第13章）。

### 作品のサイズとテンプレートの関係

作品を作るときに決める「幅×高さ」が、その作品のページの大きさになります。テンプレートを挿入すると、テンプレートは作品のサイズに合わせて自動で伸び縮みします。

サイズの単位は mm ではなく、**0.01mm を1とした数値** です。たとえば A4（210mm×297mm）は `21000×29700` になります。プリセットから選べば自分で計算する必要はありません。

### 作品を開いてからページを作る

ページは、作品を開いた状態で作るのが基本です。作品を開かずにテンプレートを挿入して保存したページは、「ページ」タブ＞「作品管理」の「グループ」タブにある **stock** というグループに入ります。「作品一覧」には表示されないので、見つからないときは stock を確認してください。

### 「保存」ボタンの役割

レイアウトタブの「保存」ボタンは、表示中のページを保存し、作業中の作品にページを登録します。編集の途中でも区切りのよいところで押す習慣をつけておくと安心です。

### 作品名の後ろに日時が付く

作品を新規作成すると、入力した作品名の後ろに作成日時が付いた名前になります（例：`mycomic` → `mycomic_20261013153000`。年月日時分秒の14桁）。作品名を空欄にすると `name` という名前になります。同じ名前の作品を何度作っても区別できるようにするためです。

> **この章のまとめ**
> - 作品 ＞ ページ ＞ コマ の順に入れ物が小さくなる。テンプレートはページのコマ割りのひな形
> - オーバーレイはページ全体の手前の層、下書きレイヤーは書き出されない下描き用の層
> - 基本の流れは「作品を作る → テンプレートを挿入 → 画像・フキダシ・セリフ → 書き出す」
> - データはブラウザの中に保存される。違うブラウザ・違うアドレスでは見えない。バックアップを忘れずに
