# はじめに

この本は、ComfyUI のカスタムノード「ComfyUI Comic Creator」（以下、Comic Creator）の使い方を、はじめての人向けに順を追って説明する入門書です。

Comic Creator は、ComfyUI の中で動くマンガ制作アプリです。コマ割りしたページに画像を並べ、フキダシやセリフを入れて、画像や PDF・EPUB として書き出すところまでを、ブラウザの1画面で行えます。

## この本の対象読者

- **ComfyUI でマンガ制作を行いたい人**
  ComfyUI で作った画像を、コマ割り・フキダシ・セリフのあるマンガのページにまとめたい人。
- **画像に文字入れなど、画像編集を行いたい人**
  マンガを描く予定がなくても、1枚の画像にタイトルやセリフを入れたい、レイヤーを重ねて加工したい、という人。

マンガ制作の経験や、画像編集ソフトの知識はなくてもかまいません。ComfyUI が起動できる状態であれば読み進められます。

> **ポイント**
> 1枚の画像に文字を入れたり、画像を編集したりしたい人は、第4章「はじめての1ページ」で全体の流れをつかんだあと、第7章（フキダシ・テキスト）と第9章（Image タブ）を中心に読んでください。

## この本で扱うこと・扱わないこと

| 扱うこと | 扱わないこと |
| --- | --- |
| Comic Creator のインストールと起動 | ComfyUI 本体のインストール方法 |
| 各タブの画面と操作 | ComfyUI のワークフロー（ノードのつなぎ方）の作り方 |
| 作品づくりの流れ（作成→配置→書き出し） | Workflow Studio の詳しい使い方 |
| AI 画像生成・AI 脚本作成との連携の流れ | Gemini API・Ollama などの契約やインストール手順の詳細 |
| 困ったときの対処 | 外部ソフト（Eagle、G'MIC、Inkscape など）の使い方 |

連携機能の多くは、別のカスタムノードや外部ソフトが入っていることが前提です。前提が必要な機能には、その都度「必要なもの」を書いています。

## 対象バージョン

この本は **Comic Creator v1.53.2** をもとに書いています。
Comic Creator は更新が早いため、バージョンが違うとボタンの位置や名前が変わっていることがあります。その場合は、アプリ内の「ヘルプ」タブ（第3章）もあわせて確認してください。

## 表記のルール

| 表記 | 意味 | 例 |
| --- | --- | --- |
| 「 」 | 画面に表示されるボタン・タブ・項目の名前 | 「保存」ボタン、「ページ」タブ |
| 日本語（英語） | 日本語表示の名前と、英語表示の名前 | 「レイアウト（Layout）」タブ |
| `等幅文字` | フォルダ名・ファイル名・入力する文字 | `ComfyUI/custom_nodes/` |
| ＞ | メニューやタブを順にたどる操作 | 「ページ」タブ＞「作品管理」 |

画面の名前は、アプリを日本語表示にしたときの文字に合わせています。アプリ側で英語のまま表示される部分（「Image」タブや「Nanobanana」タブなど）は、英語のまま書いています。

パスは `ComfyUI/` から始まる形で書きます。お使いの環境で ComfyUI の入っているフォルダに読み替えてください（第2章で説明します）。

囲みは次の2種類です。

> **ポイント**
> 知っておくと便利なこと。

> **注意**
> 作業内容が消える・失敗する、などにつながること。必ず読んでください。

## Comic Creator の特色

- **ページ作りから書き出しまで、ひとつの画面で完結する**
  作品の管理、コマ割り、画像の配置、フキダシとセリフ、仕上げの効果、書き出しまで、アプリを切り替えずに作業できます。
- **ComfyUI で作った画像をそのまま使える**
  ComfyUI の出力画像をコマにドラッグ＆ドロップするだけで配置できます。Workflow Studio と組み合わせると、ページを見ながらその場で画像を作り直すこともできます。
- **縦書きのセリフと、マンガらしいフキダシ**
  縦書き・横書きのテキスト、楕円・思考・バクダン・雲などのフキダシ、ハーフトーン（網点）などのマンガ表現を用意しています。
- **レイヤーで編集できる画像エディタ**
  「Image」タブは、レイヤー・描画・マスク・フィルタを備えた画像エディタです。マンガ以外の画像加工にも使えます。
- **AI で脚本からページを作る**
  お題からストーリーと脚本を作り、コマ割りまで自動で作る「Auto」タブがあります（AI の準備が必要です）。
- **いろいろな形式で書き出せる**
  JPEG・PNG・WebP・SVG・PDF・EPUB で書き出せます。書き出し用のライブラリはアプリに同梱されているので、インターネットにつながっていなくても書き出せます。

それでは、第1章でマンガ制作の基本的な言葉と、Comic Creator での作業の流れを見ていきましょう。
