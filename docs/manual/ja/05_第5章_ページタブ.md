# 第5章 ページタブ：作品・テンプレート・出力

「ページ」タブは、作品とページを整理し、テンプレートを管理し、できあがったページを書き出すためのタブです。第4章で使った操作を、ここでくわしく見ていきます。

「ページ」タブには、上に3つのサブタブがあります。

| サブタブ | できること |
| --- | --- |
| 作品管理 | 作品の作成・開く・削除、ページの並べ替え・複製・移動・削除、ゴミ箱 |
| テンプレート | テンプレートの作成・読み込み・名前変更・削除、グループ分け |
| 出力 | ページを画像・SVG・PDF・EPUB で書き出す |

## 5-1 作品管理

［画像：作品管理サブタブ（番号付き：①ツールバー ②作品一覧／グループ ③ページ一覧 ④右のパネル）］

作品管理の画面は、上のツールバーと、左・中央・右の3つの領域に分かれています。

| 番号 | 場所 | 役割 |
| --- | --- | --- |
| ① | ツールバー | 「新規作成」「開く」「出力」。右端に作業中の作品名とサイズが表示される |
| ② | 左：作品一覧／グループ | 作品やグループを選ぶ |
| ③ | 中央：ページ一覧 | 選んだ作品・グループのページのサムネイル |
| ④ | 右：パネル | 選んだページの情報と、ページ・グループ・作品の操作 |

### 作品を作る・開く

| ボタン | 動き |
| --- | --- |
| 新規作成 | 作品名とサイズを入力して作品を作る。作ると「レイアウト」タブに切り替わる |
| 開く | 選んだ作品の1ページ目を「レイアウト」タブで開く。作品カードのダブルクリックでも開ける |
| 出力 | 選んだ作品（またはグループ）のページだけを「出力」サブタブに表示する（5-3） |

「新規作成」で選べるサイズは次のとおりです。

| サイズ | 大きさ |
| --- | --- |
| A4 縦 | 210×297mm |
| A4 横 | 297×210mm |
| B5 縦 | 182×257mm |
| B4 縦 | 257×364mm |
| A5 縦 | 148×210mm |
| 正方形 | 210×210mm |

一覧にないサイズは、「幅×高さ」に直接入力します（単位は 0.01mm。A4 なら 21000×29700）。よく使うサイズは、入力欄の右のボタンでカスタムプリセットとして保存できます。

> **ポイント**
> 作品のサイズは、ページの大きさを決めるものです。書き出すときの画像のピクセル数は、5-3 の「解像度」で決めます。

### 作品一覧とグループ

左の領域の上には、「作品一覧」と「グループ」の切り替えボタンがあります。

| 表示 | 中身 |
| --- | --- |
| 作品一覧 | 作品のカード（1ページ目のサムネイル・サイズ・ページ数）。作業中の作品には印が付く |
| グループ | 作品ではない、ページを分類するためのグループ。stock とゴミ箱もここにある |

「作品」と「グループ」の違いは、サイズを持っているかどうかです。

- **作品**：幅と高さを持つ。テンプレートを挿入すると、作品のサイズに合わせて伸び縮みする
- **グループ**：サイズを持たない。使わなかったページのストックなどに使う

ページは、作品とグループのあいだを自由に移動できます。

> **ポイント**
> **stock** は最初からあるグループで、削除や名前変更はできません。作品を開かずに作ったページは、自動でここに入ります（第1章 1-3）。

### ページの並べ替え・選択

中央のページ一覧で、ページを操作します。

| 操作 | 動き |
| --- | --- |
| クリック | ページを1枚選ぶ |
| Ctrl（Mac は ⌘）＋クリック | ページを複数選ぶ |
| 全選択／選択解除 | 表示中のページをまとめて選ぶ／選択をやめる |
| ↑ ↓ | 選んだページの順番を前後に動かす（1枚選んでいるときだけ） |
| 一括削除 | 選んだページをまとめてゴミ箱へ移す |

ここで並べた順番が、レイアウトタブの「◀」「▶」の順番、「開く」で最初に開くページ、書き出しの順番になります。

### ページの操作（右のパネル）

| ボタン | 動き |
| --- | --- |
| 名前変更 | 選んだページの名前を変える（1枚選んでいるときだけ） |
| 連番名前変更 | 選んだページを「名前_000」の形の連番に名前を変える |
| ページ複製 | 選んだページを複製して、すぐ後ろに入れる（名前は「元の名前_copy」） |
| 移動先グループ＋移動 | 選んだページを、ほかの作品やグループへ移す |
| stockへ移動 | 選んだページを stock へ移す |
| 削除（ゴミ箱） | 選んだページをゴミ箱へ移す |
| 作品削除 | 選んだ作品を削除する。中のページはゴミ箱へ移る |

右のパネルの「グループ管理」では、グループの追加・名前変更（✎）・削除（✕）ができます。

### ゴミ箱から戻す

削除したページは、すぐには消えずにゴミ箱へ入ります。

1. 左の領域で「グループ」に切り替え、「ゴミ箱」を選びます。
2. 戻したいページを選びます。
3. 戻す先のグループ（または作品）を選んで、「復元」を押します。

ゴミ箱から「完全削除」したページは、元に戻せません。

> **注意**
> ゴミ箱も、作品と同じくブラウザの中に保存されています。ブラウザのサイトデータを消すと、ゴミ箱の中身も消えます。

## 5-2 テンプレート

［画像：テンプレートサブタブ（テンプレートの一覧と、右のグループ管理）］

テンプレートの一覧では、各カードの名前の下に、サイズとコマ枠の幅（例：`21000×29700 / 枠幅 63`）が表示されます。

| ボタン | 動き |
| --- | --- |
| SVGからテンプレート作成 | SVG ファイルを読み込んでテンプレートにする |
| テンプレートを作成 | ウィザードで線を引いてテンプレートを作る |
| クイック | 選んだテンプレートから1ページをすぐに作り、レイアウトタブで開く（コマの線幅はテンプレートのまま。作品には登録されない。下の注意を参照） |
| 名前変更 | 選んだテンプレートの名前を変える |
| 削除 | 選んだテンプレートを削除する（元に戻せない） |
| ページとして挿入 | 選んだテンプレートを、開いている作品に新しいページとして入れる |
| オートレイアウトへ送信 | 選んだテンプレートを「Auto」タブのオートレイアウトへ送る（第11章） |

> **注意**
> 作品にページを足すときは、「クイック」ではなく **「ページとして挿入」** を使ってください。「クイック」はテンプレートの大きさのままページを作り、作品にも登録しません。コマの線幅を変えたいときは、レイアウトタブ上部の「コマ枠線幅」で変えます（第4章 4-3）。

### ウィザードで作る

第4章 4-1 の手順のほかに、次の設定があります。

| 項目 | 内容 |
| --- | --- |
| ページの向き | 縦長／横長 |
| 幅・高さ | テンプレートの大きさ（単位 0.01mm）。作品に挿入すると作品のサイズに合わせて伸び縮みするので、比率が合っていれば十分 |
| フレーム幅 | ページの外側の余白とコマ間のすき間の幅 |
| デザイン | オンにすると、余白とすき間のないテンプレートになる（チラシなど向け） |
| 分割モード | 全体分割：線が通るすべてのコマを分ける／単一コマ分割：線を引き始めたコマだけを分ける |
| ガイドグリッド・スナップ | 格子線の表示と、線の端を格子に吸着させる。設定はブラウザに記憶される |

> **ポイント**
> 「デザイン」をオンにして作ったテンプレートは、コマとコマの境目に線の太さがありません。ページに入れたあと、レイアウトタブの「コマ枠線幅」で太さを決めます。0 にすると境目の線が消えます。

### SVG ファイルから作る

Inkscape・Affinity Designer・Illustrator などの描画ソフトでコマの区切りを描き、SVG で保存したファイルをテンプレートにできます。

1. 「SVGからテンプレート作成」を押し、SVG ファイルを選びます。
2. 他のテンプレートと枠線の太さをそろえるために倍率の調整が必要なときは、確認の画面が出ます。表示された倍率のまま OK を押せば調整されます。調整しないときは `1` を入力します。
3. 同じ名前のテンプレートがあるときは、別の名前を聞かれます。

> **ポイント**
> GitHub の Comic Creator のページには、描画ソフトごとのサンプル SVG（`sample_svg` フォルダ）があります。カスタムノードマネージャーでインストールした場合はこのフォルダが入らないので、使いたいときは GitHub からダウンロードしてください。描画ソフトでの作り方は、アプリ内のヘルプの付録にあります。

### グループ分け

テンプレートが増えてきたら、グループに分けると探しやすくなります。

1. 右の「グループ管理」でグループ名を入力し、「追加」を押します。
2. テンプレートを選び、グループを選んで「グループに追加」を押します。

一覧の上のドロップダウンでグループを選ぶと、そのグループのテンプレートだけが表示されます。レイアウトタブのアセットパネル「T」タブでも、グループごとに折りたたんで表示されます。

## 5-3 出力

［画像：出力サブタブ（左に設定、中央にプレビュー、右にページ一覧）］

### 出力の流れ

1. 「作品管理」で作品を選び、「出力」ボタンを押します（第4章 4-7）。
2. 「形式」を選びます。
3. 「解像度」を選びます。幅・高さ（px）が自動で計算されます。
4. 「出力ページ」で範囲を指定します。
5. 必要なら「ファイル名」と「メタ情報」を入力します。
6. 「保存」を押します。

### 形式の選び方

| 形式 | 向いている用途 |
| --- | --- |
| JPEG | SNS への投稿など。ファイルが小さい |
| PNG | 画質を落とさずに保存したいとき |
| WebP | ファイルを小さくしつつ画質も保ちたいとき |
| SVG | Inkscape などで、あとから文字や形を編集したいとき |
| PDF | 印刷や、複数ページを1つのファイルで渡したいとき |
| EPUB | 電子書籍として読みたいとき |

### 解像度と大きさ

「解像度」で 72〜600dpi を選ぶと、作品のサイズから書き出す画像のピクセル数が計算されます。たとえば A4 の作品を 300dpi にすると、2480×3508px になります。

| 解像度の目安 | 用途 |
| --- | --- |
| 72〜150dpi | 画面で見る、SNS に投稿する |
| 300〜350dpi | 印刷する |
| 600dpi | モノクロの線画を細かく印刷する |

- 幅・高さを直接入力すると、「解像度」は「手動」になります
- 「縦横比を維持」にチェックがあると、幅と高さの比率が保たれます
- 書き出せる大きさの上限は 8000px です。超えるときは縦横比を保って縮小されます
- PDF では、選んだ解像度から用紙の大きさが計算されます。A4 の作品を 300dpi で書き出すと、PDF の用紙も A4（210×297mm）になります

### 出力ページとファイル名

| 項目 | 内容 |
| --- | --- |
| 出力ページ | 書き出すページの範囲（何ページ目から何ページ目まで） |
| ファイル名 | 空欄のときはページ名がファイル名になる |
| 連番 | 2ページ以上を書き出すと、ファイル名の頭に `01_`、`02_`… が付く |
| zip保存 | 全ページを1つの zip にまとめる（JPEG・PNG・WebP・SVG のとき。PDF・EPUB を選ぶとグレーになり、選べません） |

> **注意**
> 「出力ページ」は、一覧のページ数に合わせて「1 〜 最後のページ」が自動で入ります。一部のページだけ書き出すときは、範囲を変えてください。作業中の作品があるときは、「出力」サブタブを直接開いても、その作品のページだけが一覧に並びます（すべてのページを並べたいときは、絞り込み表示の「解除」を押します）。

### メタ情報

「メタ情報」にタイトル・著者・件名・キーワードを入力すると、書き出すファイルに埋め込まれます（SVG を除く）。キーワードは、カンマや読点で区切って複数入れられます。入力した内容は次回も残ります。

### その他の項目

| 項目 | 内容 |
| --- | --- |
| 背景のみ | 画像・フキダシ・テキストを除いた、コマ枠などページの土台だけを書き出す（JPEG・PNG・WebP・SVG のとき。PDF・EPUB を選ぶとグレーになり、選べません） |
| ＋ 画像を取り込む | パソコンの画像を、ページとして取り込む |
| 並替 | ページ一覧の番号欄に入れた順番で並べ替える（作品で絞り込んでいないとき） |

### SVG で書き出して、ほかのソフトで直す

SVG 形式では、ページを画像にせず、形や文字のデータのまま書き出します。文字は文字のまま、フキダシは形のまま残り、使ったフォントもファイルに埋め込まれます。

| ソフト | 再編集のしやすさ |
| --- | --- |
| Inkscape、Affinity Designer/Publisher | ほぼそのまま編集できる |
| Adobe Illustrator | 開けるが、画像のリンクが切れるので1枚ずつ指定し直す必要がある |
| CorelDraw | 読み込み中に止まってしまうため、使えない |

> **ポイント**
> 書き出しに使うライブラリはアプリに入っているので、インターネットにつながっていなくても、すべての形式で書き出せます。ただし、Google Fonts などのWebフォントを使っているページは、フォントがまだ読み込まれていないと、別のフォントで書き出されることがあります。

> **この章のまとめ**
> - 「作品管理」で作品の作成・開く・出力と、ページの並べ替え・移動・削除を行う。削除したページはゴミ箱から戻せる
> - 「テンプレート」でテンプレートを作る・読み込む。作品にページを足すのは「ページとして挿入」
> - 「出力」では形式・解像度・出力ページを確認してから「保存」。印刷用なら 300〜350dpi
> - SVG で書き出すと、Inkscape などで文字や形を編集し直せる
