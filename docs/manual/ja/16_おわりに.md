# おわりに

最後まで読んでいただき、ありがとうございました。

Comic Creator は、「ComfyUI で作った絵を、そのままマンガのページにしたい」という思いから作り始めたツールです。コマ割り、フキダシ、セリフ、書き出しまでを1つの画面で行えるようにし、そこに画像エディタや AI との連携を少しずつ足してきました。

本書では、はじめての1ページから、AI を使った作品づくり、仕上げの効果までを順に紹介しました。すべての機能を一度に使いこなす必要はありません。まずは1枚の画像に文字を入れてみる、2ページの短いマンガを作ってみる、といった小さな作品から始めてみてください。

Comic Creator は今も更新を続けています。本書と画面が違うところがあれば、アプリ内の「ヘルプ」タブもあわせてご覧ください。不具合の報告や「こんな機能がほしい」という声は、GitHub のリポジトリで受け付けています。

あなたの作品づくりに、Comic Creator が少しでも役に立てばうれしいです。
