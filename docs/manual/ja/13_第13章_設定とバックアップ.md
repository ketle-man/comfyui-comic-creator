# 第13章 設定とバックアップ

この章では、「設定」タブの項目と、作品を守るためのバックアップ・復元を説明します。

## 13-1 設定タブの項目

「設定」タブには、上から次の項目が並んでいます。

| 項目 | 内容 | 本書の章 |
| --- | --- | --- |
| 言語 | 表示言語（日本語／English／中文）。切り替えると画面が再読み込みされる | 第2章 |
| バックアップ・復元 | 全データを zip に保存する／zip から戻す | この章の 13-2 |
| VRAM調整（Ollama） | 画像生成の前に Ollama のモデルを片付けて、GPU のメモリを空ける | 下の表 |
| Nanobanana 設定 | Nanobanana の生成方式（Gemini API／ComfyUIネイティブノード）。Nanobanana+ タブ（Nanobanana モード）・半自動マンガ・Auto に共通 | 第10章 |
| Eagle 設定 | Eagle の接続先と、自動保存 | 第12章 |
| G'MIC 設定 | G'MIC Qt の実行ファイルの場所 | 第12章 |
| Inpaint設定 | Image タブの Inpaint で使うワークフロー | 第10章 |
| Outpaint設定 | Image タブの Outpaint で使うワークフロー | 第10章 |

### VRAM調整（Ollama）

ローカルの AI（Ollama）と、Workflow Studio や MOSS-Image・Nanobanana+（ローカル）での画像生成を同じパソコンで使うと、GPU のメモリ（VRAM）が足りなくなることがあります。この設定で、画像を生成する直前に Ollama のモデルを片付け（アンロード）させられます。

| 項目 | 内容 |
| --- | --- |
| 生成前の動作 | 何もしない（既定）／空きが目標未満のときだけ必要な分をアンロード／毎回すべてアンロード |
| 目標の空き（GB） | 「必要な分だけ」のときに、どれだけ空けるか |
| 今すぐすべてアンロード | いま読み込まれている Ollama のモデルを、すぐに片付ける |

アンロードしたモデルは、次に使うときに読み込み直しになります。対象は、自分のパソコンの Ollama だけです（LM Studio などや、ComfyUI 自身のモデルは対象外）。

OCR タブでも、検出を実行する前と、意思決定モデルで判定する前、ComfyUI の Chat TE で全体読みをする前に、この設定が働きます（第10章 10-8）。

### Inpaint設定・Outpaint設定

Image タブの Inpaint・Outpaint を実行するときに、Workflow Studio に自動で読み込ませるワークフローを指定します。

1. 「デフォルトワークフローを使用する」にチェックを入れます。
2. 「ワークフローファイル名」に、Workflow Studio に保存してあるワークフローの名前を入れます。

チェックを外しているときは、Workflow Studio でいま開いているワークフローが使われます。

> **ポイント**
> I2I・T2I のワークフローの指定は、設定タブではなく、レイアウトタブの「Generate」の画面下の「ワークフロー設定」や、Image タブの Select ツールの「I2I設定」で行います（第10章）。

## 13-2 バックアップと復元

第1章で説明したとおり、Comic Creator の作品はブラウザの中に保存されています。ブラウザのデータを消したり、パソコンを買い替えたりすると、作品は見えなくなります。定期的にバックアップを取りましょう。

### バックアップを取る

1. 「設定」タブを開きます。
2. 「バックアップ・復元」の「バックアップ」を押します。
3. `ccc_backup_日時.zip` という名前の zip ファイルが保存されます。

### バックアップに含まれるもの・含まれないもの

| 含まれる（ブラウザの中のデータ） | 含まれない（パソコンのフォルダにあるもの） |
| --- | --- |
| 作品・ページ・グループ・ゴミ箱 | `assets` フォルダの素材（アセットパネル「A」） |
| テンプレートとテンプレートのグループ | Image タブの「Project」で保存したもの（アセットパネル「I」） |
| スクリプトタブの作品 | `ComfyUI/output/` に保存された画像（Nanobanana・Gallery など） |
| Auto の作品と AI 設定 | `.env`（API キー） |
| フォントタブのスタイル・プリセット・カテゴリ | G'MIC 設定 |
| 連携の設定（Eagle、ワークフロー、PixiJS FX、VRAM調整など） | ComfyUI 本体の設定 |
| 表示言語、出力の設定など | |

> **注意**
> 「含まれない」ものは、Comic Creator のバックアップでは守れません。とくに `ComfyUI/custom_nodes/comfyui-comic-creator/assets/` フォルダ（素材と Image タブの Project）は、別の場所にコピーしておいてください。

### 復元する

1. 「設定」タブの「バックアップ・復元」で「復元」を押します。
2. バックアップの zip ファイルを選びます。
3. 確認の画面で OK を押します。終わると、画面が自動で再読み込みされます。

復元は「上書きして足す」方式です。同じ名前のデータは zip の内容で上書きされ、それ以外の今あるデータはそのまま残ります。

> **ポイント**
> 今のデータを全部消して、バックアップの状態にそっくり戻したいときは、復元する前に、ブラウザの「サイトデータ」を消してから復元します。

### 別のパソコンに移す

1. 元のパソコンでバックアップを取ります。`assets` フォルダもコピーします。
2. 新しいパソコンに ComfyUI と Comic Creator を入れます（第2章）。
3. `assets` フォルダを、新しいパソコンの Comic Creator のフォルダにコピーします。
4. Comic Creator を開き、「設定」タブで「復元」します。

> **注意**
> 復元は、いつも使うブラウザ・いつも使うアドレスで行ってください。別のアドレスで開いて復元すると、そのアドレス用に保存されます（第1章）。

> **この章のまとめ**
> - 「設定」タブには、言語・バックアップ・VRAM調整・Eagle・G'MIC・Inpaint／Outpaint の設定がある
> - 「バックアップ」で、ブラウザの中の全データを1つの zip に保存できる
> - `assets` フォルダ（素材・Image タブの Project）や `output` の画像は、別にコピーしておく
> - 「復元」は同じ名前を上書きし、ほかは残す方式
