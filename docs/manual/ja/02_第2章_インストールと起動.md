# 第2章 インストールと起動

この章では、Comic Creator を ComfyUI に入れて、最初の画面を開くところまでを行います。

## 2-1 準備するもの

| 必要なもの | 説明 |
| --- | --- |
| ComfyUI | 起動できる状態にしておきます。インストール方法は本書では扱いません |
| ブラウザ | Chrome や Edge など。Comic Creator はブラウザの新しいタブで開きます |
| インターネット接続 | インストール時に必要です。インストール後の基本操作と書き出しはオフラインでも使えます |

### ComfyUI のフォルダの場所

本書では、ComfyUI のフォルダを `ComfyUI/` と書きます。お使いの環境に合わせて読み替えてください。

| 環境 | `ComfyUI/` にあたるフォルダの例 |
| --- | --- |
| ポータブル版（Windows） | `ComfyUI_windows_portable/ComfyUI/` |
| ComfyUI Desktop | インストール時に選んだフォルダ（`custom_nodes` フォルダがある場所） |
| Stability Matrix | `StabilityMatrix/Data/Packages/ComfyUI/`（設定により異なる） |
| git でインストール | `git clone` したフォルダ |

カスタムノードは、どの環境でも `ComfyUI/custom_nodes/` の中に入れます。

## 2-2 カスタムノードマネージャーでインストールする

ComfyUI には、カスタムノードを検索してインストールできる「カスタムノードマネージャー（Nodes Manager）」があります。いちばんかんたんな方法です。

1. ComfyUI を起動し、画面上部の「拡張機能の管理（Extensions）」メニューを開きます。
2. 「カスタムノードマネージャー（Nodes Manager）」を選びます。
3. 検索欄に `comic creator` と入力します。

4. 検索結果の「ComfyUI Comic Creator」をインストールします。
5. インストールが終わったら、ComfyUI を再起動します。

> **ポイント**
> 検索結果に似た名前のノードが出てきたときは、作者が「statsu」（GitHub では ketle-man）のものを選んでください。

## 2-3 手動でインストールする

カスタムノードマネージャーを使わない場合や、うまくインストールできない場合は、`custom_nodes` フォルダに Comic Creator のフォルダを置きます。

1. コマンドプロンプト（ターミナル）で `ComfyUI/custom_nodes/` に移動します。
2. 次のコマンドを実行します。
   ```
   git clone https://github.com/ketle-man/comfyui-comic-creator
   ```
   git を使わない場合は、GitHub のページから ZIP をダウンロードして展開し、`custom_nodes` の中に置きます。
3. ComfyUI を再起動します。

置いたあとのフォルダは、次のようになります。

```
ComfyUI/
└── custom_nodes/
    └── comfyui-comic-creator/
        ├── __init__.py
        ├── py/
        ├── static/
        ├── templates/
        └── web/
```

> **注意**
> ZIP を展開すると、フォルダが二重になる（`comfyui-comic-creator/comfyui-comic-creator/__init__.py`）ことがあります。`custom_nodes` のすぐ下のフォルダに `__init__.py` がある状態にしてください。

### 追加のパッケージについて

基本機能には、追加の Python パッケージは必要ありません。

「Image」タブで PSD（Photoshop 形式）のファイルを開く・保存する機能だけは、`psd-tools` というパッケージを使います。カスタムノードマネージャーでインストールした場合は自動で入ります。手動でインストールした場合は、ComfyUI が使っている Python で次のコマンドを実行してください。

```
pip install -r requirements.txt
```

（`comfyui-comic-creator` フォルダの中で実行します。ポータブル版などでは、ComfyUI に付属の Python を使います。）

`psd-tools` が入っていなくても、PSD 以外の機能はそのまま使えます。

## 2-4 Comic Creator を開く

ComfyUI を再起動すると、画面上部のバー（トップバー）に **CC** ボタンが追加されます。

1. ComfyUI をブラウザで開きます。
2. トップバーの **CC** ボタンをクリックします。
3. ブラウザの新しいタブで Comic Creator が開きます。

開いたタブのアドレスは、ComfyUI のアドレスの後ろに `/ccc` が付いたものです。たとえば ComfyUI を `http://127.0.0.1:8188` で開いているなら、Comic Creator は `http://127.0.0.1:8188/ccc` です。

アドレスの `:8188` の部分は「ポート番号」と呼ばれ、環境によって違う番号になることがあります（ComfyUI Desktop など）。**ComfyUI を開いているアドレスに `/ccc` を付ける** と覚えておけば、どの環境でも開けます。

> **ポイント**
> `/ccc` のアドレスをブラウザのブックマークに登録しておくと、次からは ComfyUI の画面を経由せずに直接開けます（ComfyUI は起動しておく必要があります）。

> **注意**
> 第1章で説明したとおり、作品のデータはブラウザの中に、**アドレスごとに** 保存されます。`127.0.0.1` と `localhost` は同じ PC を指していますが、別のアドレスとして扱われます。いつも同じアドレスで開くようにしてください。

## 2-5 表示言語を切り替える

Comic Creator の画面は、日本語・英語・中国語で表示できます。はじめて開いたときは、ブラウザの言語に合わせて表示されます（日本語・英語・中国語に対応。それ以外の言語のときは日本語になります）。

1. 「設定」タブを開きます。
2. 「言語」で表示したい言語を選びます。
3. 画面全体が再読み込みされ、選んだ言語で表示されます。

選んだ言語はブラウザに記憶されるので、次回からも同じ言語で開きます。

## 2-6 あると便利な連携ノード

次のカスタムノードが入っていると、Comic Creator の機能が増えます。入っていなくても、ほかの機能には影響しません。必要になったときに入れれば十分です。

| カスタムノード | 有効になる機能 | 本書の章 |
| --- | --- | --- |
| ComfyUI-Workflow-Studio | ComfyUI のワークフローを使った画像生成（Generate・I2I・Inpaint・Outpaint）、「workflow studio」タブのギャラリー表示 | 第10章 |
| comfyui-vrm-pose-editor | 3D ポーズ・3D テキスト | 第12章 |
| comfyUI-particle-pixijs | PixiJS FX（パーティクル・フィルタ効果） | 第12章 |

> **注意**
> comfyui-vrm-pose-editor は、フォルダ名が `comfyui-vrm-pose-editor` でないと Comic Creator から見つけられません。手動でインストールするときは、フォルダ名を変えないでください。

AI 画像生成サービス（Nanobanana）や外部ソフト（Eagle、G'MIC）との連携の設定は、使う章でそれぞれ説明します。

## 2-7 うまく起動できないときは

| 症状 | 考えられる原因 | 対処 |
| --- | --- | --- |
| CC ボタンが表示されない | ComfyUI を再起動していない | ComfyUI を再起動し、ブラウザも再読み込みします |
| CC ボタンが表示されない | フォルダの置き場所が違う（二重フォルダなど） | `ComfyUI/custom_nodes/comfyui-comic-creator/__init__.py` があるか確認します |
| CC ボタンが表示されない | ComfyUI の画面（フロントエンド）が古い | ComfyUI を更新します。ボタンがなくても、アドレスに `/ccc` を付ければ開けます |
| `/ccc` を開くと「404」などのエラーになる | Comic Creator が読み込まれていない | ComfyUI を起動したときの画面（コンソール）に `[ccc] ERROR` で始まる行が出ていないか確認します |
| 以前作った作品が表示されない | 違うブラウザ・違うアドレスで開いている | いつも使っているブラウザとアドレスで開きます（第1章） |
| 「workflow studio」タブに「見つかりませんでした」と出る | ComfyUI-Workflow-Studio が入っていない | 使う場合はインストールして ComfyUI を再起動します。使わない場合はそのままでかまいません |

> **この章のまとめ**
> - 「拡張機能の管理（Extensions）」＞「カスタムノードマネージャー（Nodes Manager）」で `comic creator` を検索して入れる。手動なら `custom_nodes` に置く
> - インストール後は ComfyUI を再起動。トップバーの **CC** ボタンで開く
> - Comic Creator のアドレスは「ComfyUI のアドレス＋`/ccc`」。いつも同じアドレスで開く
> - 言語は「設定」タブの「言語」で切り替える
> - 連携ノードは必要になってから入れればよい
