# 第9章 Image タブ：レイヤー画像エディタ

「Image」タブは、レイヤーを重ねて画像を編集する画像エディタです。レイアウトタブのページとは別の、1枚のキャンバスで作業します。

- 1枚の画像に、タイトルやセリフを入れる
- 画像を切り抜く、余白を足す、背景を消す
- レイヤーを重ねて、描き込みや加工をする
- 編集した画像を、レイアウトタブのコマに戻す

> **ポイント**
> Image タブのツール名やボタン名は、日本語表示にしても多くが英語のままです。本書でも、画面のとおり英語で書きます。一方、入力ダイアログや画面に出る通知は、表示言語に合わせて翻訳されます。

## 9-1 画面の見方

［画像：Image タブの画面（番号付き：①ツールバー ②アクションバー ③オプションバー ④キャンバス ⑤プロパティ・レイヤーパネル）］

| 番号 | 場所 | 役割 |
| --- | --- | --- |
| ① | ツールバー（左） | ツールのボタン。アイコンにマウスを乗せると名前が出る |
| ② | アクションバー（上） | 開く・新規・閉じる・元に戻す・保存・送る |
| ③ | オプションバー（②の下） | 選んだツールの設定 |
| ④ | キャンバス（中央） | 編集中の画像 |
| ⑤ | 右のパネル | 選んだもののプロパティと、レイヤーの一覧 |

キャンバスの下の「Fit」で画面に合わせた大きさ、「100%」で実寸表示になります。Space キーを押しながらドラッグすると、表示位置を動かせます。

アセットパネル（A・F・I）も左に表示されます。「A」の素材は「レイヤーとして挿入」で新しいレイヤーとして入れられます。

## 9-2 1枚の画像に文字を入れる

まずは、いちばんよく使う「画像に文字を入れて保存する」流れを通してみましょう。

1. 「Image」タブを開きます。
2. 文字を入れたい画像ファイルを、キャンバスにドラッグ＆ドロップします（または「File Open」で選びます）。
3. ツールバーの「T」（Text）を押します。
4. オプションバーで、Color（文字色）・Size（大きさ）・Font（フォント）を選びます。縦書きにするときは「縦」にチェックを入れます。
5. 文字を入れたい場所をクリックします。入力欄が開くので、文字を入力して「OK」を押します。

   ［画像：Image タブで画像に文字を入れたところ］

6. 文字の位置を直すときは、「▲」（Select）を押して、文字をドラッグします。
7. 袋文字や影を付けるときは、文字を選んでオプションバーの「スタイル」を押します（第7章 7-2 と同じ画面です）。
8. アクションバーの「PNG」を押して保存します。

> **注意**
> 文字の入力欄では、**Enter キーで改行**、**Ctrl＋Enter（Mac は ⌘＋Enter）で確定** になります。レイアウトタブの「テキスト入力」と同じ操作です。Esc で取り消せます。

> **ポイント**
> 入れた文字をダブルクリックすると、入力し直せます。フォントタブで保存したスタイルは、アセットパネルの「F」タブからクリックで適用できます。

## 9-3 画像を開く・新しく作る

| ボタン | 動き |
| --- | --- |
| File Open | パソコンの画像を開く。キャンバスへのドラッグ＆ドロップでも開ける。すでに画像を開いているときは、新しいレイヤーとして（キャンバスに収まる大きさで）追加される |
| Open PSD | PSD（Photoshop 形式）のファイルを、レイヤーごと開く（50MB まで） |
| New | 大きさを `幅x高さ`（例：`1024x1024`）で入力して、白紙のキャンバスを作る（最大 8192） |
| 下書き | 作業中の作品と同じ縦横比の、軽いキャンバスを作る（ラフ用。作品を開いていないと使えない） |
| Close | 編集中の画像を閉じる。保存するか確認が出る |
| ↩ ↪ | 元に戻す（Ctrl＋Z）／やり直す（Ctrl＋Y） |

> **ポイント**
> レイアウトタブでコマの画像をダブルクリックするか、「画像タブで編集」を押すと、その画像が Image タブで開きます。編集が終わったら「レイアウト」を押すと、元の画像に書き戻されます（9-6）。

> **注意**
> 「Open PSD」と PSD での保存には、`psd-tools` パッケージが必要です（第2章 2-3）。

## 9-4 ツール

| ボタン | ツール | キー | できること |
| --- | --- | --- | --- |
| ▲ | Select | V | レイヤーの選択・移動・拡大縮小・回転。切り抜きと余白の追加 |
| ✏ | Draw | B | ブラシで描く |
| T | Text | T | 文字を入れる |
| ◪ | 3D Text | — | 立体文字（comfyui-vrm-pose-editor が必要。第12章） |
| □ | Shape | S | 図形を描く |
| 🪣 | Fill | G | バケツ塗り（単色・グラデーション） |
| 🎭 | Mask | — | マスクを作る |
| ≈ | Blur | — | ぼかし・モザイク |
| ★ | Filter | — | G'MIC のフィルタ（第12章） |
| ⬚ | BG Remove | — | 背景を消す |
| ⤢ | Upscale | — | 大きくする・ノイズ除去・シャープ |

### Select：切り抜き・余白の追加

Select ツールでは、レイヤーを動かすほかに、キャンバスの大きさを変えられます。

| ボタン | 内容 |
| --- | --- |
| ✂ クロップ | キャンバスを切り抜く。点線の枠をドラッグするか、右のパネルに X・Y・幅・高さを入れて「実行」を押す |
| ⛶ サイズ拡張 | キャンバスの上下左右に余白を足す。「四辺を連動させる」で4辺を同じ幅に。余白の色は「拡張ピクセル（端の色を伸ばす）」「透明」「白」「黒」から選ぶ |

選んだレイヤーは、Delete キーで削除できます（レイヤーが1枚しかないときは削除されません）。

### Draw：ブラシで描く

ブラシの色・太さ・不透明度を決めて、ドラッグで描きます。カラーピッカーの右のスポイトを押してキャンバスをクリックすると、その色をブラシの色にできます。ペンタブレットの筆圧にも対応しています。

### Shape：図形を描く

矩形・楕円・線・鎖・ロープ・My Curve などを描けます。オプションバー左の「Same Layer」がオン（最初はオン）だと、図形を描くたびにレイヤーが増えず、同じレイヤーに描き足します。矩形と楕円は、塗りに単色・グラデーション・テクスチャを使えます。

### Fill：バケツ塗り

クリックした場所と、つながっている似た色の範囲を塗ります。「Tolerance」（許容誤差）を大きくすると、少し違う色まで塗ります。「Gradient」にすると、グラデーションで塗れます。

### Mask：マスク

マスクのレイヤーを作って、画像の一部を隠したり、AI で描き直す範囲を決めたりします。ブラシで塗る Paint のほか、色や透明度、文字、図形で範囲を決めるサブツールがあります。

Workflow Studio が入っていると、Mask ツールに「Inpaint」（範囲を AI で描き直す）と「Outpaint」（画像の外側を AI で描き足す）が表示されます（第10章）。

### Blur・BG Remove・Upscale

| ツール | 内容 |
| --- | --- |
| Blur | 全体、または選んだ四角の範囲を、ぼかす・モザイクにする |
| BG Remove | 背景を消す。Quality で品質（42MB／84MB／168MB）を選ぶ。初回はモデルのダウンロードにインターネット接続が必要 |
| Upscale | 画像を大きくする。ノイズ除去・シャープもできる |

> **注意**
> BG Remove のモデル「BiRefNet」は、カスタムノード「Mask Editor One」と BiRefNet のモデルが入っているときだけ選べます。入っていないときはグレーになるので、軽量モデルを使ってください。

## 9-5 レイヤーパネル

［画像：Image タブのレイヤーパネル］

| ボタン | 動き |
| --- | --- |
| ＋ | 新しいレイヤーを足す |
| M | マスクのレイヤーを足す |
| − | 選んだレイヤーを削除する |
| ↑ ↓ | 重ね順を変える |
| 📁 グループ | Shift＋クリックで2枚以上選んで押すと、フォルダのようにまとめる |
| 統合 | 2枚以上選んで押すと、選んだレイヤーを1枚にまとめる。1枚以下のときは全部を1枚にまとめる |

各レイヤーの行では、表示・非表示、ロック、不透明度を変えられます。不透明度の下にある複製ボタンで、選んだレイヤーを複製できます。

パネルの下からは、明るさ・コントラスト・彩度など12種類の **調整レイヤー** を足せます。調整レイヤーは、下にある画像の色味を、元の画像を変えずに調整します。

## 9-6 保存する・送る

アクションバーの右側には、保存と送信のボタンが並んでいます。

### 保存

| ボタン | 保存されるもの | 保存先 |
| --- | --- | --- |
| PNG | 全レイヤーを合わせた1枚の画像 | パソコンにダウンロード |
| PSD | レイヤーを保ったままの PSD ファイル（調整レイヤーは下のレイヤーに焼き込まれる） | パソコンにダウンロード |
| Project | レイヤー構成も含めた編集中の状態。あとで続きから編集できる | アセットパネルの「I」タブ |
| Gallery | 全レイヤーを合わせた画像 | ComfyUI の `output/cc` フォルダ |

> **ポイント**
> あとで直す可能性がある画像は、「Project」で保存しておきましょう。アセットパネルの「I」タブで選んで「Open」を押すと、レイヤーごと元の状態に戻ります。PNG で保存した画像は、文字を入れ直したりできません。

### 送る

| ボタン | 送り先 |
| --- | --- |
| レイアウト | レイアウトタブ。「画像タブで編集」から開いた画像なら元の画像に書き戻し、それ以外は選んでいるコマに新しい画像として入れる |
| Eagle | 画像管理ソフト Eagle（第12章） |
| wsI2I | Workflow Studio の I2I（画像から画像を作る）の入力（第10章） |
| LI Node | ComfyUI の画面で選んでいる Load Image ノード（CC ボタンから開いたときだけ使える） |

> **ポイント**
> 「下書き」で作ったキャンバスを「レイアウト」で送ると、コマではなく、ページ全体の下書きレイヤーに入ります。

> **この章のまとめ**
> - Image タブは、レイヤーで編集する1枚のキャンバス。画像はドラッグ＆ドロップか「File Open」で開く
> - 文字入れは「T」→ クリック → 入力 → OK。改行は Enter、確定は Ctrl＋Enter
> - Select の「✂ クロップ」で切り抜き、「⛶ サイズ拡張」で余白を足す
> - 保存は「PNG」、あとで直すなら「Project」。「レイアウト」でコマに戻せる
