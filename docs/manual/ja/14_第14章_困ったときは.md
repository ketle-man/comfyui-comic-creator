# 第14章 困ったときは

うまくいかないときは、まず次の3つを試してください。たいていの問題はこれで解決します。

## 14-1 まず試す3つ

| 順番 | やること | 解決しやすい問題 |
| --- | --- | --- |
| 1 | ブラウザで Comic Creator のタブを再読み込みする（F5 キー） | 画面の表示がおかしい、ボタンが反応しない、一覧が古い |
| 2 | ComfyUI を再起動して、Comic Creator を開き直す | 設定（`.env` など）が反映されない、連携ノードが見つからない |
| 3 | 「ヘルプ」タブで、困っている機能の名前を検索する | ボタンの意味が分からない、本書とバージョンが違う |

> **注意**
> 再読み込みの前に、作業中のページはレイアウトタブの「保存」を押しておきましょう。

## 14-2 症状別の対処

### 起動・表示

| 症状 | 原因 | 対処 |
| --- | --- | --- |
| CC ボタンが出ない | ComfyUI を再起動していない、フォルダの置き場所が違う、ComfyUI の画面が古い | 第2章 2-7。アドレスに `/ccc` を付けても開ける |
| 以前作った作品が見えない | 違うブラウザ、違うアドレス（`127.0.0.1` と `localhost`、ポート番号）で開いている | いつものブラウザ・アドレスで開く（第1章） |
| 英語で使いたいのに日本語で表示される | 以前に日本語を選んだ、またはブラウザの言語が日本語や未対応の言語になっている（はじめてのときは、ブラウザの言語に合わせて表示される） | 「設定」タブ＞「言語」で English を選ぶ |
| 一部のボタンが日本語にならない | Image タブのツール名・ボタン名など、英語のままの部分がある | 仕様です。本書も画面どおりに書いています |

### 作品・ページ

| 症状 | 原因 | 対処 |
| --- | --- | --- |
| テンプレートが消えてしまった | 削除した（最初に入っている「A4縦_3コマ」「A4横_3コマ」も、削除すると自動では戻らない） | 「ページ」タブ＞「テンプレート」＞「テンプレートを作成」で作る（第4章） |
| 作ったページが作品一覧にない | 作品を開かずにページを作った | 「作品管理」の「グループ」＞ stock を見る。「移動」で作品に入れる |
| ページの大きさが作品と合わない | 「クイック」でページを作った | アセットパネル「T」の「ページとして挿入」を使う（第4章 4-3） |
| ページを消してしまった | — | 「作品管理」＞「グループ」＞「ゴミ箱」から「復元」（第5章） |

### 画像・フキダシ・文字

| 症状 | 原因 | 対処 |
| --- | --- | --- |
| 画像が思ったコマに入らない | コマの外でドロップした | 入れたいコマの上でドロップする。入ったあとはレイヤーパネルの「移動」で移せる |
| 画像がつかめなくなった | コマの外に出てしまった | レイヤーパネルで選んで「OC」（第6章） |
| 画像やフキダシが選べない・動かない | ロック（🔒）されている | レイヤーパネルで 🔓 に戻す |
| フキダシを動かせない | 「編集: OFF」になっている | 「フキダシ」の「編集: ON」にする |
| セリフがフキダシからあふれる | フキダシが小さい | フキダシをハンドルで広げる（第7章） |
| コマをクリックしても文字が置けない | テキストモードがオフ | 「テキスト」の「T」ボタンをオンにする |
| Image タブで文字が確定しない | Enter は改行になっている | Ctrl＋Enter（Mac は ⌘＋Enter）で確定（第9章） |
| 加工したら元の画像が消えた | 「画像」サブタブの加工では、元の画像が非表示になる | レイヤーパネルの 👁 で元の画像を表示し直せる（第6章） |
| 背景除去でエラーになる | インターネットにつながっていない／BiRefNet のモデルや Mask Editor One が正しく入っていない | 「軽量 (@imgly)」を選ぶ。初回はインターネット接続が必要。「BiRefNet」がグレーで選べないときは、Mask Editor One とモデルを確認する |
| システムフォントが一覧に出ない | Chrome・Edge 以外のブラウザ、またはアクセスを許可していない | Chrome か Edge で「システムフォントを読み込む」を押して許可する（第8章） |

### 書き出し

| 症状 | 原因 | 対処 |
| --- | --- | --- |
| 一部のページしか書き出されない | 「出力ページ」の範囲を変えている | 範囲を確認し、「1 〜 最後のページ」にする（第4章 4-7） |
| ほかの作品のページが書き出された | 一覧の絞り込みを「解除」した | 「作品管理」で作品を選んで「出力」ボタンから開く |
| 文字のフォントが変わって書き出された | Web フォントがまだ読み込まれていない（オフライン時など） | インターネットにつないだ状態で、一度ページを表示してから書き出す |
| 下書きが書き出されない | 下書きレイヤーは書き出されない仕様 | 書き出したいものはコマかオーバーレイに置く |

### AI・連携

| 症状 | 原因 | 対処 |
| --- | --- | --- |
| Nanobanana で「APIキーが設定されていません」と出る | `.env` がない、書き方が違う、ComfyUI を再起動していない | 第10章 10-3。`.env` は Comic Creator のフォルダの直下 |
| Nanobanana で2枚目以降が挿入できない | サムネイルで選んでいない（最初は1枚目が選ばれている） | 結果の下のサムネイルをクリックして選んでから「コマに挿入」を押す。画像は `ComfyUI/output/cc_nanobanana/` にも残る |
| Nanobanana（ネイティブ）で「COMFY_API_KEY未設定」と出る | `.env` に `COMFY_API_KEY` がない、または ComfyUI を再起動していない | `.env` に `COMFY_API_KEY=キー` を書いて再起動する。使わないなら、設定タブの「生成方式」を Gemini API に戻す（第10章） |
| ネイティブで Nano Banana Pro が使えない、Lite で 2K・4K が選べない | ネイティブノード方式の制限（Pro は未対応、Lite は 1K のみ） | 設定タブの「生成方式」を Gemini API にする |
| MOSS-Image で「ComfyUIが未対応です」と出る | ComfyUI が MOSS-Image に対応していない古い版 | ComfyUI を更新して再起動する |
| MOSS-Image で「モデルが見つかりません」と出る | 拡散モデル・テキストエンコーダ・VAE が所定のフォルダにない | 第10章 10-6 の表の場所に置いて、「モデル一覧を再読込」を押す |
| MOSS-Image で空の文字枠のところに何も描かれない | 文字が空の枠は送られない仕様 | 枠に文字を入力する |
| 「workflow studio」タブに「見つかりませんでした」と出る | ComfyUI-Workflow-Studio が入っていない | 入れて ComfyUI を再起動する（使わないならそのままでよい） |
| Generate したら元の画像が残っている | 生成した画像は上に重ねて追加される | 不要な元の画像をレイヤーパネルで削除する |
| Auto で「Failed to fetch」と出る | ローカル LLM の URL と、開いているアドレスが合っていない | URL のホスト名をそろえる（`127.0.0.1` なら `http://127.0.0.1:11434`） |
| 意思決定モデルが「未設定」と表示される | Workflow Studio と違うアドレスで開いている | Workflow Studio と同じアドレス（ポート番号も）で開く |
| 3D ポーズ・3D テキストでエラーが出る | comfyui-vrm-pose-editor が入っていない、フォルダ名が違う | フォルダ名を `comfyui-vrm-pose-editor` にして入れる（第2章） |
| PixiJS FX を開くとエラーになる | comfyUI-particle-pixijs が入っていない | 入れて ComfyUI を再起動する |
| 画像生成で GPU のメモリが足りない | Ollama のモデルが VRAM を使っている | 「設定」＞「VRAM調整（Ollama）」（第13章） |
| G'MIC が開かない | 実行ファイルの場所が違う | 「設定」＞「G'MIC 設定」で赤字の警告がないか確認する |

> **この章のまとめ**
> - 困ったら「再読み込み」「ComfyUI の再起動」「ヘルプタブの検索」の順に試す
> - 作品が見えないときは、ブラウザとアドレスを確認する
> - 書き出しは「出力ページ」の範囲を必ず確認する
> - 連携機能のエラーは、必要なカスタムノードが入っているか、ComfyUI を再起動したかを確認する
