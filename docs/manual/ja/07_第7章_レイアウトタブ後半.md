# 第7章 レイアウトタブ（後半）：フキダシ・テキスト・描画

この章では、フキダシとセリフ、文字、図形やペイント、マスク、マンガらしい効果の付け方を説明します。

1枚の画像に文字を入れたい人は、7-1・7-2 を読めば、ページに置いた画像にタイトルやセリフを入れられます。

## 7-1 フキダシ

ツールペインの「フキダシ」で、フキダシを置いて形を整えます。基本の置き方は第4章 4-5 で説明しました。

### フキダシの種類

「種類」で選べるフキダシは次の7つです。

| 種類 | 向いている場面 |
| --- | --- |
| 通常 (楕円) | ふつうの会話 |
| 角丸矩形 | 落ち着いた会話、説明 |
| キャプション (直角・尻尾なし) | ナレーション、場所や時間の説明 |
| 思考 (泡) | 心の声（尻尾が小さな泡になる） |
| バクダン | 叫び声、驚き |
| 雲 (もこもこ) | 心の声、ふんわりした台詞 |
| 雲 (なみなみ) | 不安、ゆらぐ気持ち |

### 置く・整える

1. フキダシを置きたいコマをクリックして選びます。
2. 「種類」を選び、「挿入」を押します。コマの中央にフキダシが置かれます。
3. ハンドルで大きさを変え、ドラッグで位置を動かします。

| 項目 | 内容 |
| --- | --- |
| 編集: ON／OFF | ON のあいだは、フキダシを動かしたり形を変えたりできる。挿入すると自動で ON になる |
| 色 | フキダシの中の色 |
| 枠 | フキダシの枠線の色 |
| 尻尾：角度・長さ・幅 | 尻尾の向き・長さ・根元の太さ |
| 尻尾なし | チェックすると尻尾を消す。外すと元の長さに戻る |

8つの丸いハンドルでは、つかんだ側だけが伸び縮みします（反対側は動きません）。

種類ごとに、次の調整項目が追加で表示されます。

| 種類 | 追加の項目 |
| --- | --- |
| バクダン | シード（トゲの並び方）、トゲ数、長さ、バラツキ、内側カーブ（トゲの谷を丸くする） |
| 思考 | 泡サイズ、個数、離す（本体と泡の間隔） |
| 角丸矩形 | 角丸（角の丸さ） |
| 雲 | シード、個数、凹凸、バラツキ |

> **ポイント**
> バクダンや雲の「シード」は、形のパターンの番号です。数字を変えると、同じ設定のまま形だけが変わります。気に入る形になるまで変えてみましょう。

### セリフを入れる

フキダシを選んで「テキストを内包」を押すと、「テキストを内包」の画面が開きます（第4章 4-5）。

| 項目 | 内容 |
| --- | --- |
| テキスト | セリフ。改行もできる |
| 文字サイズ・行間 | 文字の大きさと行の間隔 |
| 縦書き | チェックすると縦書き |
| 文字色 | 黒・白・赤・青 |
| 太字 | チェックすると太字 |
| 上下（左右）・文字寄せ | フキダシの中での文字の位置。横書きは上下と左右、縦書きは左右と上下 |
| フォント | Google／システム／カテゴリの3つのタブから選ぶ |

セリフは、フキダシの大きさに合わせて自動で折り返されます。フキダシ自体の大きさは変わらないので、文字があふれるときはフキダシのほうをハンドルで広げてください。入れたセリフは、フキダシをダブルクリックすると直せます。

### セリフの位置をドラッグで動かす

セリフ入りのフキダシを選ぶと、文字の周りに紫の点線ボックスが出て、その左下に小さな三角のコーナーが表示されます。

| 操作 | 動き |
| --- | --- |
| 三角コーナーをドラッグ | フキダシはそのままで、セリフの位置だけを動かす（回転したフキダシでは、フキダシの向きに沿って動く） |
| 三角コーナーまたはフキダシをダブルクリック | これまでどおり、セリフの入力画面を開く |

> **注意**
> 入力画面で「上下」や「文字寄せ」を変えると、ドラッグで動かした分はリセットされ、寄せの位置が優先されます。

> **ポイント**
> バクダンと雲は輪郭がでこぼこしているので、文字が入る範囲は形のひと回り内側になります。

### 延長フキダシ：長いセリフを分ける

長いセリフを、つながった2つ以上のフキダシに分けられます。

1. もとになるフキダシを選びます。
2. 「延長を追加」を押します。同じ形・色のフキダシが、くびれ（ネック）でつながって追加されます。
3. 追加されたフキダシを好きな位置に動かし、「テキストを内包」でセリフの続きを入れます。

| 動き | 内容 |
| --- | --- |
| もとのフキダシを動かす | 延長したフキダシも一緒に動く |
| 延長したフキダシを動かす | ネックだけが伸び縮みする |
| 線 | 重なった部分に線は出ず、全体の外側だけが1本の線になる |
| 削除 | 延長だけ消すと、もとのフキダシは残る。もとのフキダシを消すと、延長も一緒に消える |

### フキダシを画像にする

「画像に変換」を押すと、選んだフキダシを PNG 画像にして、同じ位置・同じ大きさで追加します。元のフキダシは残るので、不要なら削除してください。

## 7-2 テキスト

フキダシを使わずに、文字だけを置くときはツールペインの「テキスト」を使います。タイトル、効果音、手書き風の文字などに使います。

### 文字を置く

1. ツールペインの「テキスト」を押します。
2. フォント、「縦」（縦書きにするか）、「色」を選びます。
3. 「T」ボタンを押して、テキストを置けるモードにします。
4. プレビューで、文字を置きたい場所をクリックします。「テキスト入力」の画面が開きます。
5. 文字を入力して OK を押します。改行もできます。

置いた文字は、ダブルクリックすると入力し直せます。

### 文字の大きさ・形を変える

文字をクリックすると、周りに枠とハンドルが表示されます。

| 操作 | 方法 |
| --- | --- |
| 移動 | 文字をドラッグする |
| 文字の大きさ | 角の緑のハンドルをドラッグする（ドラッグした角の反対側の角が固定され、そこから見て広げた・縮めた量で大きさが決まる） |
| 縦長・横長にする | 辺の中央の青いハンドルをドラッグする |
| 斜めにゆがめる | Shift キーを押しながら、辺の青いハンドルをドラッグする |
| 伸び縮み・ゆがみを元に戻す | 「変形リセット」を押す |
| 縦書き⇔横書き | 文字を選んで「縦」のチェックを切り替える |

### フォントの選び方

| タブ | 中身 |
| --- | --- |
| Google | Google Fonts のフォント（フォントタブと共通の一覧） |
| システム | パソコンに入っているフォント |
| カテゴリ | フォントタブで分類したフォント（第8章） |

フォントが一覧に出てこないときは「再読込」を押します。

### スタイル：袋文字・影・グラデーション

「スタイル」を押すと、文字の見た目をくわしく決める画面が開きます。

| 項目 | 内容 |
| --- | --- |
| 塗り | 文字の色。単色・グラデーション・テクスチャ（画像の模様）から選ぶ。チェックを外すと塗りなし |
| 線 | 文字の輪郭線 |
| 袋文字 | 文字の外側を太く縁取る（マンガの効果音やタイトルでよく使う） |
| 影 | 文字の影 |
| 太字・斜体・下線 | 文字の飾り |
| 行間・上下位置・文字寄せ | 複数行の文字の並び方 |

プレビューを見ながら調整し、文字を選んでいるときはその文字にすぐ反映されます。文字を選んでいないときは、選んでいるコマの中央に新しい文字として入ります。

> **ポイント**
> 作ったスタイルは保存でき、フォントタブの「スタイル」一覧と共通です。保存したスタイルは、アセットパネルの「F」タブからクリック1つで使えます（第8章）。

> **ポイント**
> 線・袋文字・影の太さは、文字の大きさに対する割合で記録されます。あとから文字を大きくしても、見た目のバランスは変わりません。

### そのほかのボタン

| ボタン | 内容 |
| --- | --- |
| テキスト→PNG | 選んだ文字を PNG 画像に変換する |
| Insert | 「テキストを挿入」の画面を開く。挿入元に「スクリプト（プロットで選択中のセル）」か「OCR（OCRタブで検出したテキスト）」を選んで、文字として入れる（下の囲み、第10章 10-8、第11章） |

> **ポイント**
> 「OCR」を選ぶと、OCR タブで読み取った文字が、読み取った枠の位置に入ります。フォントサイズは「領域サイズから自動換算」か「指定フォントサイズ」を選べ、書字方向は「枠の形から自動」「横書き」「縦書き」から選べます。文字はオーバーレイに1つずつ入り、元に戻すと挿入した分がまとめて取り消されます。

## 7-3 図形を描く・ペイントする（ドロー）

ツールペインの「ドロー」には、上に4つのモードがあります。

| モード | できること |
| --- | --- |
| ドロー | 四角・丸・線などの図形を描く（あとから形や色を変えられる） |
| ペイント | ブラシで自由に描く |
| SVG色変更 | アセットから入れた SVG 画像の色を変える |
| SVG→PNG | SVG 画像を PNG 画像に変換する |

### ドロー：図形を描く

1. 図形を描きたいコマをクリックして選びます。
2. 「ドロー」モードで、描きたい形を選びます。
3. 「描画」を「ON」にして、コマの中をドラッグします。

「描画」を「OFF」にすると、描いた図形を選んで動かしたり、形を直したりできます。

| 形 | 描き方 |
| --- | --- |
| 矩形・楕円・直線 | ドラッグする。矩形は「角丸」で角を丸くできる |
| 曲線 | ドラッグした通りの自由な線を描く |
| 多角形 | クリックで角を足していき、始点の近くをクリックして閉じる |
| ベクター曲線 | クリックで点を足していき、なめらかな曲線でつなぐ。始点の近くをクリックで閉じる。Enter キーで閉じずに終える |
| 鎖・ロープ | ドラッグした道筋に沿って鎖・ロープ模様を描く |
| My曲線 | 「画像選択」で選んだ画像を、ドラッグした道筋に沿って並べる（最初から既定の画像が入っています） |

多角形とベクター曲線は、Esc キーで直前の点を1つ取り消せます。

| 項目 | 内容 |
| --- | --- |
| 塗り | 単色・グラデーション・テクスチャ（画像の模様）から選ぶ。「なし」で塗りなし |
| 線 | 線の色と太さ。「なし」で線なし |
| 不透明度 | 透け具合 |
| 図形をPNG変換 | 選んだ図形を PNG 画像にして、同じ位置に追加する |

図形を選んでいるときに塗りや線を変えると、その図形にすぐ反映されます。選んでいないときは、次に描く図形の設定になります。

### ペイント：ブラシで描く

1. 描きたいコマ（またはオーバーレイ・下書き）を選びます。
2. 「ペイント」モードで「ペイントを追加」を押します。コマと同じ大きさの、描き込み用の透明な画像が追加され、すぐに描ける状態になります。
3. 「ブラシ色」「サイズ」「不透明度」を決めて、ドラッグで描きます。

| 項目 | 内容 |
| --- | --- |
| 背景色 | チェックして色を選ぶと、透明ではなくその色で塗りつぶした画像として追加する |
| x5 | オン（オレンジ）にすると、ブラシを5倍の太さにする |
| 消しゴム | オン（赤）にすると、描いた部分を消す |
| 選択画像を統合 | レイヤーパネルでチェックした画像・ペイントを1枚の画像にまとめる |

ペンタブレットを使うと、筆圧に応じて太さと濃さが変わります。ブラシは、ペイント用の画像だけでなく、コマに入れたふつうの画像にも直接描き込めます。

> **ポイント**
> ペイントは、Workflow Studio で I2I（画像から画像を作る）をするときの、ラフや参照画像づくりにも使えます。透明のまま送ると、生成モデルによっては透明な部分を黒として扱います。「背景色」を白にしておくと安心です（第10章）。

### SVG色変更・SVG→PNG

アセットから入れた SVG 画像は、色を変えたり PNG 画像にしたりできます。

| モード | 使い方 |
| --- | --- |
| SVG色変更 | SVG 画像を選んで「色を抽出」→ 色ごとに色を選び直して「変更を適用」 |
| SVG→PNG | SVG 画像を選んで、幅・高さを入れて（空欄なら元の大きさ）「PNG変換して挿入」 |

## 7-4 マスク：一部だけ隠す・見せる

マスクを使うと、画像やコマの一部を消しゴムのように隠せます。元の画像は消えないので、あとから何度でも直せます。

### マスクの種類

| 種類 | 動き |
| --- | --- |
| 隠すマスク（塗った所を隠す） | ブラシで塗ったところが見えなくなる |
| 表示マスク（塗った所だけ表示） | ブラシで塗ったところだけが見える |

### マスクをかける

1. マスクをかけたい画像（またはコマ・オーバーレイ）を選びます。「対象」に表示されます。
2. ツールペインの「マスク」を押し、マスクの種類を選びます。
3. 「編集」を「ON」にします。
4. ブラシの「サイズ」「硬さ」を決めて、隠したい（または見せたい）ところをドラッグで塗ります。

| 項目 | 内容 |
| --- | --- |
| ブラシ：塗る／消す | 塗る＝マスクを足す、消す＝マスクを減らす |
| 非表示部を赤表示 | 隠れるところを半透明の赤で表示する |
| マスク適用 | チェックを外すと、マスクを一時的に無効にする（比べたいときに使う） |
| 反転 | 塗ったところと塗っていないところを入れ替える |
| クリア | 塗ったところを全部消す |
| 全面塗り | 全体を塗る |
| ＋レイヤー追加／レイヤー削除 | 1つの対象に、マスクを何枚も重ねられる |

> **ポイント**
> 画像のはしをぼかしたいときは、「硬さ」を下げてから塗ると、境目がやわらかくなります。

## 7-5 マンガらしい効果を付ける

マンガらしい効果は、2か所にあります。

| 場所 | ボタン | できること |
| --- | --- | --- |
| ツールペインの「画像」 | 🎨 ハーフトーン | 画像を網点にする、網点のパターンを作る |
| ツールペインの「マンガ」 | ✨ マンガ効果 | ヴィネット（周辺を暗く）、スクリーントーンノイズ、集中線 |
| ツールペインの「マンガ」 | 🎴 背景パターン | 縞・ドット・和柄などの背景模様 |

どれも、ボタンを押すとプレビュー付きの画面が開きます。プレビュー上の「選択画像／デフォルト／白」で背景を切り替えると、実際に重ねたときの見え方を確かめられます。

### ハーフトーン（網点）

| モード | 内容 |
| --- | --- |
| 画像を変換 | 選んだ画像を網点の画像に置き換える。明るさ・コントラスト・2値化・最小濃度で調子を整えられる |
| パターンを作成 | 網点の模様だけを、選んだコマ（またはオーバーレイ）と同じ大きさで新しく作る。スクリーントーンを貼るように使う |

画像を選ばずにコマだけを選んで開くと、「パターンを作成」で開きます。

| 共通の項目 | 内容 |
| --- | --- |
| 色モード | モノクロ／デュオトーン（インク色と紙色の2色） |
| パターン形状 | ドット・線・正方形・十字 |
| ドットサイズ・角度・カバレッジ | 網点の大きさ・向き・密度 |
| 明暗反転 | 網点の濃い・薄いを入れ替える |
| 濃度・グラデーション化 | （パターンを作成）全体の濃さと、だんだん薄くなる網点 |
| 背景を透過にする | （パターンを作成）網点のないところを透明にする |

### マンガ効果：ヴィネット・トーンノイズ・集中線

選んだコマ（またはオーバーレイ）と同じ大きさの、透明な効果の画像を作って、「コマに追加」で入れます。

| 効果 | 内容 |
| --- | --- |
| ヴィネット | 周りを暗くして、中心に目を向けさせる。色も選べる |
| スクリーントーンノイズ | 紙のようなざらつき。「粒サイズ」で調整 |
| 集中線 | 放射状・ウニフラ・ウニ（輪）・線形（流線）から選ぶ |

集中線の主な項目は次のとおりです。

| 項目 | 内容 |
| --- | --- |
| 密度 | 線の多さ |
| 範囲・長さ | 中心の空白の大きさ。大きいほど線が中心近くまで届く |
| 外枠側の太さ | 線の根元の太さ。大きくすると線がつながってベタ塗りのようになる |
| 中心X・中心Y | 集中線の中心の位置（放射状・ウニ） |
| 外側の長さ | トゲが外へ伸びる長さ（ウニ） |
| 角度 | 流れる向き（線形） |

> **ポイント**
> ウニフラの色を白にすると、ひらめきや驚きの「フラッシュ」表現になります。

追加した効果は、ふつうの画像と同じように、レイヤーパネルで動かしたり、不透明度を変えたり、削除したりできます。

### 背景パターン

選んだコマ（またはオーバーレイ）と同じ大きさの、模様の画像を作ります。

| 模様 | 種類 |
| --- | --- |
| 縞 | 横縞・縦縞・斜め縞 |
| 図形 | ドット・チェック |
| 和柄 | 麻の葉・市松・七宝・鱗 |
| カスタムSVG | 自分で用意した SVG 画像を並べる（ロゴなど） |

色・不透明度・サイズ（模様のくり返しの間隔）・回転を指定できます。「背景を透過」のチェックを外すと、背景色で塗りつぶした模様になります。

> **この章のまとめ**
> - フキダシは7種類。「テキストを内包」でセリフを入れ、長いセリフは「延長を追加」で分ける
> - 文字だけを置くときは「テキスト」の「T」をオンにしてクリック。「スタイル」で袋文字・影・グラデーション
> - 「ドロー」で図形、「ペイント」でブラシ描き。ペンタブの筆圧にも対応
> - 「マスク」で画像の一部を隠す・見せる。元の画像は消えないので何度でも直せる
> - ハーフトーンは「画像」、集中線・ヴィネット・背景パターンは「マンガ」から
