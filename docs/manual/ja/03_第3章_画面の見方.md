# 第3章 画面の見方

この章では、Comic Creator の画面のどこに何があるかを説明します。全部を覚える必要はありません。迷ったときに戻ってくる「地図」として使ってください。

## 3-1 タブの一覧

Comic Creator を開くと、画面の上に10個のタブが並んでいます。はじめて開いたときは「ページ」タブが表示されます。

［画像：画面上部のタブバー（10個のタブ）］

10個のタブは、役割で3つのグループに分けると分かりやすくなります。

### 作る

マンガのページや画像を作るためのタブです。いちばんよく使います。

| タブ | できること | 本書の章 |
| --- | --- | --- |
| ページ | 作品の作成・管理、テンプレートの管理、書き出し（出力） | 第4章・第5章 |
| レイアウト | ページのコマに画像・フキダシ・テキストを置いて編集する。メインの作業場所 | 第4章・第6章・第7章 |
| Image | レイヤーで画像を編集する画像エディタ。1枚の画像への文字入れにも使う | 第9章 |
| フォント | フォントの確認と、文字の見た目（スタイル）の保存 | 第8章 |

### AIで作る

AI で画像や脚本を作るためのタブです。使うには AI の準備が必要です。

| タブ | できること | 本書の章 |
| --- | --- | --- |
| Nanobanana | Google の Gemini API で画像を生成する | 第10章 |
| Auto | お題から AI でストーリー・脚本・コマ割りを作る | 第11章 |
| スクリプト | 脚本（あらすじ・プロット・コマごとのセリフ）を書いて管理する。AI なしでも使える | 第11章 |

### 補助する

作業を手助けするタブです。

| タブ | できること | 本書の章 |
| --- | --- | --- |
| workflow studio | Workflow Studio のギャラリーを表示する（ComfyUI-Workflow-Studio が必要） | 第10章 |
| 設定 | 表示言語、バックアップ・復元、外部ソフトとの連携の設定 | 第13章 |
| ヘルプ | アプリ内の説明書。キーワードで検索できる | この章の 3-4 |

> **ポイント**
> タブバーの右端にある「ws再読込」「ws新しいタブで開く」は、Workflow Studio 用のボタンです。Workflow Studio を使っていなければ気にしなくてかまいません。

## 3-2 レイアウトタブの画面

いちばん長く使うのが「レイアウト」タブです。画面は左から右へ、次のように分かれています。

［画像：レイアウトタブの画面構成（番号付き：①アセットパネル ②ツールペイン ③操作バー ④ツールの設定 ⑤プレビュー ⑥レイヤーパネル）］

| 番号 | 場所 | 役割 |
| --- | --- | --- |
| ① | アセットパネル（左端） | 画像素材・ページ・テンプレートなどの一覧。ここから選んでページに入れる |
| ② | ツールペイン（①の右） | 「フキダシ」「テキスト」などのツールを切り替える縦のボタン列 |
| ③ | 操作バー（上） | ページ送り・保存・コマの選択など、どのツールでも使う操作 |
| ④ | ツールの設定（③の下） | ②で選んだツールの設定項目 |
| ⑤ | プレビュー（中央） | 編集中のページ。ここで直接クリック・ドラッグして編集する |
| ⑥ | レイヤーパネル（右端） | ページ内のコマ・画像・フキダシなどの一覧と重ね順 |

### ① アセットパネル

アセットパネルの上には、アルファベット1文字のタブが並んでいます。マウスを乗せると名前が表示されます。

| タブ | 名前 | 中身 |
| --- | --- | --- |
| A | アセット | 画像素材やグループ素材。「コマに挿入」で選択中のコマに入れる |
| P | ページ | ページのサムネイル一覧 |
| T | テンプレート | コマ割りテンプレートの一覧。「ページとして挿入」で新しいページを作る |
| F | フォント | フォントタブで作ったスタイル・プリセット |
| I | Image | Image タブで保存した画像プロジェクト |

一覧が古いときは、右上の「↺」（アセット一覧を更新）を押します。

アセットパネルは「ページ」タブでは表示されません。「Image」タブでは A・F・I、「スクリプト」タブでは S（保存済み作品・ページ作品）だけが表示されます。

### ② ツールペイン

ツールペインは、レイアウトタブでだけ表示されます。ボタンを押すと、④の設定が切り替わります。

| ボタン | 使い方 | 本書の章 |
| --- | --- | --- |
| フキダシ | フキダシを置く | 第7章 |
| テキスト | 文字を置く | 第7章 |
| ドロー | 図形や線を描く、ペイントする | 第7章 |
| 画像 | 背景除去などの画像処理、ハーフトーン、PixiJS FX | 第6章・第7章・第12章 |
| 動画 | 動画をコマに置く（実験的な機能） | 第12章 |
| マスク | 画像やコマの一部を隠す・表示する | 第7章 |
| 3Dポーズ／3Dテキスト | 3D モデルや立体文字を置く | 第12章 |
| マンガ | マンガ効果（集中線など）・背景パターン | 第7章 |
| サブコマ／分割／変形 | コマ割りをあとから直す | 第6章 |

### ③ 操作バー

| 項目 | 動き |
| --- | --- |
| ページ ◀ ▶ | 作業中の作品の前・次のページへ切り替える |
| 「3 / 12」の表示 | 今のページ番号／作品のページ数 |
| ページ削除 | 表示中のページをゴミ箱へ移す |
| 保存 | 表示中のページを保存し、作品に登録する |
| コマ | 操作するコマを選ぶ（プレビューでコマをクリックしても選べる） |
| コマ枠線幅 | コマの枠線の太さ |
| 削除 | 選択中の画像・フキダシなどを削除する |
| 元に戻す | 直前の操作を取り消す |
| 画像を挿入 | 選んだ画像ファイルをコマに入れる |
| 画像タブで編集 | 選択中の画像を Image タブで開く |
| Generate | Workflow Studio で画像を生成する（第10章） |
| OC | 選択中のものをコマの中央（オーバーレイならページの中央）へ移動する |
| 閉じる | 作業中の作品を閉じる。保存済みのデータは消えない |

> **ポイント**
> 画像は、パソコンのフォルダからプレビューへドラッグ＆ドロップしても入れられます。

### ⑥ レイヤーパネル

ページの中にあるものが一覧で表示されます。上にあるものほど手前に表示されます。

- 行をクリックすると、そのもの（とそれが入っているコマ）が選択されます
- 「↑」「↓」で重ね順を入れ替えます
- 「G+」でグループにまとめ、「G-」でグループを解除します
- 「不透明度」で選択中のものの透け具合を変えます
- いちばん下の「表示サイズ」で、プレビューの拡大・縮小（25〜300%）ができます

くわしい使い方は第6章で説明します。

## 3-3 ほかのタブの画面

ほかのタブの画面は、それぞれの章で説明します。ここでは見分け方だけ紹介します。

| タブ | 画面の特徴 |
| --- | --- |
| ページ | 上に「作品管理」「テンプレート」「出力」の3つのサブタブ。アセットパネルは出ない |
| Image | 左にアセットパネル（A・F・I）、上にツールのボタン、右にレイヤー |
| フォント | フォントの一覧とプレビュー |
| Nanobanana | 「生成設定」「I2I 入力」「履歴」の3つのサブタブ |
| Auto | 「ストーリー・脚本」「オートレイアウト」の2つのサブタブ |
| スクリプト | 左にアセットパネル（S）、中央にプロット |

［画像：ページタブの画面］

## 3-4 ヘルプタブを使う

「ヘルプ」タブは、Comic Creator に組み込まれた説明書です。本書より細かい機能まで書かれています。

［画像：ヘルプタブ（左に検索欄と項目一覧、右に説明）］

1. 「ヘルプ」タブを開きます。
2. 左上の検索欄（「機能を検索...」）に、調べたい言葉を入力します。例：`フキダシ`、`バックアップ`
3. 左の一覧から項目を選ぶと、右に説明が表示されます。
4. 説明の中の「タブを開く →」を押すと、その機能のタブへ移動します。

ヘルプは日本語・英語・中国語で表示され、「設定」タブで選んだ言語に合わせて切り替わります。

> **ポイント**
> 本書はバージョン v1.53.2 をもとにしています。ボタンの名前や場所が本書と違うときは、ヘルプタブで検索すると、今のバージョンの説明が見つかります。

> **この章のまとめ**
> - タブは「作る」「AIで作る」「補助する」の3グループ。よく使うのは「ページ」と「レイアウト」
> - レイアウトタブは左から、アセットパネル・ツールペイン・操作バーとツールの設定・プレビュー・レイヤーパネル
> - アセットパネルの A・P・T・F・I は、素材・ページ・テンプレート・フォント・Image
> - 分からないことはヘルプタブで検索する
