# 第6章 レイアウトタブ（前半）：コマと配置

この章では、レイアウトタブで画像を置く場所の選び方、レイヤーパネルでの整理、コマ割りをあとから直す方法、素材（アセット）の登録を説明します。フキダシ・テキスト・描画は第7章で扱います。

## 6-1 画像を置く場所と入れ方

### 置き場所は3種類

レイアウトタブでは、画像を次の3か所に置けます。

| 置き場所 | 特徴 | 書き出しに含まれるか |
| --- | --- | --- |
| コマ | コマの形で切り取られる。ふつうはここに置く | 含まれる |
| オーバーレイ（全面） | ページ全体を覆う手前の層。コマの枠をまたいで表示される（ページの外にははみ出さない） | 含まれる |
| 下書き（全面） | オーバーレイよりさらに手前の、下描き用の層。画像だけ置ける | **含まれない** |

置き場所は、プレビューでコマをクリックするか、レイヤーパネルで「オーバーレイ（全面）」「下書き（全面）」の行をクリックして選びます。選んだコマは青い枠で囲まれます。

> **ポイント**
> 下書きレイヤーは、選んでいるあいだだけクリックやドラッグを受け付けます。選んでいないときは、クリックがその下のオーバーレイやコマに素通りします。ラフや構図の下描きを置いたまま、その下で作業できます。

### 画像の入れ方は3通り

| 方法 | 手順 |
| --- | --- |
| ドラッグ＆ドロップ | パソコンの画像ファイルを、入れたいコマの上にドロップする（第4章 4-4） |
| 画像を挿入 | コマを選んで、操作バーの「画像を挿入」でファイルを選ぶ |
| アセットパネル | アセットパネルの「A」タブで素材を選び、「コマに挿入」を押す（6-5） |

画像はコマの左上にそろえて、コマの幅いっぱいの大きさで入ります。

### 画像を動かす・大きさを変える・回す

画像をクリックすると、周りにハンドルが表示されます。

| 操作 | 方法 |
| --- | --- |
| 移動 | 画像をドラッグする |
| 拡大・縮小 | 緑のハンドルをドラッグする（縦横の比率は保たれる） |
| 自由に変形 | Alt キーを押しながら緑のハンドルをドラッグする（画像も伸び縮みする） |
| 回転 | 黄色のハンドルをドラッグする |
| 中央に戻す | 操作バーの「OC」を押す |
| 削除 | 操作バーの「削除」、または Delete／Backspace キー |

> **ポイント**
> 画像をコマの外まで動かしてしまい、つかめなくなったときは、レイヤーパネルでその画像の行を選んで「OC」を押すと、コマの中央に戻ります。

## 6-2 レイヤーパネル

［画像：レイヤーパネル（コマの行と、その下に並ぶ画像・フキダシの行）］

レイヤーパネルには、ページの中のものが「コマ → その中のもの」の順に並びます。

### コマの行のボタン

| ボタン | 動き |
| --- | --- |
| ✕ | そのコマを削除する（中の画像・フキダシ・サブコマも消える。「元に戻す」で戻せる） |
| □／− | そのコマの枠線を表示する（□）／隠す（−） |
| 🔓／🔒 | コマの中のもの全部をまとめてロックする／ロックを外す |

### 画像・フキダシなどの行のボタン

| ボタン | 動き |
| --- | --- |
| 👁 | 表示する／隠す |
| 👁 を Alt＋クリック | ページ全体の、同じ種類のもの（フキダシだけ、画像だけ、など）をまとめて表示／非表示 |
| 🔓／🔒 | ロックする／ロックを外す。ロックすると、選択・移動・削除ができなくなる |
| ✕ | 削除する |

> **ポイント**
> 👁 の Alt＋クリックで「フキダシだけ全部隠す」と、絵だけを確認できます。もう一度 Alt＋クリックすると元に戻ります。

### パネル上部・下部の操作

| 場所 | 操作 | 動き |
| --- | --- | --- |
| 上部 | ↑ ↓ | 選んだものの重ね順を上下に動かす（上ほど手前） |
| 上部 | G+／G- | グループにまとめる／グループを解除する（6-3） |
| 上部 | 📦+ | チェックした1つをアセットとして登録する（6-5） |
| 上部 | 不透明度 | 選んだものの透け具合 |
| 下部 | 複製／移動 | 選んだものを、ドロップダウンで選んだコマ（またはオーバーレイ・下書き）へ複製／移動する |
| 下部 | 表示サイズ | プレビューの拡大・縮小（25〜300%） |

## 6-3 グループにまとめる

複数のものをまとめて動かしたいときは、グループにします。

1. レイヤーパネルで、まとめたいものの行のチェックボックスに2つ以上チェックを入れます。
2. 上部の「G+」を押します。

グループの行（[G] の印）をクリックすると、オレンジ色の点線の枠が表示されます。ドラッグで一緒に動かし、ハンドルで一緒に拡大・縮小・回転できます。解除するときは、グループを選んで「G-」を押します。

> **注意**
> グループにできるのは、同じコマの中のものどうしだけです。

## 6-4 コマ割りをあとから直す

テンプレートで作ったコマ割りは、ページに入れたあとでも直せます。ツールペインの「サブコマ」「分割」「変形」を使います。

### サブコマ：コマの中に小さなコマを作る

コマの中に、別のカットを差し込むための小さなコマ（サブコマ）を作ります。サブコマには、ふつうのコマと同じように画像やフキダシを入れられます。

1. ツールペインの「サブコマ」を押します。
2. 「サブコマ追加」を「ON」にし、形を「矩形」か「丸」から選びます。
3. プレビューで、サブコマを作りたいコマの中をドラッグします。

   ［画像：コマの中にサブコマを作ったところ］

作ると、「サブコマ追加」は自動で「OFF」に戻ります。

| 操作 | 方法 |
| --- | --- |
| 移動 | サブコマの枠線（黒い線）をドラッグする |
| 大きさ・回転 | 選んだときに出る丸いハンドル／黄色のハンドルをドラッグする |
| 枠線の太さ | 「選択中のサブコマの枠線幅」に入力する |
| 削除 | レイヤーパネルのサブコマの行の ✕ |

> **ポイント**
> サブコマの中をクリックすると、ふつうは中の画像が選ばれます。サブコマの枠ごと動かしたいときは、レイヤーパネルのサブコマの行にあるチェックボックスをオンにします。

### 分割：1つのコマを2つに分ける

1. ツールペインの「分割」を押します。
2. 「コマ分割」を「ON」にします。
3. プレビューで、分けたいコマの中を、分ける線に沿ってドラッグします。斜めの線でもかまいません。

選んだコマだけが2つに分かれ、ほかのコマは変わりません。

| 項目 | 内容 |
| --- | --- |
| コマ間の幅 | 分けた2つのコマのあいだのすき間。ページの既存のすき間から自動で入るので、ふつうは変えなくてよい |
| 中にあったもの | 新しいコマの範囲にすっぽり入るものだけが新しいコマへ移る。それ以外は元のコマに残る |
| コマ番号 | 新しいコマは元のコマの次の番号になり、以降の番号が1つずつずれる |

### 変形：コマの形を変える・コマを消す

1. ツールペインの「変形」を押します。
2. 「コマ変形」を「ON」にして、変えたいコマをクリックします。角（●）と辺が表示されます。
3. 角をドラッグすると、その角だけが動きます。辺をドラッグすると、その辺が平行に動きます。

   ［画像：コマ変形で角をドラッグしているところ］

| 操作 | 方法 |
| --- | --- |
| 角を減らす | 角をクリックして選び、「選択頂点を削除」（または Delete キー）。四角形を三角形にできる |
| コマを消す | 「選択コマを削除」。中の画像なども一緒に消える |
| ページの外周も動かす | 「外周ロック」をオフにする（最初はオンで、外周上の角は灰色で表示され、動かせない） |

> **注意**
> 変形では、選んだコマだけが動きます。となりのコマと重なったり、ページの外にはみ出したりしても止まりません。思ったとおりにならなければ「元に戻す」で戻してください。

> **ポイント**
> ロック（🔒）したコマは、分割も変形もできません。サブコマも、分割・変形の対象外です。

## 6-5 アセット（素材）を使う

よく使う画像や、作ったフキダシの組み合わせを「アセット」として登録しておくと、アセットパネルの「A」タブからすぐに入れられます。

### 自分の画像フォルダを素材にする

アセットパネルの「A」タブには、Comic Creator のフォルダの中にある `assets` フォルダの中身が表示されます。

```
ComfyUI/custom_nodes/comfyui-comic-creator/assets/
└── （好きなフォルダ名）/
    ├── 背景01.png
    └── 効果線.png
```

1. `assets` フォルダの中にフォルダを作り、画像（PNG・JPEG・WebP・SVG）を入れます。`assets` の直下に置いた画像は表示されません。
2. アセットパネルの「↺」を押すと、一覧に表示されます。
3. 素材をクリックして選び、「コマに挿入」を押します。

> **注意**
> アセットパネルで素材を Alt＋クリックすると、確認のあと、**パソコンの中のファイルごと削除されます**（元に戻せません）。

> **注意**
> `assets` フォルダは Comic Creator のフォルダの中にあります。Comic Creator を削除して入れ直すと、中の素材も消えます。入れ直す前に、`assets` フォルダを別の場所にコピーしておいてください。

### 作ったものをアセットとして登録する

レイアウトタブで作ったフキダシ・テキスト・図形や、そのグループを、アセットとして登録できます。

| 登録したいもの | 方法 |
| --- | --- |
| グループ | レイヤーパネルのグループの行の 📦 ボタン |
| 1つのもの（画像・フキダシ・テキスト・図形） | チェックボックスで1つだけチェックして、上部の 📦+ ボタン |

ボタンを押したら、登録先のフォルダを選ぶか新しく作り、ファイル名を入れて「登録」を押します。アセットパネルにすぐ表示されます。

フキダシやテキストを登録した場合は、あとで「コマに挿入」したときも、フキダシやテキストとして編集できる状態で入ります。

### アセットパネルのほかのタブ

| タブ | 使い方 |
| --- | --- |
| P（ページ） | 作業中の作品のページ一覧。クリックでそのページに切り替える |
| T（テンプレート） | 選んで「ページとして挿入」（またはダブルクリック）でページを足す |
| F（フォント） | フォントタブで作ったスタイルの一覧。クリックすると、選んだコマにテキストとして入る（テキストを選んでいるときは、そのテキストに適用される）（第8章） |
| I（Image） | Image タブで保存した画像プロジェクト。レイアウトタブでは、その画像をコマに入れる（第9章） |

## 6-6 画像を加工する（画像サブタブ）

ツールペインの「画像」では、選んだ画像に簡単な加工ができます。

［画像：画像サブタブ］

| 項目 | 内容 |
| --- | --- |
| 背景除去 | チェックすると、人物などを残して背景を透明にする |
| モデル | 「軽量 (@imgly)」を使う |
| 品質 | 低品質・軽量（42MB）／標準品質（84MB）／高品質（168MB）。高いほど輪郭がきれいだが、初回のダウンロードが大きい |
| 倍率 | 画像を何倍の大きさにするか（最大 4 倍） |
| シャープ | 輪郭をくっきりさせる強さ |
| ノイズ除去 | チェックすると、ざらつきを減らす |
| 実行 | 上の設定で加工する |

1. 加工したい画像をクリックして選びます。
2. 項目を設定して「実行」を押します。

加工した画像は、元の画像と同じ位置・大きさ（回転も同じ）で **新しい画像として追加** され、元の画像は自動で **非表示** になります。元の画像は消えていないので、比べたいときは、レイヤーパネルの 👁 で表示し直せます。不要なほうは削除してください。

> **注意**
> 背景除去は、初回にモデルをダウンロードするため、インターネット接続が必要です。また、モデルの「BiRefNet」を使うには、カスタムノード「Mask Editor One」と BiRefNet のモデルが必要です。入っていないときは、「BiRefNet」はグレーになり、選べません。

画像サブタブには、ほかに次のボタンがあります。

| ボタン | 内容 | 本書の章 |
| --- | --- | --- |
| ↔ ↕ | 画像を左右／上下に反転する | — |
| G'MIC GUIで編集／結果を挿入 | 外部ソフト G'MIC で画像を編集する | 第12章 |
| ✨ PixiJS FX | パーティクルやフィルタの効果を付ける | 第12章 |
| 🎨 ハーフトーン | 網点（スクリーントーン風）にする | 第7章 |

> **この章のまとめ**
> - 画像の置き場所は、コマ・オーバーレイ（全面）・下書き（全面）の3つ。下書きは書き出されない
> - 緑のハンドルで拡大・縮小（Alt で自由変形）、黄色のハンドルで回転
> - レイヤーパネルで重ね順・表示・ロック・グループを管理する。👁 の Alt＋クリックで同じ種類をまとめて隠せる
> - コマ割りは「サブコマ」「分割」「変形」であとから直せる
> - `assets` フォルダの中のフォルダに画像を入れると、アセットパネルの「A」タブから使える
> - 「画像」サブタブの加工結果は、元の画像と同じ位置・大きさで追加され、元の画像は非表示になる（👁 で戻せる）
